> **140회 출제 예상 토픽 #1** — v7-multi(KPC+ITPE) 상위, 137~139 미출제
> 선정 근거: ① 두 학원 140 대비 모의·파이널라운드에서 Physical AI·자율주행·Affective 반복 출제, ② 137~139 기출 전무(직전 미출제), ③ 엔비디아·현대차 등 산업 투자 폭증, ④ AI가 SW를 넘어 물리 세계로 확장하는 패러다임 전환

## 1. 출제 트렌드 분석 (135~139회)

다음 표는 피지컬 AI·로봇 관련 출제 이력이다.

| 회차 | 유형 | 출제 형태 | 비고 |
|------|------|-----------|------|
| 137회 | 관리 단답 | 트랜스포머·MoE | 모델 기반기술 |
| 138회 | 관리 논술 | GPU·TPU | 컴퓨팅 인프라 |
| 139회 | 관리 논술 | 다중 에이전트(MAS) | 소프트웨어 자율성 |
| 모의/파이널 | KPC·ITPE | Physical AI·자율주행·감성로봇 | **140 집중 드릴** |

**핵심 인사이트**: 138 GPU→139 소프트웨어 에이전트로 이어진 흐름이 **140에서 물리 세계(피지컬 AI)로 확장**되는 것이 자연스럽다. MAS는 139에 나왔으므로 각도를 **체화(Embodied)·물리 상호작용**으로 튼다.

## 2. 개념·정의

### 피지컬 AI (Physical AI)
> 센서로 물리 환경을 인지하고, AI로 판단해, 구동장치로 **실제 세계에서 행동**하는 AI. LLM이 언어를 다뤘다면 피지컬 AI는 **물리 법칙·공간·동역학**을 다룬다.

### 월드모델 (World Model)
> AI가 환경의 동작 방식을 내부에 학습해, **다음 상태를 예측·시뮬레이션**하는 모델. 실제 시행착오 없이 "상상 속에서" 계획한다.

### VLA (Vision-Language-Action)
> 시각·언어·행동을 하나로 잇는 로봇 기초모델. 명령을 이해하고 장면을 보고 동작을 생성한다.

## 3. 피지컬 AI 아키텍처

```
┌──────────────────────────────────────────────────────────┐
│                    Physical AI Loop                        │
│  ① 인지(Perception) → ② 월드모델(예측) → ③ 계획 → ④ 제어  │
└───────┬──────────────┬──────────────┬──────────────┬─────┘
        │              │              │              │
  ┌─────▼────┐   ┌─────▼────┐   ┌────▼─────┐  ┌─────▼─────┐
  │ 센서퓨전 │   │ World    │   │ VLA/정책 │  │ 액추에이터│
  │ 카메라·  │   │ Model    │   │ 모델     │  │ 구동·제어 │
  │ 라이다·  │   │ (동역학  │   │ (행동생성)│  │           │
  │ IMU      │   │  예측)   │   │          │  │           │
  └──────────┘   └──────────┘   └──────────┘  └───────────┘
        │                                            │
   [Sim2Real]                                  [기능안전/페일세이프]
   디지털트윈 학습 → 실환경 이전           SIL·비상정지·HITL
```

## 4. 핵심 기술요소

| 요소 | 설명 |
|------|------|
| 센서퓨전 | 카메라·라이다·레이더·IMU 융합 인지 |
| 월드모델 | 환경 동역학 학습·미래 상태 예측 |
| VLA 모델 | 시각·언어·행동 통합 로봇 파운데이션 |
| Sim2Real | 시뮬레이션(디지털트윈) 학습 → 실환경 이전 |
| 감성컴퓨팅 | 표정·음성 멀티모달 정서 인식·표현 |
| 엣지 실시간 | 저지연 온디바이스 추론·제어 루프 |

> 🔑 **두음: 센월브시감엣** (센서퓨전·월드모델·VLA·Sim2Real·감성·엣지)

## 5. 응용과 안전 과제

- **응용**: 자율주행(도로·철도), 휴머노이드·서비스 로봇, 스마트팩토리, 돌봄·감성 로봇
- **안전**: 물리 오작동이 곧 사고 → **기능안전(SIL)·페일세이프**, 인지 오류의 안전 여파, 실시간성 보장
- **신뢰**: 감정·생체 데이터 프라이버시, 설명가능성, Human-in-the-Loop

- **정의**: 인지-판단-행동으로 물리 세계와 상호작용하는 AI
- **핵심**: 월드모델·VLA·Sim2Real·센서퓨전
- **차이**: 디지털(LLM) vs 물리(동역학·실시간·안전)

### 논술형(25점) 구조
**[서론]** SW를 넘어 물리로 확장되는 AI 패러다임, 정의·등장배경

**[본론2] 핵심기술** 월드모델의 예측·계획, 디지털트윈 기반 학습, 감성컴퓨팅

**[결론]** 자율성과 안전의 균형, 표준화·산업 생태계
