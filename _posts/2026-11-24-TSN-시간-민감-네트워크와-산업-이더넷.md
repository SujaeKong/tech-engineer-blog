## 1. 뉴스 요약

뉴스로드·데일리안(11-22~23)은 **안산시가 네이버클라우드와 손잡고 지역 제조업의 AI 전환에 나선다**고 보도했고, 에너지타임즈(11-22)는 **한국지역난방공사와 에머슨의 집단에너지 AI 최적운영 기술개발**을 전했다. 앞서 파이낸셜뉴스 등(11-18~19)은 정부·민간이 5년간 2조 원을 들여 스마트공장 2,000곳을 지원한다고 보도했다. 현장의 AI 전환이 실제로 설비를 움직이려면 센서 데이터와 제어 명령이 **정해진 시간 안에 반드시 도착하는 네트워크**가 필요하다. 이 글은 특정 기사 하나가 아니라 이런 산업 현장 AX 흐름을 바탕으로, 결정적 이더넷 기술인 **TSN**(Time-Sensitive Networking)을 토픽 심화로 정리한다.

## 2. 핵심 개념

### 정의
**TSN**은 IEEE 802.1 작업 그룹이 표준화한 **표준 이더넷 위에서 시간 동기, 지연 상한 보장, 무손실 이중화를 제공하는 표준군**이다. 일반 이더넷은 "가능한 한 빨리"(Best Effort) 보내므로 혼잡하면 지연이 들쭉날쭉하지만, TSN은 "**정해진 시간 안에 반드시**"(Deterministic) 보내는 것을 목표로 한다. 이 덕분에 제어 트래픽과 영상·IT 트래픽이 **하나의 네트워크를 함께 써도** 제어 트래픽의 실시간성을 지킬 수 있다.

### 결정성이 필요한 이유
- **제어 주기**: 모션 제어는 수백 μs~수 ms 주기로 명령이 오가야 한다. 한 번만 늦어도 동작이 어긋난다.
- **지터**: 평균 지연보다 **지연의 흔들림**(지터)이 문제다. 제어 알고리즘은 일정한 주기를 전제로 설계된다.
- **망 통합**: 기존에는 제어망과 IT망을 따로 깔았다. 하나로 합치려면 IT 트래픽이 제어 트래픽을 방해하지 못하게 해야 한다.

### 표준 이더넷 vs 산업 이더넷 vs TSN

| 구분 | 표준 이더넷 | 기존 산업 이더넷(실시간 프로토콜) | TSN |
|---|---|---|---|
| 전송 방식 | 최선 노력 | 벤더별 전용 방식(시분할·전용 칩) | IEEE 표준 기반 스케줄링 |
| 지연 보장 | 없음 | 있음 | 있음(지연 상한) |
| 상호운용성 | 높음 | 낮음(프로토콜 간 비호환) | 높음(표준 기반) |
| 망 통합 | 가능하나 실시간성 없음 | 전용망 필요 | 제어·IT 트래픽 공존 |
| 이중화 | 스패닝 트리 등(전환 시간 발생) | 전용 링 이중화 | 무중단 이중 전송(FRER) |
| 대역폭 | 높음 | 제한적인 경우 많음 | 높음(일반 이더넷 속도) |
| 장비 | 범용 | 전용 장비 | TSN 지원 스위치·NIC |

### IEEE 802.1 TSN 주요 표준

| 기능 | 표준 | 역할 |
|---|---|---|
| 시간 동기 | IEEE 802.1AS(gPTP) | 망 전체 장비의 시계를 정밀하게 맞춤 — 모든 TSN 기능의 기반 |
| 시간 인지 셰이퍼 | IEEE 802.1Qbv | 시간표(게이트 제어 목록)에 따라 큐의 문을 열고 닫아 제어 트래픽 전용 시간 확보 |
| 프레임 선점 | IEEE 802.1Qbu·802.3br | 긴 일반 프레임 전송을 잠시 끊고 급한 프레임을 먼저 보냄 |
| 신용 기반 셰이퍼 | IEEE 802.1Qav | 오디오·영상 스트림 대역폭 평탄화(AVB에서 유래) |
| 이중화 | IEEE 802.1CB(FRER) | 프레임을 복제해 두 경로로 보내고 수신 측에서 중복 제거 — 링크 장애 시 무중단 |
| 스트림 필터링·감시 | IEEE 802.1Qci | 스트림별로 규칙 위반 트래픽 차단 — 오작동·공격 장비 격리 |
| 구성 관리 | IEEE 802.1Qcc | 스트림 요구사항 수집과 중앙 집중형 경로·스케줄 계산 |

### 구성도 ① — 시간 인지 셰이퍼와 프레임 선점

```
 한 주기(예: 1ms)를 시간 창으로 나눔(802.1Qbv)

 시간 ─▶ |◀ 제어 창 ▶|◀──────── 일반 트래픽 창 ────────▶|◀ 제어 창 ▶|
 큐 7    [열림 ■■]    [닫힘]                              [열림 ■■]
 큐 0~6  [닫힘]        [열림 □□□□□□□□□□□□□□□□]           [닫힘]
                                              ▲
                                     보호 구간(Guard Band): 제어 창 직전에
                                     긴 프레임이 걸쳐 있지 않도록 비워 둠

 프레임 선점(802.1Qbu·802.3br)을 쓰면:
   긴 일반 프레임 □□□□ 전송 중 → 급행 프레임 ■ 도착 → □□ 잘라 멈춤 → ■ 전송 → □□ 이어서 전송
   → 보호 구간을 줄여 대역폭 낭비 감소
```

시간 인지 셰이퍼가 제대로 동작하려면 **모든 스위치가 같은 시각을 공유**해야 한다. 그래서 802.1AS 시간 동기가 TSN의 출발점이다.

### 구성도 ② — TSN 구성 모델(완전 중앙 집중형)

```
 [CUC: 중앙 사용자 설정]  ← 공장 엔지니어링 도구(어떤 장비가 어떤 주기로 통신하는지)
        │ 스트림 요구사항(주기·크기·최대 지연)
        ▼
 [CNC: 중앙 네트워크 설정]  토폴로지 파악 → 경로·시간표(GCL) 계산
        │ 설정 배포
        ▼
 ┌───────────── TSN 스위치망 ─────────────┐
 │ [스위치]──[스위치]──[스위치]            │  802.1AS 시간 동기
 │    │          │          │              │  802.1Qbv 시간표 적용
 │ [PLC]     [로봇]     [카메라·AI 엣지]   │  802.1CB 이중 경로
 └─────────────────────────────────────────┘
```

구성 방식은 장비들이 서로 협상하는 **완전 분산형**, 망 설정만 중앙에서 하는 **중앙 망·분산 사용자형**, 그리고 위 그림의 **완전 중앙 집중형**으로 나뉜다. 시간표 계산이 복잡해 산업 현장에서는 중앙 집중형이 주로 검토된다.

### 5G-TSN 연동
무선이 필요한 이동 로봇·AGV를 위해 3GPP는 **5G 시스템 전체를 하나의 TSN 브리지처럼 보이게** 하는 연동 구조를 표준화했다. 단말 쪽과 네트워크 쪽에 변환 기능(TSN 변환기)을 두어, TSN 망 입장에서는 5G 구간이 지연 특성이 정해진 스위치 하나로 보인다. 다만 무선 구간의 지연 변동을 유선 수준으로 줄이는 것이 과제다.

### 적용 분야와 고려사항
- **적용**: 공장 자동화(모션 제어·PLC 간 통신), 차량 내 네트워크, 전력 변전소 자동화, 방송·음향(AVB)
- **산업 프로파일**: 표준 기능이 많아 분야별로 쓸 기능 조합을 정한 프로파일이 필요하다(산업 자동화용 IEC/IEEE 60802, 차량용 IEEE 802.1DG 등).
- **보안**: 시간 동기를 교란하면 모든 시간표가 무너진다. 802.1AS 메시지 보호와 스트림 필터링(802.1Qci)이 중요하다.
- **설계 복잡도**: 스트림이 많아지면 시간표 계산이 어려워져 자동화 도구가 필수다.
- **기존 설비 연동**: 기존 산업 이더넷 장비와의 공존·전환 계획이 필요하다.

### 관련 표준
- **IEEE 802.1 TSN 표준군**: 802.1AS·Qbv·Qbu·Qav·CB·Qci·Qcc 등
- **IEEE 802.3br**: 이더넷 프레임 선점(IET)
- **IEC/IEEE 60802**: 산업 자동화용 TSN 프로파일
- **3GPP 5G-TSN 연동**: 5G 시스템을 TSN 브리지로 통합
- **OPC UA over TSN**: 산업 데이터 모델(OPC UA)과 TSN 전송의 결합

## 4. 연결 기출 토픽과 예상 변형

- **큐 스케줄링**: 140회 2교시에 **FIFO·WFQ 스케줄링**이 출제됐다. 시간 인지 셰이퍼는 시간을 기준으로 큐를 열고 닫는 스케줄링으로, 같은 문항의 확장 변형으로 나오기 좋다.
- **5G**: 블로그 통합 기출 분석(`exam_trend_integrated.json`) 기준 **5G는 기출 13회**다. 5G-TSN 연동은 5G의 산업용 저지연(URLLC) 활용 문항과 연결된다.
- **매체 접근 제어**: 140회 3교시 **CSMA/CA·CDMA·TDMA**가 출제됐다. TSN의 시간 창 분할은 유선 이더넷에 시분할 원리를 도입한 것으로 비교 설명에 쓸 수 있다.
- **예상 변형**
  - 1교시: "TSN(Time-Sensitive Networking)을 설명하시오"
  - 1교시: "IEEE 802.1Qbv 시간 인지 셰이퍼(TAS)를 설명하시오"
  - 논술: "스마트공장의 IT·OT 망 통합을 위한 TSN 기반 네트워크 설계 방안을 제시하시오"

## 5. 답안 구성 예시

**단답형**(1교시, 1페이지)
- 정의: 표준 이더넷 위에서 시간 동기·지연 상한 보장·무손실 이중화를 제공하는 IEEE 802.1 표준군
- 특징 3개: ① 802.1AS 시간 동기 기반 ② 802.1Qbv 시간 창으로 제어 트래픽 지연 보장 ③ 802.1CB 이중 전송으로 무중단
- 구성도 키워드: CUC → CNC(경로·시간표 계산) → TSN 스위치(gPTP·Qbv·CB) → PLC·로봇·AI 엣지

**논술형(2~4교시) 목차**
1. 개요: 산업 현장 AX와 결정적 네트워크의 필요성
2. 구성/비교: 이더넷·산업 이더넷·TSN 비교표, TSN 표준표, 시간 인지 셰이퍼 구성도, 중앙 집중형 구성도
3. 적용방안: IT·OT 망 통합 설계, 트래픽 등급 분류, 중앙 집중형 스케줄 계산, 핵심 제어 스트림 FRER 이중화, 5G-TSN으로 이동 설비 연결
4. 고려사항: 시간 동기 보안, 시간표 계산 복잡도, 기존 산업 이더넷 공존, 장비 비용, 산업 프로파일 준수
5. 기술사 제언: TSN 도입은 장비 교체보다 **트래픽 분류와 지연 요구 정의**가 먼저이며, 스트림 필터링과 시간 동기 보호를 OT 보안 체계에 포함해 망 통합의 위험을 함께 관리할 것
