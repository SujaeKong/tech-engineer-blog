## 1. 뉴스 요약

2026-09-15 현대차그룹이 **레벨2++ 도심 자율주행에 성공**하고 **AI·데이터 선순환 구조**를 완성했다고 밝혔다. 주행 데이터로 AI를 학습·개선하고, 개선된 AI가 다시 더 나은 데이터를 만드는 **선순환**으로 자율주행 완성도를 높이며, 2029년 독자 AI 양산차를 예고했다.

이는 자율주행이 단발 기술을 넘어 **데이터-학습-배포의 지속 순환 시스템**임을 보여준다. 자율주행 데이터 선순환과 컴퓨팅 아키텍처는 정보관리기술사 시스템구조 영역과 직결된다.

## 2. 핵심 개념

### 데이터 선순환(Data Flywheel)
차량이 수집한 **주행 데이터로 AI를 재학습**하고, 개선 모델을 **OTA로 배포**해 성능을 높이는 반복 구조다. 데이터가 많을수록 강해진다.

### 자율주행 시스템 요소

| 요소 | 내용 |
|---|---|
| 인지 | 센서퓨전·환경 인식 |
| 판단 | 경로계획·의사결정 |
| 컴퓨팅 | 차량 고성능 SoC |
| 순환 | 데이터·학습·OTA |

### 자율주행 컴퓨팅 아키텍처 관점
핵심은 **차량 엣지 컴퓨팅과 데이터 선순환의 결합**이다. ① 카메라·레이더·라이다를 센서퓨전으로 인지하고, ② 경로계획·의사결정을 실시간 수행하며, ③ 고성능 차량 SoC(NPU)로 저지연 추론하고, ④ 주행 데이터를 클라우드에서 학습해 OTA로 되먹인다. 안전 직결이라 **기능안전·신뢰성·검증**이 필수다. 관건은 롱테일(희귀상황) 대응, 데이터 인프라·비용, 그리고 독자 AI·칩 내재화다.

## 3. 기술사 출제 포인트

- 자율주행 데이터 선순환(Data Flywheel)과 OTA 되먹임
- 센서퓨전·경로계획과 차량 고성능 SoC(엣지 컴퓨팅)
- 레벨 구분(L2++/L3)과 기능안전·신뢰성 검증
- 롱테일(희귀상황) 대응과 시뮬레이션 학습
- 독자 AI·자율주행 칩 내재화와 데이터 인프라
