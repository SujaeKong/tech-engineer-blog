## 1. 뉴스 요약

건설이코노미뉴스(10-27)는 **공간정보품질관리원이 AI 시대 공간정보 품질 혁신 해법을 찾는다**고 보도했다. 항공사진·위성영상에서 건물·도로를 자동으로 뽑아내는 AI가 늘면서 공간정보 구축 속도는 빨라졌지만, **AI가 만든 데이터의 정확도를 어떻게 보증할 것인가**라는 품질 문제가 새로 생겼다. 같은 배치에서 수원시의 **피지컬 AI 기반 스마트도시 조성**(쿠키뉴스·일간투데이 등, 10-26~28)처럼 공간정보를 기반으로 하는 서비스 소식도 이어졌다. 행사 세부 내용은 제목 이상으로 확인되지 않으므로, 아래에서는 공간정보 품질관리의 표준 틀과 AI 시대의 변화를 정리한다.

## 2. 핵심 개념

### 정의
**공간정보 품질관리**는 지형·건물·도로 등 위치를 가진 데이터가 **실제 세계를 얼마나 정확하고 완전하게, 그리고 최신 상태로 표현하는지**를 정의된 기준으로 측정하고 개선하는 활동이다. 국제표준 **ISO 19157**은 공간정보 품질을 완전성·논리적 일관성·위치 정확도·주제 정확도·시간 품질·사용성의 요소로 정의한다.

### ISO 19157 공간정보 품질 요소

| 품질 요소 | 의미 | 결함 예시 | 측정 예 |
|---|---|---|---|
| 완전성 | 있어야 할 객체가 있는가(누락·과잉) | 신축 건물 누락, 철거 건물 잔존 | 누락률·과잉률 |
| 논리적 일관성 | 데이터 구조·규칙을 지키는가 | 도로선이 끊김, 건물 면이 겹침 | 위상 오류 건수 |
| 위치 정확도 | 좌표가 실제 위치와 맞는가 | 건물 경계가 수 m 어긋남 | 평균제곱근오차(RMSE) |
| 주제 정확도 | 속성·분류가 맞는가 | 주거용을 상업용으로 분류 | 분류 정확도·오분류율 |
| 시간 품질 | 시점 정보가 정확하고 최신인가 | 갱신일 누락, 오래된 데이터 | 갱신 주기 준수율 |
| 사용성 | 목적에 쓸 수 있는가 | 축척이 용도에 맞지 않음 | 요구사항 충족 여부 |

일반 데이터 품질(정확성·완전성·일관성·적시성)과 비교하면, 공간정보에는 **위치 정확도**와 **위상(topology) 일관성**이 추가된다는 점이 특징이다.

### 구성도 — AI 자동 추출 데이터의 품질관리 흐름

```
 [원천]  항공사진 · 위성영상 · 라이다 점군 · 차량 촬영 영상
    │
    ▼
 [AI 자동 추출]  건물·도로·차선 객체 추출 + 신뢰도 점수 부여
    │
    ▼
 [자동 검사]  ─ 위상 규칙: 겹침·틈·끊김 검사
    │         ─ 위치: 기준점 대비 오차 계산
    │         ─ 속성: 필수 값·코드 유효성
    ▼
 [위험 기반 표본 검수]  신뢰도 낮은 객체·변화 많은 지역 우선 사람 검수
    │
    ▼
 [품질 평가·보고]  품질 요소별 지표 산출 → 메타데이터(ISO 19115)에 기록
    │
    ▼
 [배포·피드백]  사용자 오류 신고 → 재학습 데이터로 AI 모델 개선
```

사람이 전량 검수하던 방식에서, **AI 신뢰도 점수와 자동 규칙 검사로 위험한 부분을 골라 사람이 집중 검수**하는 방식으로 바뀌는 것이 AI 시대 품질관리의 핵심 변화다.

### 기존 품질관리 vs AI 시대 품질관리

| 구분 | 기존(수작업 구축) | AI 자동 추출 시대 |
|---|---|---|
| 구축 속도 | 느림(사람이 도화) | 빠름(자동 추출) |
| 오류 유형 | 사람 실수(누락·오기) | 모델 편향(특정 지역·형태에서 체계적 오류) |
| 검수 방식 | 전수 또는 무작위 표본 | 신뢰도·위험 기반 표본 |
| 갱신 주기 | 수년 단위 | 수개월~실시간 |
| 품질 근거 | 작업 규정 준수 | 모델 성능 + 데이터 검사 결과 |
| 추가 관리 대상 | 데이터 | 데이터 + 학습 데이터·모델 버전 |

### 용도별 품질 요구 차이
- **디지털트윈 국토·도시**: 건물·시설의 3D 형태와 속성이 시뮬레이션 결과를 좌우하므로 완전성과 주제 정확도가 중요하다.
- **자율주행 정밀지도**: 차선·표지판의 위치 정확도가 센티미터 수준까지 요구되고, 공사 구간 같은 변화를 빠르게 반영하는 시간 품질이 핵심이다.
- **행정·통계**: 행정구역·주소와의 일치(논리적 일관성)가 중요하다.

### 관련 표준·법
- **ISO 19157-1**: 지리정보 데이터 품질 — 품질 요소·평가 절차
- **ISO 19115**: 지리정보 메타데이터 — 품질 평가 결과를 메타데이터로 기록
- **국가공간정보 기본법**: 국가공간정보의 표준화·품질관리 근거
- **공간정보 구축 작업규정**: 측량·도화 등 구축 단계별 정확도 기준

## 3. 기술사 출제 포인트

- 공간정보 품질의 정의와 ISO 19157 품질 요소
- 완전성(누락·과잉)과 논리적 일관성(위상 오류)
- 위치 정확도 측정(RMSE)과 주제 정확도
- 시간 품질과 갱신 주기 관리
- AI 자동 추출 데이터의 체계적 오류(모델 편향)
- 신뢰도·위험 기반 표본 검수
- ISO 19115 메타데이터에 품질 정보 기록
- 디지털트윈·자율주행 정밀지도의 용도별 품질 요구
- 사용자 오류 신고와 재학습 피드백 루프

## 4. 연결 기출 토픽과 예상 변형

- **데이터 품질관리**: 139회 3교시·140회 2교시에 **AI 학습용 데이터 품질관리**가 연속 출제됐고, 140회 4교시에는 **멀티모달 데이터 품질검증**(TTA 표준 관점)이 나왔다. 공간정보 품질 요소는 같은 품질관리 틀을 공간 데이터에 적용한 변형으로 쓸 수 있다.
- **이상치·편향**: 139회 3교시 **데이터 분석 이상치·편향**이 출제됐다. AI 추출 데이터의 지역별 체계적 오류는 편향의 공간 버전이다.
- **표본추출**: 140회 4교시 **표본추출**(확률·비확률)이 출제됐다. 위험 기반 표본 검수는 층화 표본추출의 실무 적용이다.
- **예상 변형**
  - 1교시: "공간정보 데이터 품질 요소(ISO 19157)를 설명하시오"
  - 1교시: "위상(Topology) 일관성 검사의 개념과 유형을 설명하시오"
  - 논술: "AI 기반 공간정보 자동 구축 환경에서 데이터 품질관리 체계를 제시하시오"

## 5. 답안 구성 예시

**단답형**(1교시, 1페이지)
- 정의: 공간 데이터가 실세계를 정확·완전·최신으로 표현하는지 측정·개선하는 활동(ISO 19157)
- 특징 3개: ① 위치 정확도·위상 일관성 등 공간 고유 품질 요소 ② 메타데이터(ISO 19115)로 품질 공개 ③ 용도별 품질 요구 차등
- 구성도 키워드: 원천 영상 → AI 추출(신뢰도) → 자동 규칙 검사 → 위험 기반 검수 → 품질 평가·메타데이터 → 피드백

**논술형(2~4교시) 목차**
1. 개요: AI 자동 추출 확산과 공간정보 품질 보증 문제
2. 구성/비교: ISO 19157 품질 요소표, AI 품질관리 흐름도, 기존 vs AI 시대 비교표
3. 적용방안: 위상 규칙 자동 검사, 신뢰도 기반 표본 검수, 품질 메타데이터 공개, 사용자 신고-재학습 루프
4. 고려사항: 모델의 지역별 편향, 갱신 주기와 검수 비용의 균형, 학습 데이터·모델 버전 관리
5. 기술사 제언: 데이터만이 아니라 **추출 모델의 버전과 성능까지 품질관리 대상에 포함**하고, 용도별 품질 등급을 정해 같은 데이터라도 쓰임에 맞는 품질 정보를 함께 제공할 것
