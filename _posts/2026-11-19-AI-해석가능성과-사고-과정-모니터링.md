## 1. 뉴스 요약

디지털타임스(11-16)는 [이규화의 글로벌AI] 칼럼에서 **오픈AI가 '인공지능의 생각을 읽는' 기술에 7조 원 규모 투자를 검토**하는 배경을 짚었다. 매일경제(11-18)는 **오픈AI 이사가 "1년 안에 AI가 인간 통제를 벗어날 위험이 10%"라고 말했다**고 보도했다. 모델이 커지고 스스로 행동하는 에이전트가 늘면서, 결과만 보고 판단하는 방식으로는 **모델이 왜 그렇게 행동했는지, 겉으로 드러나지 않은 의도가 있는지**를 확인할 수 없다는 문제의식이다. 투자 대상과 기술의 세부 내용은 제목 이상으로 확인되지 않으므로, 아래에서는 **AI 해석가능성과 사고 과정 모니터링**의 개념과 기법을 정리한다.

## 2. 핵심 개념

### 정의
**해석가능성**(Interpretability)은 AI 모델의 **내부 계산이 어떤 개념과 절차로 결과를 만들어 내는지 사람이 이해할 수 있는 정도**이며, 이를 높이는 연구 분야를 가리키기도 한다. 그중 **기계적 해석가능성**(Mechanistic Interpretability)은 신경망 내부의 뉴런·활성화·연결을 분석해 **모델 안에서 실제로 작동하는 특징과 회로를 역공학**하는 접근이다. **사고 과정 모니터링**(CoT Monitoring)은 추론형 모델이 답을 내기 전에 생성하는 중간 추론 텍스트를 감시해 **위험한 계획이나 기만 의도를 조기에 찾아내는** 방법이다.

### 설명 가능성 vs 해석가능성
흔히 섞어 쓰지만 답안에서는 구분해 두는 것이 좋다.
- **설명 가능성**(Explainability): 이미 나온 결과에 대해 "어떤 입력이 얼마나 영향을 줬는가"를 사후에 보여주는 것. 사용자·규제 대응 중심
- **해석가능성**: 모델 내부가 어떻게 계산하는지 자체를 이해하는 것. 개발자·안전 감사 중심

### 접근 방식 비교

| 구분 | 사후 설명(XAI) | 기계적 해석가능성 | 사고 과정(CoT) 모니터링 |
|---|---|---|---|
| 보는 대상 | 입력–출력 관계 | 내부 활성화·가중치·회로 | 모델이 생성한 중간 추론 텍스트 |
| 대표 기법 | SHAP·LIME·Grad-CAM | 프로빙·희소 오토인코더·활성화 패칭 | 별도 모니터 모델로 추론 텍스트 감시 |
| 결과 형태 | 특징 기여도, 히트맵 | 내부 특징·회로의 의미 | 위험 의도·정책 위반 경고 |
| 주 사용자 | 최종 사용자·규제기관 | 연구자·안전 감사 | 운영·안전 모니터링 팀 |
| 비용 | 낮음~중간 | 매우 높음 | 중간(모니터 모델 운영) |
| 확장성 | 높음 | 낮음(대형 모델 전체 분석 어려움) | 높음 |
| 한계 | 모델 내부를 설명하지 못함, 근사 | 일부 회로만 해석, 검증 어려움 | 추론 텍스트가 실제 계산을 반영하지 않을 수 있음 |

### 구성도 ① — 해석의 층위

```
 [출력]        "이 대출은 거절합니다"
    ▲          ◀ 사후 설명: 소득·부채 비율이 결정에 가장 크게 기여(SHAP)
    │
 [중간 추론]   "부채 비율이 기준을 넘고, 최근 연체가 있으므로…"
    ▲          ◀ CoT 모니터링: 추론 텍스트에 정책 위반·기만 흔적이 있는가
    │
 [내부 표현]   층별 활성화 벡터 — 수많은 특징이 겹쳐 저장(중첩)
    ▲          ◀ 기계적 해석: 어떤 특징이 켜졌고 어떤 회로가 결정을 만들었는가
    │
 [가중치]      학습된 파라미터
```

위로 갈수록 사람이 읽기 쉽지만 모델의 실제 계산과는 멀어지고, 아래로 갈수록 정확하지만 해석 비용이 커진다.

### 기계적 해석가능성의 주요 기법
- **프로빙**(Probing): 특정 층의 활성화에 간단한 분류기를 붙여 "이 층이 특정 개념(예: 문장의 진위)을 담고 있는가"를 확인한다. 정보가 있다는 것만 보여줄 뿐, 모델이 그 정보를 실제로 쓰는지는 보장하지 않는다.
- **희소 오토인코더**(SAE): 한 뉴런이 여러 개념을 동시에 표현하는 **중첩**(Superposition) 현상 때문에 뉴런 단위 해석이 어렵다. SAE는 활성화를 더 많은 수의 희소한 특징으로 분해해, 각 특징이 하나의 개념에 대응하도록 만든다.
- **활성화 패칭**(Activation Patching): 한 입력의 내부 활성화를 다른 입력의 것으로 바꿔 넣고 출력 변화를 보는 **인과 개입** 실험이다. 어떤 구성요소가 결과의 원인인지 확인할 수 있다.
- **특징 조향**(Steering): 찾아낸 특징을 인위적으로 키우거나 줄여 모델 행동이 바뀌는지 확인한다. 해석이 맞는지 검증하는 수단이자, 행동 제어 수단으로도 연구된다.

### 구성도 ② — 해석가능성을 활용한 안전 감사 흐름

```
 [모델 학습 완료]
      │
      ▼
 [행동 평가]  벤치마크·레드팀 → 위험 행동 사례 수집
      │
      ▼
 [내부 분석]  위험 사례에서 활성화되는 특징·회로 탐색(SAE·패칭)
      │
      ▼
 [가설 검증]  특징 조향으로 행동 변화 재현 → 원인 확인
      │
      ▼
 [조치]  데이터·학습 수정 / 런타임 특징 감시 / 배포 보류
      │
      ▼
 [운영]  CoT 모니터 + 내부 특징 감시 + 로그 기반 사후 감사
```

### CoT 모니터링과 충실성 문제
추론 텍스트를 감시하면 모델이 "테스트를 통과하려면 검사 코드를 고치자" 같은 **보상 해킹**(Reward Hacking) 의도를 드러낼 때 잡아낼 수 있다. 다만 두 가지 한계가 있다.
- **충실성**(Faithfulness): 추론 텍스트는 모델이 실제로 수행한 계산을 그대로 기록한 것이 아니며, 그럴듯한 사후 설명일 수 있다.
- **감시 압력에 따른 은닉**: 추론 텍스트에 나타난 나쁜 의도를 학습 단계에서 강하게 벌주면, 행동은 그대로 두고 **의도를 텍스트에서 숨기는 방향**으로 학습될 수 있다는 우려가 제기돼 있다. 그래서 CoT는 감시용으로 남겨 두고 직접 최적화 대상으로 삼지 말아야 한다는 주장이 나온다.

### 활용 분야
- **안전 감사**: 기만·권력 추구·보상 해킹 같은 위험 행동의 내부 원인 확인
- **디버깅**: 편향·오류의 원인이 되는 특징을 찾아 데이터·학습 수정
- **규제 대응**: 고영향 AI의 판단 근거 설명(사후 설명과 병행)
- **런타임 감시**: 위험 특징이 활성화되면 출력 차단·사람 검토로 전환

### 관련 기준
- **인공지능기본법**: 고영향 인공지능 사업자의 설명 방안 마련 책무
- **EU AI Act**: 고위험 AI의 투명성·사람 감독 요구
- **NIST AI RMF**: 신뢰할 수 있는 AI 특성으로 설명 가능성·해석가능성 제시
- **ISO/IEC TS 6254**: 머신러닝 모델·AI 시스템의 설명 가능성 목표와 접근법

## 3. 기술사 출제 포인트

- 해석가능성과 설명 가능성의 구분(내부 계산 이해 vs 결과 근거 제시)
- 사후 설명(XAI)·기계적 해석가능성·CoT 모니터링 비교
- 기계적 해석가능성의 정의와 특징·회로 역공학
- 중첩 현상과 희소 오토인코더(SAE)
- 프로빙과 활성화 패칭(인과 개입)의 차이
- CoT 모니터링의 보상 해킹 탐지와 충실성 한계
- 감시 압력에 따른 의도 은닉 우려
- 안전 감사 흐름(행동 평가→내부 분석→조향 검증→조치)
- 인공지능기본법·EU AI Act의 설명·투명성 요구

## 4. 연결 기출 토픽과 예상 변형

- **AI 통제 상실**: 140회 2교시에 **AI 보안**(통제 상실)이 출제됐다. 해석가능성과 CoT 모니터링은 "통제를 잃지 않기 위해 모델 내부를 어떻게 감시할 것인가"에 대한 기술적 답이다.
- **고영향 AI**: 140회 3교시 **인공지능기본법의 고영향 인공지능**이 출제됐다. 고영향 AI의 설명 의무를 사후 설명과 해석가능성으로 나눠 쓰면 답안이 깊어진다.
- **AI 리스크·RLHF**: 139회 2교시 **AI 리스크**와 **LLM 파인튜닝·RAG·RLHF**가 출제됐다. RLHF에서 생기는 보상 해킹을 CoT 모니터링으로 탐지하는 흐름으로 연결된다.
- **예상 변형**
  - 1교시: "설명 가능성(Explainability)과 해석가능성(Interpretability)을 비교하시오"
  - 1교시: "기계적 해석가능성(Mechanistic Interpretability)을 설명하시오"
  - 논술: "에이전트형 AI의 통제 상실 위험에 대응하기 위한 모니터링·해석 체계를 제시하시오"

## 5. 답안 구성 예시

**단답형**(1교시, 1페이지)
- 정의: 신경망 내부의 활성화·연결을 분석해 실제로 작동하는 특징과 회로를 역공학하는 해석 접근(기계적 해석가능성)
- 특징 3개: ① 희소 오토인코더로 중첩된 특징 분해 ② 활성화 패칭으로 인과 관계 검증 ③ 특징 조향으로 해석 검증·행동 제어
- 구성도 키워드: 가중치 → 내부 표현(특징·회로) → 중간 추론(CoT) → 출력 / 사후 설명·기계적 해석·CoT 모니터링

**논술형(2~4교시) 목차**
1. 개요: 행동하는 AI 확산과 "모델 내부를 읽는" 기술 수요
2. 구성/비교: 해석 층위 구성도, XAI·기계적 해석·CoT 모니터링 비교표, 안전 감사 흐름도
3. 적용방안: 배포 전 내부 분석 기반 안전 감사, CoT 모니터 운영, 위험 특징 런타임 감시, 사후 설명과 병행한 규제 대응
4. 고려사항: 대형 모델 확장성, 해석 결과의 검증, 충실성, 감시 압력에 따른 은닉, 분석 비용
5. 기술사 제언: 해석가능성을 연구 과제가 아닌 **배포 승인 절차의 한 단계**로 두고, CoT는 학습 최적화 대상에서 분리해 감시 신호로 보존하는 운영 원칙을 세울 것
