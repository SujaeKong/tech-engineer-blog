## 1. 뉴스 요약

2026-09-30 정무경 디노티시아 대표가 **"AI 인프라의 새 축을 설계한다"**는 구상을 밝혔다. 생성형 AI가 사내 문서·지식을 활용하려면 방대한 데이터를 **의미 기반으로 빠르게 찾아주는 계층**이 필요하며, 이 **벡터 데이터 처리**가 GPU 연산과 함께 AI 인프라의 한 축이 된다는 관점이다.

이는 데이터베이스의 역할이 정형 데이터 관리를 넘어 **AI의 장기 기억·검색 계층**으로 확장됨을 보여준다. 벡터 데이터베이스는 정보관리기술사 데이터베이스 영역의 새로운 핵심 주제다.

## 2. 핵심 개념

### 벡터 데이터베이스
텍스트·이미지를 **임베딩(고차원 벡터)**으로 바꿔 저장하고, 질의와 **의미가 가까운 벡터**를 찾아준다. 키워드 일치가 아닌 의미 유사도로 검색하는 것이 핵심이다.

### 벡터 검색 요소

| 요소 | 내용 |
|---|---|
| 임베딩 | 데이터를 고차원 벡터화 |
| 거리 | 코사인·내적·유클리드 |
| 색인 | ANN(HNSW·IVF·PQ) |
| 결합 | 메타데이터 필터·하이브리드 |

### 벡터 검색 가속 아키텍처 관점
핵심은 **정확도·속도·메모리의 균형**이다. ① 데이터를 임베딩해 저장하고, ② 전수 비교 대신 **근사 최근접 탐색(ANN)** 색인(HNSW 그래프·IVF 군집·PQ 양자화)으로 속도를 확보하며, ③ 메타데이터 필터와 키워드 검색을 결합(하이브리드)하고, ④ 대규모 벡터는 메모리 대역폭이 병목이라 **전용 하드웨어·분산 처리**로 가속한다. 재현율(recall)과 지연·비용이 트레이드오프다. 관건은 색인 갱신 비용, 권한 기반 필터링, 그리고 임베딩 모델 교체 시 재색인이다.

## 3. 기술사 출제 포인트

- 벡터 데이터베이스와 임베딩 기반 의미 검색 개념
- 유사도 척도(코사인·내적·유클리드)
- ANN 색인 기법(HNSW·IVF·PQ)과 재현율-속도 트레이드오프
- 하이브리드 검색(벡터+키워드)과 메타데이터 필터링
- RAG에서 벡터 DB의 역할과 검색 가속 하드웨어
