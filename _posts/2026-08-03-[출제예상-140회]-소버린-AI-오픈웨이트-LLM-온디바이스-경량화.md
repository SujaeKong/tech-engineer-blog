## 1. 출제 트렌드 분석 (135~139회)

| 회차 | 유형 | 출제 형태 | 관점 |
|------|------|-----------|------|
| 137회 | 관리 단답 | 트랜스포머·MoE | 모델 구조 |

**핵심 인사이트**: 모델 구조·도입(137~139)에서 **국가 AI 주권(Sovereign)과 경량화(온디바이스)**라는 정책·산업 관점으로 확장. IT경영·시스템과 융합되는 논술 유력.

## 2. 개념·정의

### 소버린 AI (Sovereign AI)
> 자국의 데이터·인프라·인재로 **독자적 AI 역량과 통제권**을 확보하는 전략. 데이터 주권·안보·산업경쟁력 관점.

### 오픈웨이트 (Open-Weight) LLM
> 모델 **가중치를 공개**해 자체 파인튜닝·온프레미스 배포가 가능한 모델. 완전 오픈소스와 폐쇄형(API)의 중간.

### 온디바이스 AI / sLLM
> 클라우드 없이 **단말에서 직접 추론**하는 경량 AI. 프라이버시·저지연·오프라인 강점. 소형 언어모델(sLLM)이 핵심.

## 3. 소버린·온디바이스 AI 스택

```
┌──────── 소버린 AI (국가/기업 주권) ────────┐
│ 자국 데이터 · 국산 인프라(GPU/AIDC) · 인재 │
│              │                             │
│        오픈웨이트 파운데이션(공개 가중치)   │
│              │ 파인튜닝/도메인 적응         │
└──────────────┼──────────────────────────────┘
               ▼  경량화(양자화·증류·프루닝)
        ┌──────────────┐
        │   sLLM       │──온디바이스 추론(NPU)
        │ (소형 LLM)   │   프라이버시·저지연·오프라인
        └──────────────┘
```

## 4. 핵심 기술요소

| 요소 | 설명 |
|------|------|
| 오픈웨이트 | 가중치 공개·자체 배포·파인튜닝 |
| 양자화(Quantization) | 정밀도 축소로 모델 경량화 |
| 지식증류(Distillation) | 큰 모델→작은 모델 지식 이전 |
| 프루닝(Pruning) | 불필요 파라미터 제거 |
| 온디바이스 NPU | 단말 가속기 저전력 추론 |
| 도메인 적응 | 자국어·산업 특화 파인튜닝 |

> 🔑 **두음: 오양증프온도** (오픈웨이트·양자화·증류·프루닝·온디바이스·도메인)

## 5. 전략적 쟁점

- **주권 vs 효율**: 독자 개발 비용 vs 글로벌 모델 활용
- **개방 vs 통제**: 오픈웨이트의 혁신·투명성 vs 오남용 위험
- **경량화 트레이드오프**: 크기·속도 ↔ 정확도(양자화 손실)
- **거버넌스**: 데이터 주권·보안·라이선스·국가 AI 정책 정합

## 6. 답안 키워드

- **핵심**: 양자화·증류·프루닝, sLLM·NPU
