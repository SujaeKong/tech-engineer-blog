## 1. 뉴스 요약

프레시안·지디넷코리아(10-30)는 **이진숙 의원이 원전 AI 개발·안전관리 특별법을 대표발의**했다고 보도했다. 프레시안은 법안의 목표로 "**글로벌 원전 AI 시장 선도**"를 소개했고, 에너지안전신문(10-30)은 "**원전 AI 안전규제 새 판 짠다…마지막 통제는 사람**"이라는 제목으로 안전 규제 측면을 다뤘다. AI를 원전 설계·운영에 쓰는 흐름을 산업으로 키우면서도, **최종 판단은 사람이 한다는 원칙**을 법으로 정하려는 시도로 읽힌다. 법안 조문은 제목 이상으로 확인되지 않으므로, 아래에서는 **안전 중요 시스템에 AI를 적용할 때의 구조와 규제 원칙**을 정리한다.

## 2. 핵심 개념

### 정의
**안전 중요 AI**는 오작동 시 인명·환경에 심각한 피해를 줄 수 있는 시스템에 적용되는 AI를 말한다. 원전에서는 **원자로를 안전하게 정지·냉각시키는 안전 계통**과 **발전 운영을 돕는 비안전 계통**을 엄격히 구분하며, AI는 원칙적으로 **운전원 판단을 돕는 조언·진단 역할**에 두고, 안전 계통의 자동 동작은 **검증된 결정론적 로직**이 맡는 구조가 기본이다. "마지막 통제는 사람"이라는 원칙은 이 계층 구분을 법적으로 확인하는 의미가 있다.

### 구성도 — 원전 계통 계층과 AI 적용 위치

```
 ┌──────────────────── 경영·정비 계층 ──────────────────────┐
 │ AI 적극 활용: 설계 최적화 · 정비 계획 · 문서 검색 · 교육   │
 └───────────────────────────┬──────────────────────────────┘
 ┌──────────────────── 운전 지원 계층(비안전) ───────────────┐
 │ AI 조언: 이상 징후 조기 진단 · 예측 정비 · 절차 안내       │
 │          → 운전원에게 제안, 최종 판단은 운전원(HITL)       │
 └───────────────────────────┬──────────────────────────────┘
                 독립성 확보 │ (단방향 정보 전달·물리적 분리)
 ┌──────────────────── 안전 계통 ──────────────────────────┐
 │ 원자로 보호·공학적 안전설비 작동                          │
 │ 검증된 결정론적 로직 · 다중성 · 다양성 · 독립성            │
 │ AI 직접 제어 배제(현재 원칙)                              │
 └─────────────────────────────────────────────────────────┘
```

### 안전 계통 설계 원칙과 AI의 충돌 지점

| 원칙 | 의미 | AI 적용 시 문제 |
|---|---|---|
| 심층방어 | 여러 겹의 독립된 방호 수단 | AI 오류가 여러 방어층에 동시에 영향 줄 위험 |
| 다중성 | 같은 기능을 여러 채널로 구성 | 같은 모델을 복제하면 같은 오류도 복제됨 |
| 다양성 | 서로 다른 원리로 같은 기능 수행 | 학습 기반 모델 간 다양성 입증이 어려움 |
| 독립성 | 계통 간 고장 전파 차단 | 데이터·네트워크 연결이 독립성을 약화 |
| 단일고장기준 | 하나의 고장에도 안전 기능 유지 | 모델 결함은 모든 채널의 공통원인고장 가능 |
| 결정론적 동작 | 같은 입력에 같은 출력 | 확률적 출력·학습 후 변화로 예측성 저하 |
| 검증 가능성 | 모든 경우의 동작을 확인 | 신경망 내부 논리의 완전한 검증 곤란 |

이 표가 "왜 AI를 안전 계통에 바로 넣지 못하는가"에 대한 답이다. 특히 **공통원인고장**(CCF), 즉 같은 모델·데이터에 기반한 여러 채널이 같은 상황에서 동시에 틀리는 위험이 핵심 쟁점이다.

### 원전 AI 적용 영역별 위험 수준

| 영역 | 예시 | 위험 | 통제 |
|---|---|---|---|
| 설계·해석 | 노심 설계 최적화, 해석 가속 | 중간 | 기존 검증 코드로 결과 교차 확인 |
| 정비·예측 진단 | 펌프·밸브 고장 예측 | 낮음~중간 | 정비 결정은 사람, 예측 근거 기록 |
| 운전 지원 | 이상 징후 경보, 절차 안내 | 중간~높음 | 운전원 최종 판단, 오경보 관리 |
| 안전 계통 제어 | 자동 정지·안전설비 작동 | 매우 높음 | 현재 원칙상 배제, 장기 연구 대상 |

### 관련 표준·기준
- **IEC 61513**: 원전 계측제어 계통의 일반 요구사항(안전 등급 분류 체계)
- **IEC 60880 / IEC 62138**: 안전 등급별 원전 소프트웨어 요구사항(최상위 등급 / 하위 등급)
- **IEEE 7-4.3.2**: 원전 안전 계통 디지털 컴퓨터 요구사항
- **원자력안전법**: 원전 설계·운영 인허가와 안전 규제 근거
- **인공지능기본법**: 국민 생명·안전에 중대한 영향을 미치는 영역의 AI를 고영향 AI로 규율하며, 사람의 관리·감독 등 사업자 책무를 둔다

## 3. 기술사 출제 포인트

- 안전 중요 AI의 정의와 원전 계통 계층(안전·비안전)
- AI의 조언·진단 역할과 안전 계통 결정론적 로직의 분리
- 심층방어·다중성·다양성·독립성 원칙
- 공통원인고장(CCF)과 동일 모델 복제의 위험
- 확률적 출력과 결정론적 동작 요구의 충돌
- 신경망의 검증 가능성 한계와 교차 검증
- 영역별 위험 수준에 따른 차등 통제
- 운전원 최종 판단(HITL)과 오경보 관리
- IEC 61513·60880·62138, IEEE 7-4.3.2 등 원전 SW 표준

## 4. 연결 기출 토픽과 예상 변형

- **AI 통제 상실**: 140회 2교시 **AI 보안 — 자율성으로 인한 통제 상실 위협 및 대응**이 출제됐다. "마지막 통제는 사람"은 이 문항의 대응 방안 단락을 원전이라는 극단적 안전 영역에 적용한 사례다.
- **고영향 AI**: 140회 3교시 **인공지능기본법의 고영향 인공지능**이 출제됐다. 원전 AI는 고영향 AI 영역의 대표 사례로, 특별법과 기본법의 관계를 묻는 변형이 가능하다.
- **피지컬 AI**: 140회 1교시 **Physical AI와 생성형 AI 비교**가 출제됐다. 물리 세계에 영향을 주는 AI일수록 검증 요구가 커진다는 논점과 이어진다.
- **예상 변형**
  - 1교시: "안전 중요 시스템(Safety-Critical System)에 AI 적용 시 고려사항을 설명하시오"
  - 1교시: "공통원인고장(Common Cause Failure)과 다양성(Diversity) 설계를 설명하시오"
  - 논술: "원자력·의료 등 고위험 분야 AI의 안전 확보 체계를 기술·제도 관점에서 논하시오"

## 5. 답안 구성 예시

**단답형**(1교시, 1페이지)
- 정의: 오작동 시 중대 피해를 줄 수 있는 시스템에 적용되는 AI, 원전은 안전 계통과 운전 지원 계층을 분리
- 특징 3개: ① AI는 조언·진단, 안전 계통은 결정론적 로직 ② 다중성·다양성·독립성 원칙 적용 ③ 운전원 최종 판단
- 구성도 키워드: 경영·정비(AI 활용) → 운전 지원(AI 조언·HITL) → 독립성 경계 → 안전 계통(결정론적·AI 배제)

**논술형(2~4교시) 목차**
1. 개요: 원전 AI 산업화 추진과 안전 규제 정비 필요성
2. 구성/비교: 계통 계층 구성도, 설계 원칙-AI 충돌표, 영역별 위험표
3. 적용방안: 영역별 차등 규제, 비안전 계층 우선 적용, 교차 검증, 오경보 관리, 사람 최종 판단 명문화
4. 고려사항: 공통원인고장, 검증 가능성, 학습 후 변화 관리, 사이버보안(계통 연결 확대)
5. 기술사 제언: 산업 진흥과 안전 규제를 한 법에 담더라도 **안전 계통 적용은 별도의 엄격한 인허가 경로**로 분리하고, 비안전 영역에서 실증 데이터를 쌓아 단계적으로 범위를 넓힐 것
