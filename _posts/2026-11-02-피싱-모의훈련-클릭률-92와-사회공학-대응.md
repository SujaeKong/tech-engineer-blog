## 1. 뉴스 요약

산업일보(10-31)는 **위생 점검을 위장한 모의 피싱 메일의 클릭률이 92%에 달했고, AI 기술 안내를 가장한 메일에도 취약했다**고 보도했다. 업무와 관련된 그럴듯한 핑계가 붙으면 대부분이 링크를 누른다는 결과다. 같은 날 지디넷코리아(10-31)는 [보안칼럼] "**인간중심 사이버보안의 몰락**"을, 비즈니스포스트(10-31)는 **한국 금융권을 덮친 'AI 해킹' 불안감이 전 세계로 확산**되고 있다고 전했다. 훈련 대상과 규모는 제목 이상으로 확인되지 않으므로, 아래에서는 **사회공학 공격의 구조와 기술·절차·사람 3계층 대응**을 정리한다.

## 2. 핵심 개념

### 정의
**사회공학**(Social Engineering)은 기술적 취약점 대신 **사람의 신뢰·호기심·긴급함·권위에 대한 복종 같은 심리를 이용해** 정보를 빼내거나 원하는 행동을 하게 만드는 공격이다. **피싱**은 그 대표 수단으로, 정상 기관이나 업무 연락을 가장한 메시지로 링크 클릭·첨부 실행·계정 입력을 유도한다. **모의훈련**은 실제와 비슷한 가짜 피싱을 보내 조직의 취약 수준을 측정하고 대응 습관을 기르는 활동이다.

### 사회공학 공격 유형

| 유형 | 수단 | 특징 | 예시 |
|---|---|---|---|
| 피싱 | 대량 이메일 | 불특정 다수, 낮은 정교도 | 택배·결제 안내 위장 |
| 스피어피싱 | 맞춤 이메일 | 특정 조직·개인 정보 활용 | 거래처 담당자 이름으로 견적서 |
| 웨일링 | 맞춤 이메일 | 경영진 표적 | 이사회 자료 위장 |
| BEC(업무 이메일 침해) | 이메일 | 송금·결제 변경 유도 | "계좌가 바뀌었습니다" |
| 스미싱 | 문자 | 모바일 링크 클릭 유도 | 과태료·택배 문자 |
| 비싱 | 전화·음성 | 실시간 대화로 압박 | 수사기관·은행 사칭, 딥보이스 |
| 프리텍스팅 | 각종 수단 | 그럴듯한 상황 설정 | 위생 점검·감사 일정 안내 |

이번 훈련의 "위생 점검 위장"은 **프리텍스팅이 결합된 스피어피싱**의 전형이다. 업무 일정과 관련된 내용일수록 의심이 줄어든다.

### AI가 바꾼 피싱

| 구분 | 과거 피싱 | AI 고도화 피싱 |
|---|---|---|
| 문장 품질 | 어색한 번역투, 오탈자 | 자연스러운 한국어, 업무 문체 |
| 맞춤화 | 대량 동일 문안 | 대상별 맞춤 문안 대량 생성 |
| 정보 수집 | 수작업 | 공개 정보 자동 수집·요약 |
| 음성·영상 | 어려움 | 딥보이스·딥페이크로 경영진 사칭 |
| 탐지 단서 | 문법 오류로 식별 가능 | 문장 품질로는 식별 불가 |

"오탈자가 있으면 의심하라"는 기존 교육 포인트는 더 이상 통하지 않는다. 판단 기준을 **문장 품질에서 요청 내용과 경로**(이 요청이 평소 절차와 맞는가)로 바꿔야 한다.

### 구성도 — 3계층 대응 구조

```
 [공격 메일 도착]
       │
       ▼
 ┌─ 기술 계층 ─────────────────────────────────────────────┐
 │ 메일 인증(SPF·DKIM·DMARC)으로 발신 위조 차단             │
 │ 첨부 샌드박스·URL 재검사 · 외부 메일 경고 배너            │
 └───────────────┬─────────────────────────────────────────┘
                 │ 걸러지지 않은 메일
                 ▼
 ┌─ 사람 계층 ─────────────────────────────────────────────┐
 │ 의심 메일 원클릭 신고 → 보안팀 즉시 분석 → 전사 차단       │
 │ 정기 모의훈련 · 상황별 교육(BEC·비싱)                     │
 └───────────────┬─────────────────────────────────────────┘
                 │ 클릭·입력이 일어나도
                 ▼
 ┌─ 절차·피해 최소화 계층 ──────────────────────────────────┐
 │ 피싱 저항 인증(FIDO2 보안키·패스키)으로 계정 탈취 무력화   │
 │ 송금·계좌 변경은 별도 채널로 이중 확인 · 최소 권한          │
 └─────────────────────────────────────────────────────────┘
```

어느 한 계층도 완벽하지 않다는 전제에서 설계한다. 클릭률을 0으로 만드는 것은 불가능하므로, **클릭이 일어나도 피해가 생기지 않게** 만드는 마지막 계층이 특히 중요하다.

### 모의훈련 지표 설계

| 지표 | 의미 | 해석 |
|---|---|---|
| 열람률 | 메일을 연 비율 | 참고 지표 |
| 클릭률 | 링크를 누른 비율 | 낮을수록 좋음 |
| 정보 입력률 | 가짜 로그인 페이지에 계정 입력 비율 | 실제 피해와 가장 가까움 |
| 신고율 | 의심 메일을 보안팀에 신고한 비율 | 높을수록 좋음, 조직 방어력의 핵심 |
| 신고 소요 시간 | 첫 신고까지 걸린 시간 | 짧을수록 전사 차단이 빠름 |

클릭률만 보면 훈련이 "적발과 망신"이 되기 쉽다. 신고율과 신고 소요 시간을 함께 관리하면, 직원이 **조직 방어의 탐지 센서** 역할을 하도록 문화를 바꿀 수 있다.

### 관련 표준·기준
- **SPF(RFC 7208)·DKIM(RFC 6376)·DMARC(RFC 7489)**: 발신 도메인 위조 방지 메일 인증 체계
- **FIDO2/WebAuthn**: 도메인에 묶인 공개키 인증으로 가짜 사이트에서는 인증이 성립하지 않는 피싱 저항 인증
- **NIST SP 800-50**: 사이버보안·개인정보 학습 프로그램 구축 지침
- **ISMS-P**: 인적 보안(교육·훈련) 통제 항목

## 3. 기술사 출제 포인트

- 사회공학의 정의와 심리적 원리(신뢰·긴급함·권위)
- 피싱·스피어피싱·웨일링·BEC·스미싱·비싱·프리텍스팅 비교
- AI로 고도화된 피싱의 특징과 기존 탐지 단서의 무력화
- 기술·사람·절차 3계층 대응 구조
- SPF·DKIM·DMARC 메일 인증
- FIDO2·패스키 등 피싱 저항 인증
- 모의훈련 지표(클릭률·정보 입력률·신고율·신고 시간)
- 송금·계좌 변경의 별도 채널 이중 확인
- 비난이 아닌 신고 중심의 보안 문화

## 4. 연결 기출 토픽과 예상 변형

- **AI 기반 공격**: 140회 2교시 **AI 보안 — 고도화된 사이버공격 지원 위협**이 출제됐다. AI가 피싱 문안을 맞춤 생성하는 것은 이 문항의 가장 구체적인 사례다.
- **위협 노출 관리**: 139회 1교시 **CTEM**(지속적 위협 노출 관리)이 출제됐다. 사람의 취약성도 노출 면(Attack Surface)의 일부로, 모의훈련은 이를 측정·검증하는 활동이다.
- **포렌식**: 140회 1교시 **디지털 포렌식**이 출제됐다. 피싱으로 시작된 침해사고에서 메일 헤더·접속 기록 분석이 첫 단계가 된다.
- **예상 변형**
  - 1교시: "사회공학(Social Engineering) 공격 유형과 대응 방안을 설명하시오"
  - 1교시: "DMARC의 동작 원리를 SPF·DKIM과 연계해 설명하시오"
  - 논술: "생성형 AI 시대 피싱 공격의 변화와 조직의 기술·관리·인적 대응 체계를 제시하시오"

## 5. 답안 구성 예시

**단답형**(1교시, 1페이지)
- 정의: 사람의 심리를 이용해 정보 탈취·행동을 유도하는 공격, 피싱이 대표 수단
- 특징 3개: ① 프리텍스팅 결합으로 높은 성공률 ② AI로 문장 품질·맞춤화 고도화 ③ 기술·사람·절차 다층 대응 필요
- 구성도 키워드: 메일 인증·샌드박스(기술) → 신고·훈련(사람) → 피싱 저항 인증·이중 확인(절차)

**논술형(2~4교시) 목차**
1. 개요: 모의 피싱 클릭률 92%와 AI 고도화 피싱의 위험
2. 구성/비교: 공격 유형표, 과거 vs AI 피싱 비교표, 3계층 대응 구성도, 훈련 지표표
3. 적용방안: DMARC 정책 강화, 피싱 저항 인증 도입, 원클릭 신고·자동 차단, 신고율 중심 훈련, 송금 이중 확인
4. 고려사항: 훈련의 형식화·직원 반감, 개인정보(훈련 결과) 관리, 협력사·외주 인력 포함 여부
5. 기술사 제언: 사람을 "가장 약한 고리"가 아니라 **탐지 센서**로 보고 신고율을 핵심 지표로 삼되, 클릭이 일어나도 피해가 없도록 피싱 저항 인증을 우선 도입할 것
