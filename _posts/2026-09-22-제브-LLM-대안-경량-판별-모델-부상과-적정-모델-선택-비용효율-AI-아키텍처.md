## 1. 뉴스 요약

2026-09-22 **"LLM을 꼭 써야 하나"**는 문제 제기와 함께, 생성 없이 **판단(분류)만 수행하는 경량 모델 '제브'가 LLM 대비 194배 빠른 속도**를 냈다는 결과가 주목받고 있다. 모든 과제에 거대 모델을 쓰는 관행이 **비용·지연 낭비**를 낳는다는 지적이다.

이는 AI 시스템 설계에서 **과제에 맞는 적정 모델 선택**이 핵심 역량임을 보여준다. 모델 선택과 비용효율 설계는 정보관리기술사 소프트웨어공학 영역과 직결된다.

## 2. 핵심 개념

### 생성 vs 판별
**생성 모델(LLM)**은 자유로운 텍스트를 만들지만 무겁다. **판별 모델**은 분류·점수화만 하므로 훨씬 가볍고 빠르며, 정해진 판단 과제에는 충분하다.

### 모델 선택 기준

| 기준 | 내용 |
|---|---|
| 과제 | 생성 필요 vs 판단 충분 |
| 성능 | 정확도·지연(레이턴시) |
| 비용 | 토큰·연산·운영비 |
| 운영 | 예측가능성·재현성 |

### 비용효율 AI 아키텍처 관점
핵심은 **과잉 설계를 피한 적정 기술 선택**이다. ① 과제가 생성이 필요한지 판단으로 충분한지 먼저 구분하고, ② 분류·라우팅 등은 경량 모델로 처리하며, ③ 복잡한 요청만 LLM으로 넘기는 **계층적 라우팅(cascade)**을 두고, ④ 캐싱·배치로 호출을 줄인다. 경량 모델은 **지연·비용·재현성** 면에서 유리하다. 관건은 과제 정의의 정확성, 품질-비용 균형, 그리고 모델 교체 가능한 추상화 설계다.

## 3. 기술사 출제 포인트

- 생성 모델(LLM)과 판별(분류) 모델의 차이와 선택 기준
- 적정 기술 선택과 과잉 설계(over-engineering) 회피
- 계층적 라우팅(cascade)과 복잡도 기반 모델 분기
- 추론 비용·레이턴시 최적화(캐싱·배치)
- 모델 추상화·교체 가능성과 벤더 종속 회피
