## 1. 뉴스 요약

2026-07-05 한국경제 등은 **특허청 산하 지식재산 당국(지재처)이 'AI 모델 증류(Distillation)'에 대한 규제 검토에 착수**해 한국의 'AI 3강' 도약에 변수가 될 수 있다고 보도했다. 같은 시기 네이버도 **"작지만 똑똑한 모델(sLLM)로 비용을 효율화"**하는 서비스 특화 전략을 공개했다. 두 뉴스는 공통적으로 **지식 증류가 소형·저비용 AI의 핵심 기술로 부상**했음을 보여준다.

지식 증류는 대형 모델의 능력을 소형 모델로 이전하는 대표적 **모델 경량화 기법**이다. 규제 논의가 불거질 만큼 산업적 파급력이 커진 만큼, 기법 자체의 이해가 중요하다. (증류를 통한 모델 탈취·지식재산 침해 등 보안 관점은 별도 토픽에서 다룬다.) 정보관리기술사 AI데이터분석 영역의 모델 압축·추론 최적화·데이터 효율 전략과 직결된다.

## 2. 핵심 개념

### 지식 증류(Knowledge Distillation)의 원리
지식 증류는 성능이 높은 **교사 모델(Teacher)**의 출력을 **학생 모델(Student)**이 모방하도록 학습시키는 기법이다. 정답 레이블(hard label)만 쓰지 않고, 교사가 출력한 **확률 분포(soft label)** 를 함께 학습해 "정답 사이의 관계"라는 풍부한 신호(dark knowledge)를 전달한다. 그 결과 학생 모델은 훨씬 작은 크기로도 교사에 근접한 성능을 낸다.

### 모델 경량화 기법 비교
소형·저비용 모델을 만드는 방식은 여러 가지이며, 목적에 따라 조합한다.

| 기법 | 방식 | 특징 |
|---|---|---|
| 지식 증류 | 교사→학생 지식 이전 | 성능 유지력 높음, 교사 필요 |
| 양자화 | 가중치 비트수 축소 | 메모리↓, 정밀도 손실 관리 |
| 가지치기 | 불필요 연결 제거 | 희소화, 하드웨어 지원 필요 |
| LoRA/어댑터 | 일부 파라미터만 학습 | 미세조정 비용↓ |

### sLLM과 비용효율·데이터 전략
증류로 만든 **sLLM(소형 언어모델)**은 추론 비용과 지연을 크게 낮춰 **온디바이스·서비스 특화** 배치에 적합하다. 성공의 관건은 **데이터**다. 교사 모델의 응답을 어떤 도메인·난이도로 샘플링해 증류 데이터셋을 구성하느냐가 학생 성능을 좌우한다. 다만 타사 모델 출력을 무단 증류하면 **라이선스·지식재산 분쟁**이 생길 수 있어, 데이터 출처와 이용약관 준수가 거버넌스 요건이 된다.

## 3. 기술사 출제 포인트

- 지식 증류의 원리(교사-학생, soft label, dark knowledge)와 필요성
- 모델 경량화 기법(증류·양자화·가지치기·어댑터) 비교와 조합 전략
- sLLM의 비용효율·지연·온디바이스 배치 관점의 장단점
- 증류 데이터셋 구성이 학생 모델 품질에 미치는 영향과 데이터 전략
- 모델 증류의 지식재산·라이선스 이슈와 데이터 거버넌스 고려사항
