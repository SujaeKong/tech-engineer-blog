## 1. 뉴스 요약

2026-08-07 성신여대가 **국가공인 SQLD(SQL 개발자) 자격 취득 과정**을 무상 개설한다고 밝혔다. "비전공자도 AI·데이터 전문가로" 키우겠다는 취지로, AI 시대의 기초 역량인 **데이터 모델링과 SQL 활용** 능력을 갖추게 하는 것이 목표다.

이는 AI·데이터 활용의 밑바탕에 여전히 **정형 데이터(관계형 DB)와 SQL**이 있다는 점을 보여준다. 데이터 모델링·SQL·트랜잭션은 정보관리기술사 데이터베이스 영역의 핵심 기본기다.

## 2. 핵심 개념

### 데이터 모델링(개념-논리-물리)
데이터 모델링은 현실 세계의 데이터를 구조화하는 과정으로 **개념→논리→물리** 단계로 진행한다. 개념 모델(엔터티·관계), 논리 모델(정규화·키), 물리 모델(테이블·인덱스·타입)로 구체화된다.

### 관계형 DB 핵심 요소

| 요소 | 내용 |
|---|---|
| 정규화 | 이상현상 제거·중복 최소화(1~BCNF) |
| 키 | 기본키·외래키·후보키로 무결성 보장 |
| 무결성 | 개체·참조·도메인 무결성 |
| 인덱스 | 검색 성능(B-tree)·트레이드오프 |
| 트랜잭션 | ACID·동시성 제어·격리수준 |

### SQL과 성능
SQL은 DDL(정의)·DML(조작)·DCL(제어)로 구성된다. 실무의 관건은 **옵티마이저가 효율적 실행계획**을 세우도록 하는 것으로, 인덱스 설계·조인 방식·통계정보가 성능을 좌우한다. 정규화(무결성)와 반정규화(성능)의 **균형**, 그리고 대용량·분석 환경에서의 파티셔닝·컬럼스토어 활용이 중요하다.

## 3. 기술사 출제 포인트

- 데이터 모델링 단계(개념·논리·물리)와 산출물
- 정규화(1NF~BCNF)와 이상현상, 반정규화의 트레이드오프
- 무결성(개체·참조·도메인)과 키 개념
- 트랜잭션 ACID·동시성 제어·격리수준
- SQL 성능(옵티마이저·인덱스·실행계획)과 대용량 처리
