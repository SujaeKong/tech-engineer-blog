## 1. 뉴스 요약

2026-06-03 마이크로소프트는 자사 2세대 데이터센터용 Arm 기반 서버 프로세서 **"Azure Cobalt 200"**을 공개했다. 핵심은 ① 1세대 **Cobalt 100** 대비 **데이터베이스(DB) 처리 성능을 최대 135% 향상**시켰다고 밝힌 점, ② x86(인텔·AMD) 중심이던 하이퍼스케일 데이터센터에 **자체 설계 Arm SoC**를 본격 투입해 **클라우드 비용 구조(TCO)를 재편**하려 한다는 점, ③ 범용 컴퓨팅·웹서비스·DB·캐시 등 **스케일아웃 워크로드**에 최적화된 멀티코어·고대역폭 메모리 구조를 채택했다는 점이다.

이는 아마존(Graviton), 구글(Axion), 엔비디아(Grace)에 이은 **클라우드 사업자의 자체 칩(in-house silicon) 경쟁** 가속을 의미한다. 빅테크가 CPU·NPU·DPU를 직접 설계하는 흐름은 **성능당 전력(Perf/Watt)**과 **총소유비용** 최적화, 그리고 **공급망 종속 탈피**라는 시스템 아키텍처 차원의 전략 변화다. 기술사 시스템구조 영역에서 **프로세서 아키텍처(RISC/CISC), 메모리 계층, 데이터센터 전력·냉각, 클라우드 자원 효율화**와 직결되는 시의성 높은 주제다.

## 2. 핵심 개념

### Arm 서버 CPU가 부상하는 이유

기존 데이터센터 CPU는 x86(CISC) 계열이 지배했으나, 클라우드 워크로드가 **다수의 경량 요청을 병렬 처리하는 스케일아웃** 형태로 바뀌면서 **코어 수·전력 효율·메모리 대역폭**이 단일 코어 최고 성능보다 중요해졌다. Arm(RISC) 기반 설계는 명령어 집합이 단순해 **코어를 조밀하게 집적**하고 **전력당 처리량**을 높이기 유리하다.

### CISC(x86) vs RISC(Arm 서버) 비교

| 항목 | x86 (CISC) | Arm 서버 (RISC) |
|---|---|---|
| 명령어 집합 | 복잡·가변길이 | 단순·고정길이 |
| 설계 지향 | 단일코어 고성능 | 다코어 고효율 |
| 전력당 성능 | 상대적으로 낮음 | 높음(Perf/Watt 우위) |
| 코어 집적도 | 낮음 | 높음 |
| 생태계 성숙도 | 매우 높음(레거시 호환) | 확대 중(재컴파일 필요) |
| 대표 제품 | Xeon, EPYC | Graviton, Axion, Cobalt |

### 자체 설계 칩(In-house Silicon)의 시스템 효과

- **수직 통합**: 클라우드 사업자가 워크로드 특성을 알고 칩을 맞춤 설계해 **하드웨어-소프트웨어 공동 최적화** 달성
- **TCO 절감**: 라이선스 비용·전력·랙 밀도를 함께 개선해 단위 연산 비용 하락
- **메모리 대역폭 중심 설계**: DB·인메모리 캐시 워크로드는 연산보다 메모리 병목이 크므로, 고대역폭 메모리·대용량 캐시가 성능을 좌우(135% 향상의 핵심 동인)

## 3. 기술사 출제 포인트

- **개념 정의와 필요성**: 클라우드 자체 설계 서버 CPU의 정의, 등장 배경(스케일아웃 워크로드, 전력·비용 한계)
- **CISC와 RISC 아키텍처 비교**: 명령어 집합, 파이프라인, 전력당 성능, 코어 집적도 관점의 차이
- **데이터센터 효율 지표**: Perf/Watt, 랙 밀도, PUE(전력사용효율), TCO 구성요소와 산정 관점
- **메모리 계층과 병목**: 캐시·메모리 대역폭이 DB 성능에 미치는 영향, 메모리 중심 컴퓨팅
- **도입 시 고려사항**: 기존 x86 바이너리 호환성·재컴파일, 마이그레이션 비용, 멀티아키텍처 운영(컨테이너 이미지 멀티아키 빌드)
- **하드웨어-소프트웨어 공동 최적화**: 수직 통합이 가용성·확장성에 주는 영향
