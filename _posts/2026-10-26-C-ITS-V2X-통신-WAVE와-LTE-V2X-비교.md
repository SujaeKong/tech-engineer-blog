## 1. 뉴스 요약

지디넷코리아(10-23)는 **카카오모빌리티가 강릉 ITS 세계총회에서 AI 주차 기술을 공개**했다고 보도했다. 세계일보(10-24)·대한경제(10-23)는 **SK에코플랜트가 용인 백암초등학교 앞에 'AI 스마트 횡단보도'를 설치**했다고 전했다. 두 기사 모두 지능형 교통체계(ITS)의 현장 적용 사례지만, 차량 통신 방식 자체를 다룬 것은 아니며 세부 내용도 제목 이상으로 확인되지 않는다. 이 글은 ITS 세계총회를 계기로, ITS가 협력형으로 진화할 때 핵심 기반이 되는 **C-ITS의 V2X 통신**을 깊게 다루는 **토픽 심화 글**이다.

## 2. 핵심 개념

### 정의
**C-ITS**(Cooperative ITS, 협력형 지능형 교통체계)는 차량이 주변 차량·도로 인프라·보행자와 **실시간으로 정보를 주고받아** 사고 위험을 미리 알리고 교통 흐름을 개선하는 체계다. 이를 가능하게 하는 통신이 **V2X**(Vehicle-to-Everything)이며, 대표 기술로 무선랜 기반 **WAVE**(IEEE 802.11p)와 이동통신 기반 **C-V2X**(LTE-V2X, NR-V2X)가 있다.

### V2X 통신 유형

| 유형 | 통신 대상 | 대표 서비스 |
|---|---|---|
| V2V | 차량 ↔ 차량 | 전방 급정거 경고, 교차로 충돌 방지 |
| V2I | 차량 ↔ 도로 인프라(RSU·신호기) | 신호 정보 제공, 도로 위험 구간 알림 |
| V2P | 차량 ↔ 보행자 단말 | 보행자 접근 경고 |
| V2N | 차량 ↔ 이동통신망·서버 | 실시간 교통정보, 원격 업데이트 |

### 구성도 — C-ITS 통신 구조

```
               ┌──────────── 센터 / 클라우드 ────────────┐
               │ 교통관제 · 정보 융합 · 보안인증(SCMS)   │
               └───────▲──────────────────────▲──────────┘
                       │ Uu(기지국 경유)        │ 유선 백홀
                       │                        │
    ┌─────────┐   PC5 직접통신   ┌─────────┐  ┌─┴───────┐
    │ 차량 A  │◀────────────────▶│ 차량 B  │  │  RSU    │ (노변 기지국)
    │ (OBU)   │                  │ (OBU)   │◀▶│ 신호정보 │
    └────┬────┘                  └─────────┘  └─────────┘
         │ PC5
         ▼
    [보행자 단말]   ※ 안전 메시지는 기지국을 거치지 않는 직접통신이 원칙
```

- **PC5**(사이드링크): 단말 간 직접 통신. 기지국 없이도 동작해 지연이 짧고 커버리지 밖에서도 쓸 수 있다.
- **Uu**: 기지국을 경유하는 일반 이동통신 링크. 넓은 범위의 정보 전달(V2N)에 적합하다.

### WAVE vs LTE-V2X vs NR-V2X

| 구분 | WAVE (DSRC) | LTE-V2X | NR-V2X |
|---|---|---|---|
| 기반 기술 | 무선랜(IEEE 802.11p) | 4G LTE(3GPP Rel-14) | 5G NR(3GPP Rel-16) |
| 상위 계층 표준 | IEEE 1609 계열 | 3GPP + 응용 메시지 표준 | 3GPP + 응용 메시지 표준 |
| 직접 통신 | O | O(PC5) | O(PC5) |
| 망 연동 | 별도 인프라(RSU) 필요 | 이동통신망 활용 가능(Uu) | 이동통신망 활용 가능(Uu) |
| 매체 접근(MAC) | CSMA/CA(경쟁 기반) | 센싱 기반 반영구 스케줄링 | 반영구·동적 스케줄링 |
| 혼잡 시 특성 | 충돌·지연 증가, 숨은 노드 문제 | 자원 예약으로 충돌 완화 | 고신뢰·저지연 강화 |
| 주요 용도 | 기본 안전 메시지 | 기본 안전 메시지 | 군집주행·센서 공유 등 고도화 서비스 |
| 진화 경로 | 802.11bd로 개선 | NR-V2X와 공존·진화 | 자율주행 협력 서비스 |

### MAC 계층 차이가 중요한 이유
- **CSMA/CA**: 채널이 비어 있으면 임의 대기 후 전송한다. 차량이 적을 때는 효율적이지만, 교차로처럼 차량이 몰리면 **충돌과 재전송**이 늘고, 서로 보이지 않는 차량끼리 동시에 보내는 **숨은 노드 문제**가 생긴다. 방송형 안전 메시지는 수신 확인(ACK)이 없어 충돌이 나도 재전송되지 않는다.
- **센싱 기반 반영구 스케줄링**(SPS): 안전 메시지는 일정 주기로 반복되므로, 단말이 주변 사용 자원을 감지한 뒤 **빈 자원을 일정 기간 예약**해 쓴다. 주기적 트래픽에서 충돌을 줄이는 방식이다.

### V2X 보안·프라이버시
- **메시지 서명**: 모든 안전 메시지에 전자서명을 붙여 위조 차량의 거짓 경고를 막는다(IEEE 1609.2 보안 서비스).
- **SCMS**(Security Credential Management System): V2X 인증서를 발급·폐기하는 PKI 체계
- **가명 인증서**: 인증서를 주기적으로 바꿔 차량 위치 추적을 어렵게 한다. 인증과 익명성을 함께 만족시키는 장치다.

### 관련 표준·정책
- **IEEE 802.11p / IEEE 1609**: WAVE 물리·MAC 계층 / 상위 계층·보안
- **3GPP Rel-14 · Rel-16**: LTE-V2X · NR-V2X 규격
- **국내 C-ITS 통신 방식**: 정부가 2023년 **LTE-V2X 단일 방식**으로 결정
- **주파수**: 5.9GHz 대역을 ITS용으로 사용(미국은 2020년 이 대역 일부를 C-V2X용으로 재배치)

## 3. 기술사 출제 포인트

- C-ITS의 정의와 V2X 통신 유형(V2V·V2I·V2P·V2N)
- WAVE(IEEE 802.11p)와 LTE-V2X·NR-V2X 비교
- PC5 직접통신과 Uu 망 경유 통신의 차이
- CSMA/CA와 센싱 기반 반영구 스케줄링(SPS) 비교
- 혼잡 환경의 숨은 노드 문제와 방송형 메시지의 한계
- V2X 메시지 서명과 SCMS 인증체계
- 가명 인증서를 통한 위치 프라이버시 보호
- 국내 C-ITS 통신 방식 LTE-V2X 단일화 결정
- NR-V2X 기반 자율주행 협력 서비스(군집주행·센서 공유)

## 4. 연결 기출 토픽과 예상 변형

- **매체 접근 제어**: 140회 3교시에 **CSMA/CA·CDMA·TDMA**가 출제됐다. WAVE의 CSMA/CA와 C-V2X의 자원 예약 방식을 비교하면, 같은 개념을 차량 통신에 적용한 응용 문항으로 연결된다.
- **5G**: 블로그 통합 기출 분석(`exam_trend_integrated.json`) 기준 **5G는 기출 13회**로 네트워크 최빈출 키워드다. NR-V2X는 5G의 대표 응용(초저지연·고신뢰) 사례로 쓸 수 있다.
- **자율주행**: 같은 분석 기준 **자율주행은 기출 8회**다. 센서만으로 보이지 않는 위험을 통신으로 보완하는 "협력형 자율주행"은 자율주행 문항의 확장 논점이다.
- **QoS·스케줄링**: 140회 2교시 **FIFO vs WFQ**처럼 큐잉·스케줄링 기본기 문항도 꾸준하다. 안전 메시지 우선 전송은 우선순위 스케줄링의 사례가 된다.
- **예상 변형**
  - 1교시: "V2X 통신의 유형과 WAVE·C-V2X를 비교하시오"
  - 1교시: "C-V2X의 PC5 인터페이스와 Uu 인터페이스를 설명하시오"
  - 논술: "협력형 자율주행을 위한 C-ITS 통신 체계를 설계하고, 보안·프라이버시 확보 방안을 제시하시오"

## 5. 답안 구성 예시

**단답형**(1교시, 1페이지)
- 정의: 차량이 차량·인프라·보행자·네트워크와 실시간 정보를 교환하는 협력형 ITS의 통신 기술
- 특징 3개: ① PC5 직접통신으로 저지연 안전 메시지 ② WAVE(CSMA/CA)·C-V2X(자원 예약) 두 계열 ③ 서명·가명 인증서 기반 보안
- 구성도 키워드: OBU ↔ OBU(PC5) / OBU ↔ RSU / OBU ↔ 기지국(Uu) ↔ 센터·SCMS

**논술형(2~4교시) 목차**
1. 개요: 센서 기반 자율주행의 한계와 협력형 ITS의 필요성
2. 구성/비교: C-ITS 통신 구조도, V2X 유형표, WAVE·LTE-V2X·NR-V2X 비교표
3. 적용방안: 안전 메시지는 PC5 직접통신, 정보 서비스는 Uu 활용, RSU 우선 설치 구간 선정, SCMS 구축
4. 고려사항: 혼잡 구간 통신 품질, 단말 보급률(네트워크 효과), 인증서 관리 비용, 위치 프라이버시
5. 기술사 제언: LTE-V2X 단일화 이후 **NR-V2X로의 진화 경로와 기존 단말 호환성**을 미리 설계하고, 보급 초기에는 RSU 중심 V2I 서비스로 효과를 먼저 입증할 것
