## 1. 뉴스 요약

인사이트N파워(11-15)는 **프로젝트경영협회가 AI 시대 프로젝트관리의 발전방향을 모색**했다고 보도했다. 생성형 AI가 회의록 정리, 일정·비용 예측, 위험 식별 같은 관리 업무를 대신하기 시작하면서, 프로젝트 관리자의 역할이 **산출물을 통제하는 사람에서 가치와 불확실성을 조율하는 사람**으로 옮겨 가고 있다. 협회 논의의 구체 내용은 제목 이상으로 확인되지 않으므로, 아래에서는 **PMBOK 7판의 원칙 중심 체계와 AI 활용 프로젝트관리**를 답안 재료로 정리한다.

## 2. 핵심 개념

### 정의
**프로젝트관리**는 한시적 노력으로 고유한 제품·서비스·결과를 만들기 위해 **지식·기술·도구·기법을 적용해 목표 가치를 인도하는 활동**이다. PMI의 **PMBOK 7판**(2021)은 6판까지의 프로세스 중심 구성(5개 프로세스 그룹·10개 지식 영역)을 **12개 원칙과 8개 성과 영역**으로 바꿔, 예측형·적응형·하이브리드 어떤 방식에도 적용할 수 있는 **가치 인도 체계**로 재정의했다.

### PMBOK 6판 vs 7판

| 구분 | PMBOK 6판 | PMBOK 7판 |
|---|---|---|
| 구성 원리 | 프로세스 중심(입력·도구·산출물) | 원칙·성과 영역 중심 |
| 골격 | 5개 프로세스 그룹, 10개 지식 영역, 49개 프로세스 | 12개 원칙, 8개 성과 영역 |
| 지향점 | 산출물·계획 준수 | 성과와 가치 인도 |
| 개발 방식 | 예측형 중심, 애자일은 부록 성격 | 예측형·적응형·하이브리드 동등 |
| 적용 방식 | 정해진 프로세스 수행 | 상황에 맞춘 테일러링 강조 |
| 기법 정리 | 프로세스마다 도구·기법 나열 | 모델·방법·산출물로 별도 정리 |
| 관리자 역할 | 계획 수립·통제 | 리더십·조율·가치 판단 |

### 12개 원칙
스튜어드십(성실한 관리자) · 팀 · 이해관계자 · 가치 · 시스템 사고 · 리더십 · 테일러링 · 품질 · 복잡성 · 리스크 · 적응성과 회복력 · 변화 수용

원칙은 "무엇을 하라"가 아니라 **판단의 기준**이다. 예컨대 같은 일정 지연이라도 "가치" 원칙에 비추면 범위를 줄여 핵심 기능을 먼저 인도하는 선택이 나오고, "리스크" 원칙에 비추면 지연 원인의 재발 가능성부터 따지는 선택이 나온다.

### 구성도 ① — 8개 성과 영역과 상호작용

```
               ┌──────────── 가치 인도 ────────────┐
               │                                     │
   [이해관계자] ─── [팀] ─── [개발 방식과 생애주기]   │
        │            │              │                │
        ▼            ▼              ▼                │
   [기획] ───────▶ [프로젝트 작업] ───────▶ [인도] ──┘
        ▲                    │                 │
        │                    ▼                 ▼
        └──────────── [측정] ◀──────── 성과·가치 확인
                         │
                         ▼
                   [불확실성]  리스크·모호성·복잡성·변동성 대응
                   (모든 영역에 걸쳐 작동)
```

성과 영역은 순서대로 밟는 단계가 아니라 **동시에 맞물려 작동하는 관심 영역**이다. 측정 결과가 기획을 다시 바꾸고, 불확실성 대응이 모든 영역에 걸쳐 있다.

### 구성도 ② — AI가 들어가는 프로젝트관리 지점

```
 [기획]      과거 프로젝트 데이터로 일정·비용 추정 보조, WBS 초안 생성
     ▼
 [실행]      작업 진척 자동 수집(이슈 트래커·저장소), 회의록·결정사항 요약
     ▼
 [측정]      EVM 지표 계산, 완료 시점·최종 비용 예측, 지연 조기 경고
     ▼
 [불확실성]  이슈·커뮤니케이션 패턴에서 위험 신호 탐지, 대응 전략 제안
     ▼
 [보고]      이해관계자별 맞춤 보고서 자동 생성
     │
     └─ 사람이 맡는 영역: 우선순위 판단 · 이해관계자 협상 · 팀 동기 부여 · 책임
```

### 전통 관리 vs AI 활용 관리

| 구분 | 전통 방식 | AI 활용 방식 |
|---|---|---|
| 추정 | 전문가 판단·유사 추정 | 과거 데이터 기반 예측 + 전문가 보정 |
| 진척 파악 | 주간 보고 취합 | 도구 데이터 자동 수집, 실시간 대시보드 |
| 위험 식별 | 워크숍·체크리스트 | 이슈·일정 패턴에서 신호 탐지 |
| 보고 | 수작업 작성 | 자동 생성, 이해관계자별 요약 |
| 의사결정 | 경험 의존 | 시나리오 시뮬레이션 지원 |
| 관리자 시간 배분 | 문서·취합에 상당 시간 | 조율·리더십에 집중 |
| 위험 요인 | 보고 지연·누락 | 데이터 품질 의존, AI 예측 과신, 정보 유출 |

### EVM과 AI 예측
획득가치관리(EVM)는 계획가치(PV), 획득가치(EV), 실제원가(AC)로 성과를 숫자로 본다.
- **일정**: SV = EV − PV, SPI = EV / PV (1 미만이면 지연)
- **원가**: CV = EV − AC, CPI = EV / AC (1 미만이면 초과)
- **예측**: EAC = BAC / CPI (현재 원가 효율이 이어진다고 가정한 최종 원가)

AI는 이 지표의 추세에 과거 유사 프로젝트 패턴을 더해 **EAC와 완료 시점을 더 일찍 경고**하는 데 쓰인다. 다만 입력 데이터(진척률 산정 기준)가 부정확하면 예측도 함께 틀어지므로, **진척 측정 기준을 먼저 표준화**해야 한다.

### AI 프로젝트 자체의 관리 특성
AI 시스템 구축 프로젝트는 일반 SW 프로젝트와 다르게 **결과가 데이터와 실험에 좌우**된다.
- 성능 목표 달성 여부를 착수 시점에 확정하기 어렵다 → 단계별 검증 관문(PoC → 파일럿 → 확산)
- 데이터 확보·라벨링이 일정의 주 경로가 되는 경우가 많다
- 운영 후에도 성능 저하(드리프트)로 재학습이 필요하다 → 프로젝트 종료 후 운영 체계까지 계획
- 인공지능기본법 등 규제 요구를 위험 관리 항목에 포함한다

### 위험 대응 전략
- **부정적 위험**: 회피 · 전가 · 완화 · 수용 · 에스컬레이션
- **긍정적 위험**(기회): 활용 · 공유 · 증대 · 수용 · 에스컬레이션

### 관련 표준
- **PMBOK 7판**(PMI, 2021): 12개 원칙, 8개 성과 영역
- **ISO 21502**: 프로젝트·프로젝트관리 지침
- **ISO 21500**: 프로젝트·프로그램·포트폴리오 관리의 개념
- **PRINCE2**: 영국 기원의 프로세스 기반 프로젝트관리 방법론

## 3. 기술사 출제 포인트

- PMBOK 7판의 정의와 원칙·성과 영역 중심 전환
- PMBOK 6판 vs 7판 비교(프로세스 그룹·지식 영역 vs 원칙·성과 영역)
- 12개 원칙(가치·시스템 사고·테일러링·적응성과 회복력 등)
- 8개 성과 영역과 상호작용
- AI 활용 프로젝트관리(추정·진척·위험·보고 자동화)
- EVM 지표(SV·CV·SPI·CPI·EAC)와 AI 예측
- AI 프로젝트의 관리 특성(실험·데이터 주 경로·운영 연계)
- 부정적·긍정적 위험 대응 전략
- PMO 역할 변화와 데이터 기반 관리

## 4. 연결 기출 토픽과 예상 변형

- **PMO**: 140회 1교시에 **PMC와 PMO 비교**가 출제됐다. AI가 보고·취합 업무를 맡으면 PMO의 역할이 표준·데이터 관리와 의사결정 지원으로 옮겨 간다는 논리로 확장할 수 있다.
- **WBS·위험**: 139회 1교시에 **WBS**와 **IT 프로젝트 부정적 위험 대응 전략**이 출제됐다. 성과 영역 중 기획·불확실성 단락과 직접 연결된다.
- **AI 기반 BPR**: 140회 1교시 **AI 기반 BPR**이 출제됐다. 프로젝트관리 업무 자체를 AI로 재설계하는 사례로 묶을 수 있다.
- **예상 변형**
  - 1교시: "PMBOK 7판의 성과 영역(Performance Domain)을 설명하시오"
  - 1교시: "PMBOK 6판과 7판을 비교하시오"
  - 논술: "생성형 AI를 활용한 IT 프로젝트관리 고도화 방안과 고려사항을 제시하시오"

## 5. 답안 구성 예시

**단답형**(1교시, 1페이지)
- 정의: 프로세스 중심에서 12개 원칙과 8개 성과 영역 중심으로 전환한 PMI의 가치 인도 체계
- 특징 3개: ① 원칙 기반 판단과 테일러링 ② 예측형·적응형·하이브리드 동등 적용 ③ 산출물이 아닌 성과·가치 중심
- 구성도 키워드: 이해관계자·팀·개발 방식과 생애주기·기획·프로젝트 작업·인도·측정·불확실성

**논술형(2~4교시) 목차**
1. 개요: AI 확산과 프로젝트관리 패러다임 변화
2. 구성/비교: PMBOK 6판 vs 7판 비교표, 성과 영역 구성도, AI 적용 지점 구성도, 전통 vs AI 활용 비교표
3. 적용방안: 진척 측정 기준 표준화, EVM 기반 AI 예측, 위험 신호 탐지, 보고 자동화, AI 프로젝트 단계별 검증 관문
4. 고려사항: 데이터 품질, AI 예측 과신, 사내 정보 유출, 관리자 역량 재교육, 책임 소재
5. 기술사 제언: AI는 **측정과 보고를 자동화하는 도구**로 쓰고, 우선순위·협상·책임 같은 판단은 사람에게 남기는 역할 분담을 PMO 표준으로 명문화할 것
