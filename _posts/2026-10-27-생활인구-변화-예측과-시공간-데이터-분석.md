## 1. 뉴스 요약

천지일보(10-22)는 **세종대 연구팀이 생활 인구 변화를 예측·분석하는 AI 기술을 개발**했다고 보도했다. 주민등록 숫자가 아니라 실제로 그 지역에서 생활하고 오가는 인구의 변화를 미리 내다보려는 연구다. 생활인구 예측은 교통·상권·재난 대응·지방 인구 정책에 두루 쓰이는 공공 데이터 분석 주제다. 연구의 모델과 데이터 원천은 제목 이상으로 확인되지 않으므로, 아래에서는 생활인구 데이터의 특성과 **시공간 데이터 분석**의 일반 구조를 답안 재료로 정리한다.

## 2. 핵심 개념

### 정의
**생활인구**는 주민등록상 인구가 아니라 **특정 지역에 실제로 머무르거나 활동하는 인구**를 가리킨다. **시공간 데이터 분석**은 이렇게 **위치(공간)와 시간 축을 함께 가진 데이터**에서 패턴을 찾고 미래 값을 예측하는 분석으로, 이웃 지역끼리 서로 영향을 주는 **공간 의존성**과 시간대·요일에 따라 반복되는 **시간 의존성**을 동시에 다룬다는 점이 일반 시계열 분석과 다르다.

### 생활인구의 두 가지 정의

| 구분 | 법정 생활인구 | 통계형 생활인구(서울시 등) |
|---|---|---|
| 근거 | 인구감소지역 지원 특별법(2023 시행) | 지자체·통신사 협력 통계 |
| 구성 | 주민등록인구 + 체류인구 + 등록외국인 | 특정 시점에 그 지역에 있는 인구 추정치 |
| 체류 기준 | 월 1회 이상, 하루 3시간 이상 머문 사람 | 시간대별 존재 여부 |
| 주 데이터 | 통신·행정 데이터 결합 | 통신 기지국 신호 + 공공 통계 |
| 시간 단위 | 월·분기 | 시간대(1시간 단위 등) |
| 주 용도 | 인구감소지역 정책·재정 배분 | 상권·교통·안전 행정 |

답안에서 "생활인구"를 쓸 때 어느 정의인지 먼저 밝히면, 데이터 원천과 분석 단위를 일관되게 설명할 수 있다.

### 구성도 — 생활인구 예측 파이프라인

```
 [데이터 원천]
   통신 기지국 신호 · 카드 결제 · 교통카드 승하차 · 주민등록 · 기상·행사 일정
        │
        ▼
 [전처리]  통신사 점유율 보정(표본→전체 추정) · 격자/행정동 집계 · 결측 보간
        │   └ 개인 단위 데이터는 집계·가명처리 후 사용
        ▼
 [특징]   시간: 시간대·요일·공휴일·계절      공간: 인접 지역 값·거리·교통 연결
        │
        ▼
 [모델]   시계열(ARIMA·LSTM) ─┬─ 시공간 결합(ConvLSTM·그래프 신경망 GNN)
        │                     └ 외부 요인(행사·날씨) 결합
        ▼
 [검증]   시간 순서 유지 분할(과거로 학습, 미래로 평가) · 지역별 오차 비교
        │
        ▼
 [활용]   교통 배차 · 상권 분석 · 재난 시 인구 밀집 경보 · 인구 정책
```

### 시공간 데이터 분석 기법 비교

| 기법 | 다루는 의존성 | 장점 | 한계 |
|---|---|---|---|
| ARIMA·계절 분해 | 시간 | 해석 쉬움, 적은 데이터로 가능 | 지역 간 영향 반영 못 함 |
| LSTM·Transformer | 시간(비선형) | 복잡한 시간 패턴 학습 | 지역별로 따로 학습, 공간 무시 |
| 공간 회귀·크리깅 | 공간 | 공간 자기상관 반영 | 시간 변화에 약함 |
| ConvLSTM | 시간+격자 공간 | 격자 데이터에 적합 | 행정동처럼 불규칙한 공간엔 부적합 |
| 시공간 GNN | 시간+그래프 공간 | 교통망 등 연결 구조 반영 | 그래프 설계·연산 비용 |
| 군집 분석 | 공간 패턴 유형화 | 지역 유형 발견(주거형·업무형) | 예측이 아닌 기술 분석 |

### 분석 시 주의할 함정
- **공간 자기상관**: 가까운 지역은 값이 비슷하다(Moran's I로 측정). 이를 무시하고 지역을 독립 표본으로 보면 통계적 유의성이 과대평가된다.
- **MAUP**(가변적 공간단위 문제): 같은 데이터라도 격자 크기나 행정 경계를 어떻게 나누느냐에 따라 분석 결과가 달라진다. 분석 단위를 바꿔 결과가 유지되는지 확인해야 한다.
- **표본 편향**: 특정 통신사 가입자 신호만 쓰면 연령·지역별 가입률 차이가 결과에 섞인다. 점유율 보정이 필수다.
- **데이터 누수**: 시계열을 무작위로 나누면 미래 정보가 학습에 섞인다. 반드시 시간 순서대로 분할한다.

### 관련 법·기준
- **인구감소지역 지원 특별법**: 생활인구 개념의 법적 근거
- **개인정보 보호법**: 위치 기반 개인 데이터는 집계·가명처리 후 분석에 사용(가명정보 처리 특례)
- **위치정보법**: 개인위치정보 수집·이용 시 동의 등 별도 보호

## 3. 기술사 출제 포인트

- 생활인구의 정의(법정 vs 통계형)와 활용 분야
- 시공간 데이터의 특성(공간 의존성·시간 의존성)
- 통신·카드·교통 데이터 원천과 결합 방법
- 시공간 예측 기법 비교(ARIMA·LSTM·ConvLSTM·시공간 GNN)
- 공간 자기상관(Moran's I)과 독립성 가정 위반
- MAUP(가변적 공간단위 문제)
- 통신사 점유율 보정 등 표본 편향 대응
- 시간 순서 유지 분할과 데이터 누수 방지
- 위치 데이터 집계·가명처리와 위치정보법

## 4. 연결 기출 토픽과 예상 변형

- **표본과 시계열**: 140회 4교시에 **표본추출**(확률·비확률)과 **시계열 데이터 이상치 탐지**가 출제됐다. 통신 신호는 전체 인구가 아닌 가입자 표본이므로 보정 문제가 생기고, 행사·재난 때의 급증은 시계열 이상치로 다뤄진다.
- **통계 기본기**: 139회 1교시 **대수의 법칙과 중심극한정리**가 출제됐다. 표본 기반 추정치를 전체 인구로 확대할 때의 이론적 근거로 연결된다.
- **군집·이상치**: 139회 4교시 **빅데이터 클러스터링·필터링·이상치 탐지**가 출제됐다. 지역을 생활 패턴으로 묶는 군집 분석은 생활인구 분석의 대표 응용이다.
- **가명처리**: 139회 1교시 **개인정보보호를 위한 가명처리 기법**이 출제됐다. 위치 데이터 활용의 전제 조건이다.
- **예상 변형**
  - 1교시: "시공간 데이터(Spatio-temporal Data)의 특성과 분석 기법을 설명하시오"
  - 1교시: "MAUP(Modifiable Areal Unit Problem)를 설명하시오"
  - 논술: "통신 데이터 기반 생활인구 예측 모델의 구축 절차와 데이터 품질·개인정보 고려사항을 논하시오"

## 5. 답안 구성 예시

**단답형**(1교시, 1페이지)
- 정의: 위치와 시간 축을 함께 가진 데이터에서 공간·시간 의존성을 동시에 분석·예측하는 기법
- 특징 3개: ① 공간 자기상관 ② 시간대·요일 주기성 ③ 집계 단위에 따른 결과 변화(MAUP)
- 구성도 키워드: 통신·카드·교통 데이터 → 점유율 보정·집계 → 시간/공간 특징 → 시공간 모델 → 시간 순서 검증 → 정책 활용

**논술형(2~4교시) 목차**
1. 개요: 주민등록 인구와 실제 활동 인구의 괴리, 생활인구 개념 등장
2. 구성/비교: 생활인구 두 정의 비교표, 예측 파이프라인 구성도, 시공간 기법 비교표
3. 적용방안: 다중 데이터 결합, 점유율 보정, 시공간 GNN 모델, 재난·교통 활용
4. 고려사항: 공간 자기상관·MAUP, 표본 편향, 데이터 누수, 위치 개인정보
5. 기술사 제언: 예측 정확도와 함께 **분석 단위 민감도(MAUP)와 표본 보정 방식을 결과와 같이 공개**해 정책 판단의 근거로 쓸 수 있게 하고, 원천 데이터는 집계·가명처리 단계에서만 결합할 것
