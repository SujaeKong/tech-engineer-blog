## 1. 뉴스 요약

테크42(11-09)는 **카카오모빌리티가 자체 AI에 엔비디아 기술을 결합해 기아 PBV(목적기반차량)로 레벨4 자율주행에 도전**한다고 보도했다. 앞서 전자신문(11-04)은 **볼보가 엔비디아의 차세대 자율주행 기술을 탑재해 '아이즈 오프(Eyes off)·마인드 오프(Mind off)'를 도입**한다고 전했다. 운전자가 전방을 보지 않아도 되는 단계와 아예 운전에서 손을 떼는 단계는 **사고 책임이 사람에서 시스템으로 넘어가는 경계**라는 점에서 기술만큼 제도가 중요하다. 각 회사의 운행 지역과 일정은 제목 이상으로 확인되지 않으므로, 아래에서는 **자율주행 단계와 운행설계영역**(ODD) 개념을 정리한다.

## 2. 핵심 개념

### 정의
**레벨4 자율주행**은 정해진 **운행설계영역**(ODD, Operational Design Domain) 안에서 시스템이 운전의 모든 과업을 수행하고, 문제가 생겨도 **사람의 개입 없이 스스로 차량을 안전한 상태(최소위험상태, MRC)로 만드는** 단계다. 운전자가 개입 요청에 응해야 하는 레벨3와 달리, 레벨4는 ODD 안에서 **운전자가 없어도** 된다. ODD는 도로 유형·속도·날씨·시간대·지역처럼 시스템이 안전하게 동작하도록 설계된 조건의 범위를 말한다.

### SAE J3016 자율주행 단계

| 레벨 | 명칭 | 운전 주체 | 운전자 역할 | 흔한 표현 |
|---|---|---|---|---|
| 0 | 자동화 없음 | 사람 | 모든 운전 | — |
| 1 | 운전자 보조 | 사람 | 조향 또는 가감속 중 하나 보조 | 차선 유지 또는 크루즈 |
| 2 | 부분 자동화 | 사람 | 상시 감시·즉시 개입 | 핸즈 오프(조건부) |
| 3 | 조건부 자동화 | 시스템(ODD 내) | 개입 요청 시 응답 | 아이즈 오프 |
| 4 | 고도 자동화 | 시스템(ODD 내) | 불필요(ODD 내) | 마인드 오프 |
| 5 | 완전 자동화 | 시스템(모든 조건) | 불필요 | — |

레벨2와 3 사이, 레벨3과 4 사이가 가장 중요한 경계다. **레벨2까지는 사람이 운전 책임을 지고**, 레벨3부터는 ODD 안에서 **시스템이 운전 주체**가 된다.

### 구성도 — 레벨4 자율주행 운행 흐름과 ODD

```
 ┌──────────────────────── ODD (운행설계영역) ─────────────────────────┐
 │  지정 지역·도로 유형 · 속도 범위 · 날씨·조도 · 시간대 · 교통 조건      │
 │                                                                     │
 │  [인지] 카메라·라이다·레이더 융합 → [판단] 경로·행동 계획 → [제어]    │
 │        ↑ 정밀지도·측위 · V2X(선택)                                  │
 │                                                                     │
 │  ODD 이탈 징후 감지 (폭우, 공사 구간, 센서 이상, 지도 불일치)          │
 │        │                                                            │
 │        ▼                                                            │
 │  레벨3: 운전자에게 제어권 전환 요청 → 운전자 응답                      │
 │  레벨4: 시스템이 스스로 최소위험상태(MRC) 진입 → 갓길 정차 등         │
 └─────────────────────────────────────────────────────────────────────┘
          │
          ▼
   원격 관제센터: 상황 확인 · 원격 지원 · 차량 회수
```

레벨4를 가르는 기준은 "**사람에게 넘기지 않는다**"는 점이다. 그래서 ODD를 좁고 명확하게 정의하고, 이탈 시 안전하게 멈추는 MRC 전략이 시스템 설계의 중심이 된다.

### 레벨3 vs 레벨4 비교

| 구분 | 레벨3 | 레벨4 |
|---|---|---|
| ODD 내 운전 주체 | 시스템 | 시스템 |
| 운전자 필요 여부 | 필요(대기) | ODD 내 불필요 |
| 문제 발생 시 | 운전자에게 제어권 전환 요청 | 시스템이 스스로 MRC 진입 |
| 제어권 전환 위험 | 운전자 반응 지연(주의 분산) | 전환 없음 |
| 대표 적용 | 고속도로 정체 구간 주행 | 로보택시·셔틀·물류(PBV) |
| 책임 쟁점 | 전환 요청 전후의 책임 구분 | 제조사·운행 사업자 책임 확대 |
| 원격 관제 | 보조적 | 사실상 필수 |

### 안전 표준·국내 제도
- **SAE J3016**: 자율주행 단계(0~5)와 용어 정의
- **ISO 26262**: 차량 전기·전자 시스템 기능안전(고장으로 인한 위험)
- **ISO 21448**(SOTIF): 고장이 없어도 성능 한계·예상 못한 상황에서 생기는 위험 관리 — AI 인지 오류가 여기에 해당
- **UNECE R157**(ALKS): 레벨3 자동차로유지시스템 국제 기준
- **자율주행자동차법**: 시범운행지구 지정, 레벨4 차량 성능인증 등 상용화 근거

## 3. 기술사 출제 포인트

- SAE J3016 자율주행 단계(0~5)와 운전 주체
- 레벨2·3·4 경계와 책임 전환
- 운행설계영역(ODD)의 정의와 구성 요소
- 최소위험상태(MRC)와 레벨4의 페일 세이프 전략
- 레벨3 제어권 전환 요청의 위험(운전자 반응 지연)
- 인지·판단·제어 구조와 센서 융합
- ISO 26262 기능안전과 ISO 21448 SOTIF 비교
- 원격 관제·원격 지원의 역할
- 자율주행자동차법·시범운행지구·성능인증 제도

## 4. 연결 기출 토픽과 예상 변형

- **자율주행**: 블로그 통합 기출 분석(`exam_trend_integrated.json`) 기준 **자율주행은 기출 8회**인 신기술융합 빈출 키워드다. 단계 비교와 ODD는 자율주행 문항의 기본 단락이다.
- **피지컬 AI**: 140회 1교시 **Physical AI와 생성형 AI 비교**, 2교시 **피지컬 AI 논술**이 출제됐다. 자율주행은 피지컬 AI의 대표 사례로, 물리 세계 안전 요구가 생성형 AI와의 차이를 보여준다.
- **AI 통제 상실**: 140회 2교시 **AI 보안 — 자율성으로 인한 통제 상실 위협 및 대응**이 출제됐다. 레벨4의 ODD 제한과 MRC는 자율성을 통제하는 설계 장치다.
- **예상 변형**
  - 1교시: "자율주행 운행설계영역(ODD)과 최소위험상태(MRC)를 설명하시오"
  - 1교시: "ISO 26262와 ISO 21448(SOTIF)을 비교하시오"
  - 논술: "레벨4 자율주행 상용화를 위한 기술·안전·제도 과제를 제시하시오"

## 5. 답안 구성 예시

**단답형**(1교시, 1페이지)
- 정의: ODD 안에서 시스템이 모든 운전을 수행하고, 이상 시 스스로 MRC에 진입하는 고도 자동화 단계
- 특징 3개: ① 운전자 불필요(ODD 내) ② 제어권 전환 대신 MRC 진입 ③ 원격 관제 연계
- 구성도 키워드: ODD 정의 → 인지·판단·제어 → ODD 이탈 감지 → MRC 진입(레벨4) / 제어권 전환(레벨3) → 원격 관제

**논술형(2~4교시) 목차**
1. 개요: 아이즈 오프·마인드 오프 경쟁과 책임 주체의 전환
2. 구성/비교: SAE 단계표, 레벨4 운행 흐름 구성도, 레벨3 vs 레벨4 비교표
3. 적용방안: 좁고 명확한 ODD로 시작(셔틀·물류 PBV), MRC 시나리오 설계, 원격 관제 체계, SOTIF 기반 검증
4. 고려사항: ODD 이탈 판단 정확도, 사고 책임·보험, 사이버보안, 사회적 수용성
5. 기술사 제언: 상용화 범위를 **ODD 단위로 단계 확대**하고, ODD 정의·MRC 동작·운행 기록을 인증과 사고 조사의 공통 기준으로 삼을 것
