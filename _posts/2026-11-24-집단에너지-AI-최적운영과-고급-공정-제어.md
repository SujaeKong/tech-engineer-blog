## 1. 뉴스 요약

에너지타임즈(11-22)는 **한국지역난방공사와 에머슨이 집단에너지 설비의 AI 최적운영 기술개발을 추진**한다고 보도했고, 부산일보(11-19)는 이를 **'집단에너지설비 AX' 본격화**로 전했다. 집단에너지는 열병합발전소 등에서 만든 열과 전기를 지역 단위로 공급하는 시스템으로, **날씨에 따라 출렁이는 열수요와 시간대별로 바뀌는 전력 가격**을 동시에 맞춰야 하는 복잡한 운영 문제를 안고 있다. 협력의 구체 범위는 제목 이상으로 확인되지 않으므로, 아래에서는 **집단에너지 운영의 제어 계층과 AI 최적화 구조**를 답안 재료로 정리한다.

## 2. 핵심 개념

### 정의
**집단에너지**는 열병합발전소·열전용보일러 등 대규모 생산시설에서 만든 열(온수·증기)과 전기를 **배관망을 통해 다수의 건물·단지에 일괄 공급**하는 에너지 공급 방식이다. **고급 공정 제어**(APC, Advanced Process Control)는 기본 제어 위에서 **공정 모델로 미래 거동을 예측하고 여러 변수를 제약 조건 안에서 동시에 조정**하는 제어 기술로, 대표 기법이 모델 예측 제어(MPC)다. AI 최적운영은 여기에 수요 예측과 데이터 기반 모델을 더해 **언제, 어느 설비를, 얼마나 돌릴지**를 최적으로 정하는 것이다.

### 구성도 ① — 집단에너지 시스템 구조

```
 [생산]
   ├ 열병합발전(CHP): 전기 + 열 동시 생산 → 전력은 계통으로 판매
   ├ 첨두부하보일러(PLB): 열수요가 몰릴 때만 가동
   └ 축열조: 남는 열을 저장했다가 수요 피크에 방출
        │
        ▼
 [수송]  열수송관망(공급·회수) · 펌프 · 열교환 기지
        │
        ▼
 [사용]  아파트 단지 · 상업 건물 · 산업체
        │
 [외부 변수]  기온·일사 · 요일·시간 · 전력 시장 가격 · 연료 가격
```

열병합발전은 전기를 팔면서 열도 함께 얻으므로 효율이 높지만, **전기 가격이 낮은 시간에 열 때문에 억지로 돌리면 손해**가 난다. 이때 축열조에 열을 미리 쌓아 두면 발전 시점과 열 공급 시점을 분리할 수 있다. 이 시간 이동 판단이 최적화의 핵심 대상이다.

### 구성도 ② — 제어 계층

```
 [L4 계획]      연간·월간 운영 계획 · 연료 구매 · 전력 시장 입찰
     ▲
 [L3 최적화]    실시간 최적화(RTO): 설비별 최적 부하 배분, 축열 운용 결정
     ▲          ← AI: 열수요 예측 · 전력 가격 예측 · 최적 스케줄
 [L2 고급 제어] APC/MPC: 다변수 제약 제어(온도·압력·유량 동시 조정)
     ▲          ← AI: 데이터 기반 공정 모델 · 소프트 센서
 [L1 기본 제어] DCS·PLC의 PID 제어 루프
     ▲
 [L0 현장]      센서 · 밸브 · 펌프 · 보일러 · 터빈
     │
 [안전계장(SIS)]  독립 계층 — 위험 상황 시 자동 정지(AI와 분리)
```

위 계층일수록 **결정 주기가 길고**(일·시간 단위) 경제성을 다루며, 아래 계층일수록 **주기가 짧고**(초 단위) 물리적 안정성을 다룬다. AI는 주로 L2~L3에 들어가고, 안전계장시스템은 AI 판단과 독립적으로 동작해야 한다.

### PID vs MPC

| 구분 | PID 제어 | MPC(모델 예측 제어) |
|---|---|---|
| 원리 | 현재 오차의 비례·적분·미분으로 조작 | 공정 모델로 미래를 예측해 최적 조작 계산 |
| 변수 | 단일 입력–단일 출력 위주 | 다중 입력–다중 출력 |
| 제약 조건 | 직접 반영 어려움 | 제약 조건을 최적화에 직접 포함 |
| 지연 큰 공정 | 대응 어려움 | 예측으로 선제 대응 |
| 계산 부담 | 매우 낮음 | 주기마다 최적화 계산 필요 |
| 모델 필요 | 불필요(튜닝 중심) | 공정 모델 필수(정확도가 성능 좌우) |
| 용도 | 기본 루프 제어 | 상위 다변수 제어·경제성 운전 |

### 전통 운영 vs AI 최적운영

| 구분 | 전통 운영 | AI 최적운영 |
|---|---|---|
| 열수요 예측 | 운전원 경험·전일 실적 | 기상·요일·건물 특성 학습 예측 |
| 설비 배분 | 정해진 운전 순서 | 연료비·전력 가격 반영 최적 배분 |
| 축열조 운용 | 정형화된 충·방열 | 가격·수요 예측 기반 시간 이동 |
| 공정 모델 | 물리 모델·고정 파라미터 | 물리 모델 + 데이터 기반 보정 |
| 이상 감지 | 경보 임계값 | 다변수 패턴 기반 조기 감지 |
| 운전원 역할 | 직접 조작 | 권고 검토·승인, 예외 대응 |

### AI 적용 단계
AI를 처음부터 제어 루프에 직접 넣지 않는다. 신뢰를 쌓으며 단계적으로 권한을 넓힌다.
1. **자문형**(Advisory): AI가 최적 운전점을 제안하고 운전원이 판단·조작
2. **감독형 폐루프**(Supervised Closed Loop): AI가 설정값을 직접 내리되 운전원이 감시·개입 가능, 허용 범위 제한
3. **자율형**: 정해진 운전 범위 안에서 AI가 자동 운전, 범위 밖은 사람에게 넘김

### 고려사항
- **안전 분리**: 안전계장시스템은 AI·APC와 물리적·논리적으로 분리하고 AI 판단으로 무력화할 수 없게 한다.
- **OT 보안**: 최적화를 위해 IT망·클라우드와 연결하면 제어망 공격 표면이 넓어진다. 영역·관문 분리와 단방향 전송을 검토한다.
- **모델 드리프트**: 설비 노후·보수 후 공정 특성이 바뀌면 모델을 재보정해야 한다.
- **설명 가능성**: 운전원이 권고 이유를 이해하지 못하면 사용하지 않는다. 핵심 근거(예측 수요·가격)를 함께 보여준다.

### 관련 표준·법령
- **IEC 61511**: 공정 산업 안전계장시스템 기능 안전
- **IEC 62443**: 산업 자동화·제어 시스템 보안
- **ISA-95**(IEC 62264): 기업–제어 시스템 통합 계층
- **집단에너지사업법**: 집단에너지 공급·사업 관리의 근거

## 3. 기술사 출제 포인트

- 집단에너지와 열병합발전·첨두부하보일러·축열조 구조
- 열과 전력의 동시 최적화, 축열조를 통한 시간 이동
- 제어 계층(L0 현장~L4 계획)과 AI 적용 위치
- PID와 MPC 비교(다변수·제약·예측)
- 실시간 최적화(RTO)와 설비 부하 배분
- AI 열수요 예측과 데이터 기반 공정 모델(소프트 센서)
- 자문형→감독형 폐루프→자율형 단계적 적용
- 안전계장시스템(SIS) 분리와 IEC 61511
- OT 보안(IEC 62443)과 모델 드리프트

## 4. 연결 기출 토픽과 예상 변형

- **VPP**: 139회 4교시에 **가상발전소**(VPP)가 출제됐다. 열병합발전과 축열조를 묶어 전력 시장 가격에 맞춰 운영하는 구조는 VPP의 분산자원 최적화와 같은 원리다.
- **시계열 이상치**: 140회 4교시에 **시계열 데이터 이상치 탐지**가 출제됐다. 설비 센서의 다변수 이상 감지가 바로 그 응용이다.
- **Physical AI**: 140회 1교시 **Physical AI와 생성형 AI 비교**가 출제됐다. 실제 설비를 조작하는 제어 AI는 Physical AI의 산업 사례로, 안전 분리와 단계적 권한 확대가 차별점이다.
- **예상 변형**
  - 1교시: "모델 예측 제어(MPC)를 설명하시오"
  - 1교시: "PID 제어와 MPC를 비교하시오"
  - 논술: "에너지 설비에 AI 기반 최적운영을 도입할 때 제어 계층 설계와 안전·보안 확보 방안을 제시하시오"

## 5. 답안 구성 예시

**단답형**(1교시, 1페이지)
- 정의: 공정 모델로 미래 거동을 예측하고 제약 조건 안에서 다변수 조작을 최적화하는 고급 공정 제어 기법(MPC)
- 특징 3개: ① 예측 구간에 대한 최적화를 매 주기 반복(이동 구간) ② 제약 조건 직접 반영 ③ 다중 입력–다중 출력 제어
- 구성도 키워드: L1 PID(DCS) → L2 APC/MPC → L3 RTO(AI 수요·가격 예측) → L4 계획 / SIS 독립

**논술형(2~4교시) 목차**
1. 개요: 집단에너지 운영의 복잡성과 AI 최적운영 도입
2. 구성/비교: 시스템 구성도, 제어 계층도, PID vs MPC 비교표, 전통 vs AI 운영 비교표
3. 적용방안: AI 열수요·가격 예측, 축열조 시간 이동 최적화, MPC 고도화, 자문형부터 단계적 적용, 이상 감지
4. 고려사항: SIS 분리, OT 보안, 모델 드리프트, 운전원 수용성, 예측 오차 대응
5. 기술사 제언: AI 최적운영의 성과를 **연료비·탄소 배출 절감과 안전 경보 감소**로 함께 측정하고, 제어 권한은 자문형에서 시작해 검증된 범위만큼만 넓히는 단계적 운영 원칙을 둘 것
