## 1. 뉴스 요약

2026-10-07 **"데이터가 바뀌어도 최신 정보를 놓치지 않는" AI 기술**이 개발됐다. AI 모델은 학습 시점의 데이터에 고정돼 있어, 이후 사실·환경이 바뀌면 **낡은 지식으로 틀린 답**을 내기 쉬운데, 이를 비용 효율적으로 갱신하는 방법이 핵심이다.

이는 AI 운영에서 **모델의 신선도(freshness) 유지**가 품질의 핵심 과제임을 보여준다. 지속학습과 지식 갱신은 정보관리기술사 AI데이터분석 영역과 직결된다.

## 2. 핵심 개념

### 왜 모델이 낡는가
배포 후 입력 분포가 바뀌는 **데이터 드리프트**, 입력-정답 관계 자체가 바뀌는 **개념 드리프트**, 그리고 새로운 사실의 등장이 겹친다. 새 데이터로 다시 학습하면 기존 지식을 잃는 **치명적 망각**이 생긴다.

### 지식 갱신 접근 비교

| 접근 | 특징 |
|---|---|
| 전체 재학습 | 정확하지만 비용·시간 큼 |
| 지속학습 | 증분 학습·망각 억제 |
| 지식 편집 | 특정 사실만 국소 수정 |
| 검색 증강(RAG) | 외부 최신 데이터 참조 |

### 지속학습 데이터 분석 아키텍처 관점
핵심은 **변화를 감지하고 비용에 맞는 방식으로 갱신**하는 것이다. ① 입력 분포·성능 지표를 모니터링해 드리프트를 감지하고, ② 자주 바뀌는 사실은 RAG로 외부 데이터를 참조해 모델 수정 없이 반영하며, ③ 축적된 변화는 리플레이·정규화 기반 지속학습으로 망각을 억제하며 증분 학습하고, ④ 특정 오류 사실은 지식 편집으로 국소 수정한다. 갱신 후에는 **기존 성능 회귀 평가**가 필수다. 관건은 갱신 비용, 망각 방지, 그리고 갱신 이력·버전 관리다.

## 3. 기술사 출제 포인트

- 데이터 드리프트와 개념 드리프트의 구분과 감지 방법
- 치명적 망각과 지속학습 기법(리플레이·정규화·파라미터 격리)
- 전체 재학습·지속학습·지식 편집·RAG의 비교
- 모델 모니터링과 재학습 트리거 설계(MLOps)
- 갱신 후 회귀 평가와 모델 버전 관리
