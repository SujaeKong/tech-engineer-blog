## 1. 뉴스 요약

연합뉴스·동아사이언스·인공지능신문 등(10-26)은 **ETRI와 GIST가 저장된 기억을 스스로 찾아 행동하는 로봇 AI 기술을 개발**했다고 보도했다. 인공지능신문은 이를 "**모르면 추측 대신 기억을 확인한다**"는 특징을 가진 **스스로 판단하고 행동하는 로봇 AI 플랫폼**으로 소개했고, 동아사이언스는 **"유리컵만 꺼내줘"처럼 필요한 정보만 찾아 쓰는 로봇 AI**라고 전했다. 또 다른 보도는 **로봇이 직접 보고 기억한다**는 점을 강조했다. 시스템 구조와 성능 수치는 제목 이상으로 확인되지 않으므로, 아래에서는 이 연구가 다루는 **에이전트 메모리와 기억 기반 행동 결정**의 일반 구조를 정리한다.

## 2. 핵심 개념

### 정의
**에이전트 메모리**는 AI 에이전트가 과거 관찰·경험·지식을 저장했다가 **현재 작업에 필요한 것만 골라 꺼내 쓰는** 구조다. 모든 정보를 모델 입력(컨텍스트)에 넣는 대신, 저장소에 기록하고 **검색해서 선택적으로 활용**한다는 점에서 RAG와 원리가 같다. 로봇처럼 물리 환경에서 행동하는 체화 AI(Embodied AI)에서는 "무엇을 어디서 봤는가"라는 **시공간 정보가 붙은 기억**이 특히 중요하다.

### 에이전트 메모리 유형

| 유형 | 사람의 기억에 대응 | 내용 | 로봇 예시 |
|---|---|---|---|
| 작업 기억 | 단기 기억 | 지금 처리 중인 정보(컨텍스트) | 현재 지시 "유리컵 꺼내줘" |
| 일화 기억 | 경험 기억 | 언제·어디서·무엇을 봤는지 | "오전 9시 주방 선반 2단에서 유리컵 봄" |
| 의미 기억 | 지식 | 일반 사실·개념 | "유리컵은 깨지기 쉽다" |
| 절차 기억 | 기술·습관 | 행동 방법 | 컵 잡기 동작, 문 여는 순서 |
| 사용자 기억 | 관계 기억 | 사람별 선호·이력 | "이 사용자는 파란 컵을 선호" |

### 구성도 — 기억 기반 행동 결정 흐름

```
 [관찰]  카메라·센서 → 객체 인식 → (객체, 위치, 시각, 상태) 기록
             │
             ▼
 [기억 저장소]  일화 기억(시공간 태그) · 의미 기억 · 절차 기억
             │   └ 요약·통합·망각 정책으로 용량 관리
             ▼
 [지시 입력]  "유리컵만 꺼내줘"
             │
             ▼
 [기억 검색]  의미 유사도 + 시간 최신성 + 공간 근접성으로 후보 선택
             │
             ▼
 [확신도 판단] ─┬─ 충분: 기억 기반으로 바로 행동(이동·집기)
               ├─ 불충분: 확인 행동(현장 다시 보기, 사용자에게 질문)
               └─ 기억 없음: 탐색 행동 → 새 관찰을 기억에 추가
             │
             ▼
 [행동·결과 기록]  성공/실패를 다시 일화 기억에 저장 (다음 판단에 반영)
```

"모르면 추측 대신 기억을 확인한다"는 특징은 이 흐름의 **확신도 판단** 단계에 해당한다. LLM이 근거 없이 그럴듯한 답을 만드는 환각을, 로봇에서는 **존재하지 않는 위치로 가거나 엉뚱한 물체를 집는 오동작**으로 바꿔 생각할 수 있다.

### 전체 컨텍스트 주입 vs 기억 검색

| 구분 | 모든 정보를 컨텍스트에 주입 | 기억 저장 후 검색 |
|---|---|---|
| 정보량 한계 | 컨텍스트 길이에 제한 | 저장소 용량까지 확장 |
| 응답 지연·비용 | 입력이 길수록 증가 | 필요한 정보만 사용해 절감 |
| 정확도 | 관련 없는 정보가 판단 방해 | 관련 정보 집중(검색 품질에 의존) |
| 시간 경과 | 오래된 정보도 동일 비중 | 최신성 가중치 적용 가능 |
| 근거 추적 | 어떤 정보를 썼는지 불명확 | 사용한 기억 항목 추적 가능 |
| 주요 위험 | 비용 폭증, 핵심 정보 묻힘 | 검색 실패, 오래된 기억 신뢰 |

### 기억 검색의 점수 구성
기억 후보의 우선순위는 보통 여러 기준을 결합해 정한다.
- **관련성**: 지시와 기억 내용의 의미 유사도(임베딩 거리)
- **최신성**: 오래된 기억일수록 가중치 감소 — 물건은 옮겨질 수 있다
- **공간 근접성**: 현재 위치에서 가까운 장소의 기억 우선
- **중요도**: 실패 경험·사용자 지시처럼 중요한 기억에 가중치

### 고려사항
- **기억의 신선도**: 어제 본 컵이 지금도 그 자리에 있다는 보장은 없다. 기억은 "확인 전 가설"로 취급하고, 행동 전 재관찰로 검증한다.
- **용량과 망각**: 모든 관찰을 저장하면 검색 품질이 떨어진다. 반복 관찰은 요약·통합하고, 쓰이지 않는 기억은 지운다.
- **프라이버시**: 가정·병원 로봇의 기억에는 사람의 얼굴·생활 패턴이 담긴다. 저장 범위 제한, 비식별화, 삭제 요청 처리가 필요하다.

## 3. 기술사 출제 포인트

- 에이전트 메모리의 정의와 RAG와의 공통 원리
- 메모리 유형(작업·일화·의미·절차·사용자 기억)
- 시공간 태그가 붙은 일화 기억의 역할
- 확신도 기반 행동 결정(실행·확인·탐색)
- 전체 컨텍스트 주입과 기억 검색 방식 비교
- 기억 검색 점수(관련성·최신성·공간 근접성·중요도)
- 요약·통합·망각 등 메모리 용량 관리
- 로봇 오동작을 체화 AI의 환각으로 보는 관점
- 로봇 기억 데이터의 프라이버시 보호

## 4. 연결 기출 토픽과 예상 변형

- **RAG·검색**: 139회 2교시 **LLM 파인튜닝/RAG 개념과 RLHF·RAFT 비교**, 140회 1교시 **하이브리드 검색**(어휘 + 의미/벡터 검색)이 출제됐다. 에이전트 메모리는 RAG를 "외부 문서"가 아닌 "자기 경험"에 적용한 확장이라, 같은 비교표를 그대로 활용할 수 있다.
- **피지컬 AI**: 140회 1교시 **Physical AI와 생성형 AI 비교**, 2교시 **피지컬 AI 논술**이 출제됐다. 기억 기반 행동은 피지컬 AI가 생성형 AI와 달리 "현실 상태를 계속 추적해야 한다"는 차이를 보여주는 근거가 된다.
- **멀티에이전트**: 139회 3교시 **다중 에이전트 시스템**(MAS)이 출제됐다. 여러 로봇이 기억을 공유하는 구조로 확장할 수 있다.
- **예상 변형**
  - 1교시: "AI 에이전트 메모리(Agent Memory)의 유형을 설명하시오"
  - 1교시: "체화 AI(Embodied AI)에서 일화 기억(Episodic Memory)의 역할을 설명하시오"
  - 논술: "LLM 기반 에이전트의 장기 기억 구조를 설계하고, 검색 품질·용량 관리·프라이버시 고려사항을 논하시오"

## 5. 답안 구성 예시

**단답형**(1교시, 1페이지)
- 정의: 관찰·경험·지식을 저장했다가 현재 작업에 필요한 것만 검색해 쓰는 에이전트 구조
- 특징 3개: ① 작업·일화·의미·절차 기억 계층 ② 관련성·최신성·근접성 기반 검색 ③ 확신도 부족 시 확인·탐색 행동
- 구성도 키워드: 관찰 → 기억 저장(시공간 태그) → 지시 → 기억 검색 → 확신도 판단(실행/확인/탐색) → 결과 기록

**논술형(2~4교시) 목차**
1. 개요: 컨텍스트 길이 한계와 로봇의 장시간 환경 추적 필요성
2. 구성/비교: 메모리 유형표, 기억 기반 행동 흐름도, 컨텍스트 주입 vs 기억 검색 비교표
3. 적용방안: 시공간 태그 일화 기억, 다중 기준 검색 점수, 확신도 기반 확인 행동, 요약·망각 정책
4. 고려사항: 기억 신선도, 검색 실패, 저장 용량, 생활 공간 프라이버시
5. 기술사 제언: 기억을 **사실이 아닌 검증 대상 가설**로 다루는 설계 원칙을 두고, 확신도가 낮을 때 행동을 멈추고 확인하는 경로를 안전 요구사항으로 명시할 것
