## 1. 뉴스 요약

2026-08-06 한국전력기술이 **공공기관 최초로 자체 개발한 대화형 생성형 AI 코딩 서비스 '넥사코드'**를 정식 상용화했다고 밝혔다. 개발자가 자연어로 요구사항을 입력하면 **코드를 자동 생성·보완**해 개발 생산성을 높이는 것이 목표다.

이는 생성형 AI가 **코드 검증을 넘어 코드 생성·개발 전 과정**으로 확산되는 흐름을 보여준다. 폐쇄망·보안이 중요한 공공기관이 **자체 모델**로 도입했다는 점도 의미가 있다. AI 기반 개발 자동화와 품질·거버넌스는 정보관리기술사 소프트웨어공학 영역과 직결된다.

## 2. 핵심 개념

### 생성형 AI 코드 자동생성
LLM 기반으로 **자연어 명세·주석·컨텍스트로부터 코드를 생성**한다. 코드 완성, 함수 생성, 리팩터링, 테스트·문서 생성까지 지원해 개발 생산성을 높인다.

### 개발 파이프라인 통합

| 단계 | AI 지원 |
|---|---|
| 요구·설계 | 명세→코드 스캐폴딩 |
| 구현 | 코드 완성·생성·리팩터링 |
| 테스트 | 테스트 케이스·데이터 생성 |
| 리뷰 | 정적분석·취약점·품질 점검 |
| 운영 | 문서화·이슈 대응 |

### 자체 모델 도입과 품질·거버넌스
공공·보안 환경은 외부 API로 코드를 보내기 어려워 **자체(온프레미스) 모델**이 유리하다. 다만 AI 생성 코드는 **결함·보안취약점·라이선스 위반** 위험이 있어, ① 정적분석·테스트 자동화, ② 사람 코드리뷰(HITL)·승인 게이트, ③ 라이선스·SBOM 점검이 필요하다. **생산성(AI)과 신뢰(검증)의 균형**이 핵심이다.

## 3. 기술사 출제 포인트

- 생성형 AI 코드 자동생성의 개념과 개발 파이프라인 적용 범위
- AI 코딩 도입 시 생산성 효과와 품질·보안 리스크
- 자체(온프레미스) 모델 도입의 필요성(폐쇄망·데이터 보안)
- AI 생성 코드 품질 게이트(정적분석·테스트·리뷰·SBOM)
- 개발 생산성과 신뢰성(검증·거버넌스)의 균형
