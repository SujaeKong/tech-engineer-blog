## 1. 뉴스 요약

디지털경제뉴스(11-11)는 **딥엑스의 차세대 AI 반도체 'DX-M2'가 CES 2027 혁신상 AI 부문에 선정**됐다고 보도했다. 같은 시기 테크42(11-11)는 딥엑스를 포함한 국내 스타트업들의 CES 혁신상 수상 소식을 함께 전했다. AI 추론을 클라우드가 아닌 기기 안에서 처리하려는 수요가 늘면서, **적은 전력으로 신경망 연산을 빠르게 처리하는 NPU**가 핵심 부품으로 떠올랐다. DX-M2의 사양은 제목 이상으로 확인되지 않으므로, 아래에서는 **NPU의 구조와 설계 원리**를 답안 재료로 정리한다.

## 2. 핵심 개념

### 정의
**NPU**(Neural Processing Unit)는 신경망 연산의 대부분을 차지하는 **행렬 곱셈과 누산(MAC, Multiply-Accumulate)을 대량 병렬로 처리하도록 특화한 프로세서**다. 범용 CPU나 그래픽 처리에서 출발한 GPU와 달리, 연산 유닛 배열과 온칩 메모리, 데이터 흐름을 신경망 추론에 맞춰 설계해 **전력 대비 성능**(TOPS/W)을 높인다.

### CPU vs GPU vs NPU

| 구분 | CPU | GPU | NPU |
|---|---|---|---|
| 설계 목적 | 범용 순차 처리 | 대규모 병렬 연산(그래픽·HPC·AI) | 신경망 연산 특화 |
| 코어 구성 | 소수의 고성능 코어 | 수천 개 단순 코어 | MAC 유닛 배열(시스톨릭 등) |
| 제어 복잡도 | 높음(분기 예측·비순차 실행) | 중간 | 낮음(정해진 데이터 흐름) |
| 주 데이터 정밀도 | FP64/FP32 | FP32/FP16/BF16 | INT8/INT4 등 저정밀 중심 |
| 전력 효율 | 낮음 | 중간 | 높음 |
| 유연성 | 매우 높음 | 높음 | 낮음(지원 연산자 제한) |
| 주 용도 | 제어·일반 처리 | 학습·대규모 추론 | 온디바이스·엣지 추론 |

### 구성도 — NPU 내부 구조

```
 ┌──────────────────────── NPU ────────────────────────┐
 │  [명령 디코더·스케줄러]  컴파일된 신경망 실행 순서 제어   │
 │            │                                         │
 │            ▼                                         │
 │  ┌──── 온칩 SRAM(버퍼) ────┐                          │
 │  │ 가중치 버퍼 │ 입력 버퍼 │ 출력 버퍼 │                 │
 │  └─────┬────────┬─────────┘                          │
 │        ▼        ▼                                    │
 │  ┌──── MAC 배열(시스톨릭 어레이) ────┐                  │
 │  │  PE ─ PE ─ PE ─ PE                │  가중치 고정,   │
 │  │  │    │    │    │                 │  입력이 흐르며  │
 │  │  PE ─ PE ─ PE ─ PE                │  곱셈·누산 반복 │
 │  └──────────────┬───────────────────┘                  │
 │                 ▼                                    │
 │  [벡터·활성화 유닛]  ReLU·정규화·풀링 등                 │
 └─────────────────┬───────────────────────────────────┘
                   ▼ 외부 메모리(DRAM)와의 데이터 이동 = 전력·성능 병목
```

### 설계의 핵심 — 데이터 이동 줄이기
신경망 연산에서 **연산 자체보다 메모리에서 데이터를 가져오는 데 더 많은 에너지**가 든다. 그래서 NPU 설계는 다음에 집중한다.
- **데이터 재사용**: 한 번 가져온 가중치·입력을 MAC 배열 안에서 여러 번 재사용(가중치 고정·출력 고정 등 데이터 흐름 방식)
- **온칩 SRAM 확대**: 외부 DRAM 접근 횟수 감소
- **저정밀 연산**: INT8·INT4 양자화로 데이터 크기와 연산 에너지 절감
- **연산 융합**: 컨볼루션·활성화·정규화를 한 번에 처리해 중간 결과의 메모리 왕복 제거

### 성능 지표

| 지표 | 의미 | 주의점 |
|---|---|---|
| TOPS | 초당 조(10¹²) 단위 연산 수 | 이론 최대치, 실제 모델 성능과 차이 큼 |
| TOPS/W | 전력 1W당 연산 성능 | 온디바이스에서 가장 중요 |
| 지연 시간 | 입력 1건 처리 시간 | 실시간 응용의 핵심 |
| 처리량 | 초당 처리 건수(FPS 등) | 배치 크기에 따라 달라짐 |
| 이용률 | 이론 성능 대비 실제 사용 비율 | 메모리 병목·연산자 미지원 시 낮아짐 |

**TOPS 수치만으로 NPU를 비교하면 안 된다.** 실제 모델에서의 지연 시간·전력과, 지원하는 연산자·정밀도·소프트웨어 도구(컴파일러)가 실사용 성능을 좌우한다.

### 소프트웨어 스택
NPU는 하드웨어만으로 쓸 수 없다. 학습된 모델(PyTorch 등)을 **양자화·연산자 변환·메모리 배치 최적화**를 거쳐 NPU 명령으로 바꾸는 **컴파일러와 런타임**이 필요하며, 이 소프트웨어 생태계가 GPU 대비 NPU 확산의 가장 큰 과제로 꼽힌다.

## 4. 연결 기출 토픽과 예상 변형

- **NPU**: 140회 1교시에 **NPU**가 출제됐다. 블로그 140회 분석에서는 AI 데이터센터 예측 카드(가속기)와 부분 적중으로 분류했다. 같은 개념이 "**GPU와 NPU 비교**"나 "**온디바이스 AI 가속기 설계**"로 변형돼 나올 수 있다.
- **메모리 벽**: 140회 3교시 **메모리 벽·CXL 3.0**이 출제됐다. NPU의 데이터 이동 최소화 설계는 메모리 벽 문제의 칩 내부 대응이다.
- **추론 인프라**: 140회 4교시 **AI 추론 인프라 벤치마크·전력효율**이 출제됐다. TOPS/W와 실제 성능 지표 비교로 연결된다.
- **양자화**: 139회 2교시 **터보퀀트**(TurboQuant)가 양자화 신기술로 출제됐다. NPU의 저정밀 연산 지원과 짝을 이룬다.

## 5. 답안 구성 예시

**단답형**(1교시, 1페이지)
- 정의: 신경망의 행렬 곱셈·누산(MAC)을 대량 병렬 처리하도록 특화한 AI 전용 프로세서
- 특징 3개: ① 시스톨릭 어레이 기반 MAC 배열 ② 온칩 SRAM·데이터 재사용으로 메모리 이동 최소화 ③ INT8 등 저정밀 연산으로 높은 TOPS/W
- 구성도 키워드: 명령 스케줄러 → 온칩 버퍼(가중치·입력·출력) → MAC 배열 → 활성화 유닛 → 외부 DRAM

**논술형(2~4교시) 목차**
1. 개요: 온디바이스·엣지 AI 확산과 전력 효율 요구
2. 구성/비교: NPU 내부 구성도, CPU·GPU·NPU 비교표, 성능 지표표
3. 적용방안: 데이터 흐름 최적화, 저정밀 양자화 지원, 연산 융합, 컴파일러·런타임 제공
4. 고려사항: 지원 연산자 제한(신규 모델 대응), TOPS 수치 착시, 소프트웨어 생태계, 메모리 대역폭
5. 기술사 제언: NPU 도입·평가는 **실제 대상 모델의 지연 시간과 전력**으로 판단하고, 하드웨어와 함께 컴파일러·모델 변환 도구의 성숙도를 핵심 평가 항목으로 둘 것
