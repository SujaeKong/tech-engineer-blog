## 1. 뉴스 요약

스타트업엔(11-12)은 **인포시즈가 서울대와 산업 도면 전체를 읽는 AI를 개발하기 위해 '이미지 투 그래프(Image-to-Graph)' 공동 연구**를 시작했다고 보도했고, 퍼블릭타임스(11-11)는 이를 **산업 도면을 읽는 AI 파운데이션 모델 공동 연구 착수**로 전했다. 플랜트·제조 현장에는 수십 년간 쌓인 종이·스캔 도면이 많지만, 그림 형태로만 남아 있어 **검색·분석·디지털 트윈 구축에 바로 쓰기 어렵다**. 연구의 모델 구조와 대상 도면 종류는 제목 이상으로 확인되지 않으므로, 아래에서는 **도면을 구조화된 그래프로 바꾸는 AI**의 일반 구조를 정리한다.

## 2. 핵심 개념

### 정의
**이미지 투 그래프**는 도면 이미지에서 장비·밸브·계기 같은 **구성요소를 노드**(Node)로, 배관·배선·신호선 같은 **연결 관계를 엣지**(Edge)로 추출해 **기계가 읽을 수 있는 그래프 데이터**로 변환하는 기술이다. 단순히 그림 속 글자를 읽는 OCR을 넘어, "**무엇이 무엇과 어떻게 연결되어 있는가**"라는 구조 정보를 복원한다는 점이 핵심 차이다.

### 구성도 — 도면 이미지에서 그래프까지

```
 [입력]  스캔 도면 · PDF · CAD 출력 이미지 (P&ID, 회로도, 건축·설비 도면)
    │
    ▼
 [전처리]  해상도 보정 · 기울기 보정 · 잡음 제거 · 도면 영역/범례 분리
    │
    ▼
 [요소 인식]
   ├ 심볼 인식: 펌프·밸브·계기 등 객체 탐지
   ├ 문자 인식(OCR): 태그 번호·사양·주석
   └ 선 인식: 배관·신호선 검출, 교차·분기·화살표 판별
    │
    ▼
 [관계 추론]  선을 따라 연결 추적 → 심볼·문자 연결 → 노드·엣지 생성
    │
    ▼
 [그래프 출력]  노드(장비·태그·속성) + 엣지(연결 유형·방향)
    │
    ▼
 [활용]  지식그래프 · 디지털 트윈 · 설계 검증 · 자재 목록 · 변경 영향 분석
```

### OCR 중심 디지털화 vs 이미지 투 그래프

| 구분 | OCR 중심 디지털화 | 이미지 투 그래프 |
|---|---|---|
| 추출 대상 | 글자·숫자 | 구성요소 + 연결 관계 + 속성 |
| 결과물 | 텍스트 목록 | 그래프(노드·엣지) |
| 검색 | 키워드 검색 | "이 밸브 하류의 모든 장비" 같은 경로 질의 |
| 분석 | 제한적 | 연결성·영향 범위·순환 구조 분석 |
| 디지털 트윈 연계 | 수작업 필요 | 구조 데이터로 직접 연계 |
| 난이도 | 상대적으로 낮음 | 선 교차·겹침 해석 등 높음 |

### 도면 이해가 어려운 이유

| 난제 | 내용 | 대응 |
|---|---|---|
| 심볼 다양성 | 회사·업종마다 표기 관행이 다름 | 표준 심볼 학습 + 기업별 미세조정 |
| 선 교차·겹침 | 교차인지 연결인지 구분 어려움 | 교차 표기 규칙 학습, 맥락 기반 판단 |
| 저품질 스캔 | 오래된 도면의 흐림·얼룩 | 전처리·복원 모델 |
| 대형 도면 | 한 장에 수백 개 요소, 고해상도 | 분할 처리 후 결과 병합 |
| 학습 데이터 부족 | 정답 그래프 라벨링 비용 큼 | 합성 도면 생성, 반자동 라벨링 |
| 보안 | 설비 도면은 기업 기밀 | 사내 구축·데이터 반출 통제 |

### 평가 지표
- **노드 탐지 정밀도·재현율**: 구성요소를 빠짐없이, 잘못 없이 찾았는가
- **엣지 정확도**: 연결 관계를 올바르게 복원했는가 — 노드보다 어렵고 실무 가치가 큼
- **그래프 편집 거리**: 정답 그래프로 바꾸는 데 필요한 수정 횟수
- **사람 검수 시간**: 결과를 수정하는 데 걸리는 시간 — 현장 도입 판단의 실질 지표

### 관련 기준
- **ISO 10628**: 공정 플랜트 흐름도(P&ID 포함) 작성 기준
- **ISA-5.1**: 계기 심볼·식별 표기 표준
- 도면 표기 표준이 있어도 실제 도면은 기업별 변형이 많아, **표준 기반 학습 + 현장 데이터 보정**이 함께 필요하다.

## 3. 기술사 출제 포인트

- 이미지 투 그래프의 정의(노드·엣지 구조 복원)
- 도면 디지털화 처리 단계(전처리·심볼·문자·선 인식·관계 추론)
- OCR 중심 디지털화와 그래프 변환 비교
- 객체 탐지·OCR·선 추적의 결합(멀티 태스크)
- 선 교차·겹침·저품질 스캔 등 난제와 대응
- 합성 도면·반자동 라벨링으로 학습 데이터 확보
- 노드·엣지 정확도와 그래프 편집 거리 평가
- 지식그래프·디지털 트윈과의 연계
- 설비 도면의 기밀성과 사내 구축

## 4. 연결 기출 토픽과 예상 변형

- **지식그래프**: 블로그의 140회 예측 카드로 정리한 **지식그래프·GraphRAG·온톨로지** 주제와 직접 이어진다. 도면에서 추출한 그래프는 산업 지식그래프의 원천 데이터가 된다.
- **멀티모달 데이터 품질**: 140회 4교시 **멀티모달 데이터 품질검증**이 출제됐다. 이미지와 구조 정보가 함께 있는 도면 데이터의 라벨 품질 관리로 연결된다.
- **합성데이터**: 140회 3교시 **합성데이터 생성·품질 평가**가 출제됐다. 정답 그래프가 있는 합성 도면은 이 문항의 실무 사례다.
- **멀티모달**: 블로그 통합 기출 분석(`exam_trend_integrated.json`) 기준 **멀티모달은 기출 6회** 키워드다.
- **예상 변형**
  - 1교시: "문서 이해(Document AI)에서 이미지 투 그래프 기술을 설명하시오"
  - 1교시: "그래프 데이터의 노드·엣지 기반 분석 활용을 설명하시오"
  - 논술: "산업 도면 디지털화를 통한 디지털 트윈 구축 방안과 데이터 품질 확보 방안을 제시하시오"

## 5. 답안 구성 예시

**단답형**(1교시, 1페이지)
- 정의: 도면 이미지에서 구성요소(노드)와 연결 관계(엣지)를 추출해 그래프 데이터로 변환하는 기술
- 특징 3개: ① 심볼·문자·선 인식 결합 ② 연결 구조 복원으로 경로 질의 가능 ③ 지식그래프·디지털 트윈 연계
- 구성도 키워드: 도면 이미지 → 전처리 → 심볼·OCR·선 인식 → 관계 추론 → 그래프 → 디지털 트윈

**논술형(2~4교시) 목차**
1. 개요: 종이·스캔 도면의 활용 한계와 산업 도면 이해 AI 연구
2. 구성/비교: 처리 단계 구성도, OCR vs 이미지 투 그래프 비교표, 난제·대응표
3. 적용방안: 표준 심볼 기반 사전학습 + 기업별 보정, 합성 도면 학습, 사람 검수 루프, 지식그래프 적재
4. 고려사항: 엣지 오류의 파급(잘못된 연결은 안전 문제), 기업별 표기 변형, 기밀 도면 보안, 검수 비용
5. 기술사 제언: 성과를 노드 인식률이 아니라 **엣지 정확도와 사람 검수 시간 절감**으로 측정하고, 안전 관련 연결 정보는 반드시 사람이 최종 확인하는 절차를 둘 것
