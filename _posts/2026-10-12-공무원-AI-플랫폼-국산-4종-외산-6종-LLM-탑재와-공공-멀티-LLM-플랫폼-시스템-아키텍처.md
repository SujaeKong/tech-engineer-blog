## 1. 뉴스 요약

2026-10-12 공무원이 쓰는 AI 플랫폼에 **국산 LLM 4종과 외산 LLM 6종**이 탑재되고, 삼성SDS와 네이버가 구축을 맡는다. 특정 모델 하나에 의존하지 않고 **업무 성격에 맞춰 여러 모델을 골라 쓰는** 구조다.

이는 공공 AI가 단일 챗봇을 넘어 **여러 모델을 통합 관리하는 플랫폼**으로 진화함을 보여준다. 멀티 LLM 플랫폼 아키텍처는 정보관리기술사 시스템구조 영역과 직결된다.

## 2. 핵심 개념

### 왜 멀티 LLM인가
모델마다 **성능·비용·언어·보안 특성**이 다르다. 한 모델에 묶이면 장애·가격 인상·정책 변경에 취약하다. 여러 모델을 두면 업무별 최적 선택과 **벤더 종속 회피**가 가능하다.

### 멀티 LLM 플랫폼 계층

| 계층 | 역할 |
|---|---|
| 사용자 | 공무원 포털·업무 연계 |
| 게이트웨이 | 인증·라우팅·정책 적용 |
| 모델 | 국산·외산 LLM 풀 |
| 통제 | 로깅·필터·데이터 등급 관리 |

### 공공 멀티 LLM 시스템 아키텍처 관점
핵심은 **모델 앞에 공통 게이트웨이를 두는 것**이다. ① 단일 진입점에서 인증과 권한을 확인하고, ② 업무 유형·데이터 보안 등급에 따라 모델을 라우팅하며(민감 데이터는 내부망의 국산 모델로), ③ 입출력 필터와 개인정보 마스킹을 공통 적용하고, ④ 모든 요청을 로깅해 감사와 비용 배분에 쓴다. 외산 모델은 **데이터가 해외로 나가지 않도록** 정부 전용 리전이나 망 분리 조건을 갖춰야 한다. 관건은 모델 간 품질 편차 관리, 비용 통제, 그리고 보안 등급별 접근 정책이다.

## 3. 기술사 출제 포인트

- 멀티 LLM 전략의 장점(최적 선택·벤더 종속 회피)
- LLM 게이트웨이의 역할(인증·라우팅·정책·로깅)
- 데이터 보안 등급 기반 모델 라우팅과 망 분리
- 공통 입출력 필터·개인정보 마스킹과 감사 로그
- 국산·외산 모델 혼용과 소버린 AI 관점의 고려사항
