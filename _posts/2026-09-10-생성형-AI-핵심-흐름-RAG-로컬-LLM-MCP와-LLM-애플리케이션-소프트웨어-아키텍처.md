## 1. 뉴스 요약

2026-09-10 생성형 AI 개발의 핵심 흐름이 **RAG·로컬(온프레미스) LLM·MCP** 세 축으로 정리되고 있다는 분석이 나왔다. 단순 프롬프트를 넘어, **외부 지식 연결(RAG)·자체 운영(로컬 LLM)·도구 표준 연동(MCP)**으로 실용적 AI 애플리케이션을 만드는 방식이다.

이는 LLM이 **모델 그 자체보다 응용 아키텍처**로 승부하는 단계에 접어들었음을 보여준다. LLM 애플리케이션 소프트웨어 아키텍처는 정보관리기술사 소프트웨어공학 영역과 직결된다.

## 2. 핵심 개념

### 세 축의 역할
**RAG**는 외부 지식으로 환각을 줄이고, **로컬 LLM**은 데이터 주권·보안을 확보하며, **MCP(Model Context Protocol)**는 LLM과 도구·데이터를 표준 방식으로 연결한다.

### 핵심 구성 요소

| 요소 | 내용 |
|---|---|
| RAG | 검색증강·근거 기반 생성 |
| 로컬 LLM | 온프레미스·데이터 주권 |
| MCP | 표준 도구·데이터 연동 |
| 오케스트레이션 | 에이전트·파이프라인 |

### 애플리케이션 아키텍처 관점
핵심은 **모델을 감싸는 응용 계층 설계**다. ① RAG로 사내 지식·최신 데이터를 근거로 붙여 환각을 줄이고, ② 로컬 LLM으로 민감 데이터를 외부로 보내지 않으며, ③ MCP로 도구·데이터 소스를 표준 인터페이스로 연동하고, ④ 오케스트레이션으로 검색·추론·툴 호출을 조율한다. 관건은 검색 품질(청킹·임베딩), 보안·거버넌스, 그리고 평가·관측성(옵저버빌리티)이다.

## 3. 기술사 출제 포인트

- RAG(검색증강생성)의 구조와 환각 저감
- 로컬(온프레미스) LLM과 데이터 주권·보안
- MCP(Model Context Protocol)와 표준 도구·데이터 연동
- 에이전트 오케스트레이션과 LLM 파이프라인
- LLM 애플리케이션의 평가·관측성(옵저버빌리티)
