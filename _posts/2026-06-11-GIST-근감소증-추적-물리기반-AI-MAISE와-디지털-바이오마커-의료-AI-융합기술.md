## 1. 뉴스 요약

2026-06-09 GIST(광주과학기술원)·KIST·전남대병원 공동 연구팀이 **일상 동작만으로 근감소증(sarcopenia) 진행을 추적하는 물리 기반 AI 프레임워크 'MAISE'**를 개발했다고 연합뉴스·인공지능신문 등 다수 매체가 보도했다. 걷기 같은 일상 움직임 데이터에서 근골격계의 물리적 특성을 추정해, 병원 장비 검사 없이도 **근육 기능 저하를 비침습적으로 모니터링**할 수 있다.

핵심은 데이터만으로 학습하는 블랙박스 AI가 아니라 **인체 역학(물리 법칙)을 모델에 내재화한 물리 기반 AI(physics-informed AI)** 접근이라는 점이다. 의료 데이터는 수집 비용이 높고 환자별 편차가 커서 순수 데이터 기반 학습이 어려운데, 물리 모델을 결합하면 **적은 데이터로도 일반화 성능과 설명가능성**을 확보할 수 있다. 헬스케어·웨어러블·AI가 결합된 융합 신기술로서 출제 가치가 높다.

## 2. 핵심 개념

### 물리 기반 AI(Physics-Informed AI)

물리 기반 AI는 **지배 방정식·물리 법칙을 신경망 학습에 제약조건이나 구조로 내재화**하는 접근이다. 대표적으로 PINN(Physics-Informed Neural Network)은 손실함수에 물리 방정식 잔차를 포함해, 데이터가 부족해도 물리적으로 타당한 해를 학습한다.

| 구분 | 순수 데이터 기반 AI | 물리 기반 AI |
|---|---|---|
| 학습 근거 | 대규모 데이터 패턴 | 데이터 + 물리 법칙 |
| 데이터 요구량 | 많음 | 상대적으로 적음 |
| 외삽(미관측 영역) | 취약 | 물리 제약으로 안정적 |
| 설명가능성 | 낮음(블랙박스) | 물리 변수로 해석 가능 |

### 디지털 바이오마커(Digital Biomarker)

디지털 바이오마커는 **웨어러블·스마트폰 등 디지털 기기로 수집한 생체·행동 데이터에서 추출하는 건강 지표**다. 보행 속도·움직임 패턴 같은 일상 데이터를 연속적으로 측정해, 병원 내원 시점에만 측정하는 전통 검사와 달리 **질병 진행을 조기·연속적으로 추적**할 수 있다. 근감소증처럼 서서히 진행되는 노인성 질환 관리에 효과적이다.

### 비침습 연속 모니터링 시스템의 구성

일상 동작 기반 건강 모니터링은 **센서 계층(IMU·웨어러블) → 데이터 수집·전처리(시계열 정제) → AI 추론(물리 기반 모델로 근기능 지표 추정) → 임상 연계(이상 징후 시 의료진 알림)**의 파이프라인으로 구성된다. 개인 건강정보를 다루므로 가명처리·온디바이스 처리 등 프라이버시 보호 설계가 병행돼야 한다.

## 3. 기술사 출제 포인트

- 물리 기반 AI(PINN)의 개념과 필요성
- 순수 데이터 기반 AI와 물리 기반 AI의 비교
- 디지털 바이오마커의 정의와 전통 임상 검사 대비 특징
- 일상 동작 기반 비침습 건강 모니터링 시스템의 구성요소
- 의료 AI 도입 시 고려사항(데이터 부족, 설명가능성, 임상 검증, 개인건강정보 보호)
- 웨어러블·IoT·AI 융합 디지털 헬스케어 서비스 아키텍처
