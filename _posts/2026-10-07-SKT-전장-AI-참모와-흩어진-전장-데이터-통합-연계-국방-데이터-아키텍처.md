## 1. 뉴스 요약

2026-10-07 SKT가 전장에 **'AI 참모'**를 띄워 **흩어진 데이터를 한눈에** 보여주겠다고 밝혔다. 정찰·감시 장비, 부대 보고, 군수·기상 정보가 **서로 다른 체계에 따로 저장**돼 있어 지휘관이 상황을 종합하기 어렵다는 문제를, 데이터를 통합해 AI가 요약·분석하는 방식으로 풀겠다는 것이다.

이는 국방 AI의 첫 관문이 모델이 아니라 **분산된 데이터의 통합·연계**임을 보여준다. 이기종 데이터 통합 아키텍처는 정보관리기술사 데이터베이스 영역과 직결된다.

## 2. 핵심 개념

### 데이터 사일로 문제
체계마다 **데이터 형식·용어·좌표계·시간 기준**이 달라 그대로 합칠 수 없다. 같은 표적·부대를 서로 다른 이름과 코드로 기록하기도 한다.

### 데이터 통합 방식 비교

| 방식 | 특징 |
|---|---|
| 물리 통합 | 데이터웨어하우스·레이크로 적재 |
| 가상 통합 | 원천 유지·조회 시 연계 |
| 데이터 허브 | 표준 인터페이스로 중계 |
| 공통 모델 | 용어·코드·스키마 표준화 |

### 국방 데이터 통합 아키텍처 관점
핵심은 **표준화된 의미로 묶되, 보안 경계를 지키는 것**이다. ① 공통 데이터 모델과 표준 용어·코드로 이기종 체계의 의미를 맞추고, ② 실시간성이 필요한 정보는 가상 통합·스트리밍으로, 분석용 이력은 레이크로 물리 통합하며, ③ 메타데이터로 출처·시각·신뢰도를 기록해 AI 판단의 근거를 남기고, ④ **보안 등급별 접근 통제**로 기밀 데이터의 확산을 막는다. 같은 대상을 하나로 묶는 **엔터티 해석(entity resolution)**이 정확도를 좌우한다. 관건은 표준 합의, 실시간 동기화, 그리고 보안과 활용의 균형이다.

## 3. 기술사 출제 포인트

- 데이터 사일로와 이기종 데이터 통합의 필요성
- 물리 통합·가상 통합·데이터 허브 방식 비교
- 공통 데이터 모델·표준 용어·코드 체계
- 메타데이터(출처·시각·신뢰도)와 데이터 계보
- 보안 등급 기반 접근 통제와 엔터티 해석
