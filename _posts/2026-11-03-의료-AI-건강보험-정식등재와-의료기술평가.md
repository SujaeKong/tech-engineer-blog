## 1. 뉴스 요약

의학신문(11-01)은 **의료 AI의 건강보험 정식등재가 내년 1분기 윤곽을 드러내며, 임시등재로 시장에 들어온 기업들에게 전환의 분수령이 될 것**이라고 보도했다. 앞서 전자신문(10-29)은 **한국보건의료연구원(NECA)이 다음 달 16일 'AI 의료기술 정책 세미나'를 연다**고 전했다. 기술이 허가를 받아도 병원이 비용을 보전받을 수 있는 **수가 체계**에 들어가지 못하면 현장 확산이 어렵다는 점에서, 정식등재는 의료 AI 산업의 사업성을 좌우하는 관문이다. 대상 제품과 평가 결과는 제목 이상으로 확인되지 않으므로, 아래에서는 **의료 AI의 시장 진입 단계와 의료기술평가의 판단 구조**를 정리한다.

## 2. 핵심 개념

### 정의
**의료기술평가**(HTA, Health Technology Assessment)는 새로운 의료기술이 **안전한지, 효과가 있는지, 비용에 비해 가치가 있는지**를 근거에 기반해 평가하고, 건강보험 적용 여부와 가격 결정의 근거를 제공하는 체계다. 의료 AI의 **임시등재**는 근거가 충분히 쌓이기 전이라도 일정 기간 현장 사용을 허용하고, 그 기간에 축적한 **실사용 근거**로 정식등재 여부를 판단하는 단계적 진입 방식으로 이해할 수 있다.

### 구성도 — 의료 AI의 시장 진입 단계

```
 [개발·임상 검증]  성능 검증(민감도·특이도) · 임상시험
        │
        ▼
 [인허가]  식약처: 의료기기로서 안전성·성능 허가
        │       "기계로서 제대로 작동하는가"
        ▼
 [의료기술평가]  NECA 등: 임상적 안전성·유효성 평가
        │       "환자에게 실제로 도움이 되는가"
        ▼
 [임시등재]  한시적 현장 사용 허용 → 실사용 데이터·근거 축적
        │
        ▼
 [정식등재 판단]  건강보험 적용 여부 · 수가 수준 결정
        │       "비용을 지불할 가치가 있는가"
        ▼
 [확산·사후관리]  사용량 모니터링 · 재평가 · 성능 변화 관리
```

각 단계가 묻는 질문이 다르다는 점이 답안의 핵심이다. 허가는 **작동하는지**, 의료기술평가는 **환자에게 도움이 되는지**, 등재는 **지불할 가치가 있는지**를 판단한다.

### 단계별 판단 기준 비교

| 단계 | 주관 | 판단 질문 | 주요 근거 |
|---|---|---|---|
| 인허가 | 식약처 | 기기로서 안전·정확한가 | 성능 시험, 임상시험 |
| 의료기술평가 | NECA 등 | 환자 결과를 개선하는가 | 임상 연구, 문헌 근거 |
| 임시등재 | 보건당국 | 근거 축적 기간을 줄 만한가 | 혁신성, 잠재 효과 |
| 정식등재 | 건강보험 당국 | 비용 대비 가치가 있는가 | 실사용 근거, 비용효과 분석 |
| 사후관리 | 다수 기관 | 성능이 유지되는가 | 사용 데이터, 재평가 |

### 의료 AI 평가가 어려운 이유

| 쟁점 | 내용 |
|---|---|
| 성능 ≠ 환자 결과 | 판독 정확도가 높아도 진단·치료 결과 개선으로 이어지는지 별도 입증 필요 |
| 보조 도구 특성 | 의사의 판단을 돕는 도구라 AI 단독 효과를 분리하기 어려움 |
| 성능 변화 | 재학습·업데이트로 제품이 바뀌어 평가 시점과 사용 시점의 성능이 달라질 수 있음 |
| 데이터 대표성 | 특정 병원·장비 데이터로 만든 모델이 다른 환경에서 성능 저하 |
| 비용 구조 | 행위별 수가 체계에서 "AI 사용"을 어떤 단위로 보상할지 불명확 |

### 사업 모델 관점
- **수가 의존형**: 건강보험 등재로 사용 건당 보상 — 등재 실패 시 매출 기반 붕괴 위험
- **병원 구매형**(B2B): 병원이 업무 효율을 이유로 직접 구매 — 수가 없이도 성립하지만 확산 속도 제한
- **해외 진출형**: 국가별 인허가·보험 체계 대응 필요
- 임시등재 기간은 **근거를 만드는 기간**이자, 수가 없이 버틸 수 있는 **재무 체력을 시험하는 기간**이기도 하다.

### 관련 제도·기준
- **의료기기법·디지털의료제품법**: 의료 AI의 의료기기 허가 근거
- **신의료기술평가 제도**: 새로운 의료기술의 안전성·유효성 평가(NECA 수행)
- **실사용 증거**(RWE): 실제 진료 데이터로 만든 근거 — 임시 사용 기간의 핵심 산출물
- **인공지능기본법**: 의료 분야 AI는 고영향 AI 영역으로 사업자 책무 적용

## 3. 기술사 출제 포인트

- 의료기술평가(HTA)의 정의와 판단 기준(안전성·유효성·비용효과성)
- 의료 AI 시장 진입 단계(인허가→기술평가→임시등재→정식등재)
- 단계별 판단 질문의 차이(작동·도움·가치)
- 임시등재와 실사용 증거(RWE) 축적
- 성능 지표와 환자 결과 개선의 차이
- 재학습에 따른 성능 변화와 사후관리
- 데이터 대표성과 다기관 검증
- 수가 의존형·병원 구매형 사업 모델 비교
- 고영향 AI로서 의료 AI의 규제 연계

## 4. 연결 기출 토픽과 예상 변형

- **고영향 AI**: 140회 3교시 **인공지능기본법의 고영향 인공지능**이 출제됐다. 의료 AI는 고영향 AI의 대표 영역으로, "규제 → 시장 진입 → 보상" 흐름을 함께 묻는 변형이 가능하다.
- **AI 기반 업무 혁신**: 140회 1교시 **AI 기반 BPR 도입 효과**가 출제됐다. 의료 AI 도입 효과를 어떻게 측정·보상할지는 BPR 효과 측정의 의료 분야 버전이다.
- **데이터 가치평가**: 139회 2교시 **데이터 가치평가 및 데이터 자산화**가 출제됐다. 실사용 데이터가 정식등재의 근거가 된다는 점에서 데이터 자산의 가치를 보여주는 사례다.
- **AX**: 블로그 통합 기출 분석(`exam_trend_integrated.json`) 기준 **AX는 기출 4회** 키워드다. 의료 AX 확산의 병목을 묻는 문항으로 연결된다.
- **예상 변형**
  - 1교시: "의료기술평가(HTA)의 개념과 평가 요소를 설명하시오"
  - 1교시: "실사용 증거(Real-World Evidence)의 개념과 활용을 설명하시오"
  - 논술: "의료 AI의 시장 진입과 확산을 위한 평가·보상 체계의 개선 방안을 논하시오"

## 5. 답안 구성 예시

**단답형**(1교시, 1페이지)
- 정의: 신의료기술의 안전성·유효성·비용효과성을 근거로 평가해 보험 적용과 가격 결정의 근거를 제공하는 체계
- 특징 3개: ① 단계별로 다른 판단 질문(작동·도움·가치) ② 임시등재 기간의 실사용 근거 축적 ③ 사후 재평가로 성능 변화 관리
- 구성도 키워드: 개발·임상 → 인허가 → 의료기술평가 → 임시등재(RWE) → 정식등재(수가) → 사후관리

**논술형(2~4교시) 목차**
1. 개요: 허가받은 의료 AI가 현장에 퍼지지 못하는 이유, 정식등재의 의미
2. 구성/비교: 시장 진입 단계 구성도, 단계별 판단 기준표, 평가 쟁점표
3. 적용방안: 임시등재 기간 근거 축적 설계, 다기관 실사용 데이터 수집, 성과 기반 수가, 사후 재평가 주기
4. 고려사항: 성능과 환자 결과의 괴리, 업데이트 관리, 데이터 대표성, 기업 재무 지속성
5. 기술사 제언: 임시등재를 "유예 기간"이 아니라 **사전에 합의된 평가 지표로 근거를 쌓는 실증 기간**으로 설계하고, 정식등재 이후에도 성능·사용 데이터를 연동한 재평가 체계를 갖출 것
