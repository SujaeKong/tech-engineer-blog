## 1. 뉴스 요약

2026-06-20 인공지능신문은 **전남대-마틸로AI 연구진이 스캐폴드(scaffold) 구조를 반영한 생성형 AI 모델로 신약 후보물질을 설계**하는 기술을 개발했다고 보도했다. 신약 개발은 후보물질을 찾는 데만 수년·수천억이 드는데, 탐색해야 할 분자 공간이 10^60 규모로 사실상 무한하다. 연구진은 약효의 핵심 골격인 **스캐폴드를 고정한 채 주변 구조를 생성**하도록 모델을 설계해, 의미 없는 분자를 남발하지 않고 **유효한 후보군을 집중 생성**하는 데 초점을 맞췄다.

이 뉴스는 단순 연구 성과를 넘어 **'생성형 AI를 과학·산업 데이터에 어떻게 적용할 것인가'**라는 데이터 분석의 본질적 주제를 보여준다. 텍스트·이미지 생성에 머물던 생성형 AI가 **분자·단백질 같은 구조화된 과학 데이터(AI for Science)**로 확장되는 흐름으로, 도메인 제약을 학습에 결합하는 설계가 핵심이다. 정보관리기술사 AI데이터분석 영역의 생성모델·표현학습·도메인 데이터 활용 주제와 직결된다.

## 2. 핵심 개념

### 분자 표현과 스캐폴드
분자는 **SMILES 문자열**이나 원자를 노드·결합을 엣지로 보는 **그래프**로 표현된다. **스캐폴드**는 분자에서 약효를 좌우하는 핵심 골격으로, 이를 고정하면 생성 공간을 약리학적으로 의미 있는 영역으로 제한할 수 있다.

### 생성 모델 계열
분자 생성에는 여러 모델이 쓰인다. **VAE/GAN**은 잠재공간에서 분자를 복원·생성하고, **그래프 신경망(GNN)**은 분자 그래프 구조를 직접 학습하며, **확산모델(diffusion)**은 노이즈에서 점진적으로 구조를 복원한다. 스캐폴드 조건을 부여하면 **조건부 생성(conditional generation)**이 된다.

### 강화학습 기반 속성 최적화
생성된 분자가 흡수·독성·결합력 등 원하는 속성을 갖도록 **강화학습**으로 보상을 주어 최적화한다. 생성-평가-피드백 루프를 통해 후보물질의 품질을 끌어올린다.

### 전통 탐색과 생성형 AI 비교

| 구분 | 전통적 탐색(HTS) | 생성형 AI 설계 |
|------|------------------|----------------|
| 방식 | 기존 라이브러리 스크리닝 | 신규 분자 직접 생성 |
| 탐색 공간 | 제한된 후보군 | 광대한 화학 공간 |
| 도메인 제약 | 사후 필터링 | 생성 단계에 내재화 |
| 속도·비용 | 느림·고비용 | 후보 압축으로 단축 |
| 한계 | 신규성 부족 | 검증·합성 가능성 |

## 3. 기술사 출제 포인트

- **분자 데이터 표현 방식**: SMILES·분자 그래프 표현과 스캐폴드 기반 조건 부여의 의미
- **생성 모델 계열 비교**: VAE·GAN·GNN·확산모델의 원리와 분자 생성에의 적합성
- **조건부 생성과 도메인 지식 결합**: 약리학적 제약을 생성 단계에 내재화하는 설계와 그 효과
- **강화학습 기반 속성 최적화**: 생성-평가-피드백 루프와 보상 설계, 다목적 최적화 고려
- **AI for Science 확장**: 생성형 AI가 과학·산업의 구조화 데이터로 확장되는 패러다임과 데이터 품질·검증의 중요성
- **도입 시 고려사항**: 생성 결과의 합성 가능성·신뢰성 검증, 데이터 편향, 실험 검증과의 연계
