## 1. 뉴스 요약

데일리안(11-02)은 **KT와 삼성전자가 AI로 무선망을 자율 운용하는 기술을 검증**했다고 보도했다. 이동통신 기지국은 수만 개에 이르고 트래픽은 시간·장소에 따라 크게 출렁이기 때문에, 사람이 설정을 일일이 바꾸는 방식으로는 품질과 에너지 효율을 함께 잡기 어렵다. 검증 항목과 성과 수치는 제목 이상으로 확인되지 않으므로, 아래에서는 **무선망 자율운용의 구조**를 기존 SON과 O-RAN의 지능형 제어기(RIC) 중심으로 정리한다.

## 2. 핵심 개념

### 정의
**무선망 자율운용**은 기지국과 무선 접속망(RAN)의 상태를 실시간으로 수집·분석해 **설정 최적화, 장애 복구, 에너지 절감을 사람의 개입을 최소화한 채 자동으로 수행**하는 운용 방식이다. 과거에는 장비 제조사의 SON(Self-Organizing Network) 기능에 의존했다면, 최근에는 **O-RAN 표준의 RIC**(RAN Intelligent Controller) 위에 AI 애플리케이션을 올려 제조사와 무관하게 망을 제어하는 구조가 주목받는다.

### 구성도 — O-RAN 지능형 제어 구조

```
 ┌──────────────── SMO (서비스 관리·오케스트레이션) ────────────────┐
 │  Non-RT RIC  (제어 주기 1초 이상)                                │
 │   └ rApp: 장기 트래픽 예측 · 정책 수립 · AI 모델 학습·배포       │
 └──────────┬────────────────────────────────────┬─────────────────┘
            │ A1 (정책·모델 전달)                │ O1 (설정·성능 관리)
            ▼                                    │
 ┌──────── Near-RT RIC (제어 주기 10ms ~ 1초) ───┼─────────────────┐
 │   └ xApp: 트래픽 분산 · 간섭 관리 · 셀 on/off 결정             │
 └──────────┬────────────────────────────────────┼─────────────────┘
            │ E2 (실시간 측정·제어)              │
            ▼                                    ▼
   ┌─────────┐   ┌─────────┐   ┌─────────┐
   │  O-CU   │───│  O-DU   │───│  O-RU   │ ── 단말
   └─────────┘   └─────────┘   └─────────┘
          (개방형 프런트홀로 장비 제조사 혼합 가능)
```

제어 주기에 따라 역할이 나뉜다는 점이 핵심이다. **느린 판단(정책·예측·학습)은 Non-RT RIC**, **빠른 판단(초 이하 제어)은 Near-RT RIC**, **밀리초 미만의 스케줄링은 기지국 내부**(O-DU)가 맡는다.

### SON vs O-RAN RIC

| 구분 | SON(Self-Organizing Network) | O-RAN RIC |
|---|---|---|
| 표준 | 3GPP(LTE 시절부터) | O-RAN Alliance |
| 구현 주체 | 주로 장비 제조사 내장 | 제3자 앱(xApp·rApp) 탑재 |
| 기능 범위 | 자가설정·자가최적화·자가치유 | 정책 기반 제어 + AI 모델 운영 |
| 제조사 종속 | 높음 | 낮음(개방 인터페이스) |
| AI 적용 | 규칙·제한적 최적화 | 학습 모델 배포·갱신 구조 내장 |
| 제어 주기 | 기능별 상이 | Non-RT(1초+)·Near-RT(10ms~1s) 계층화 |
| 과제 | 다중 제조사 환경 통합 어려움 | 앱 간 충돌·검증·보안 |

### 대표 활용 사례

| 활용 | 내용 | 효과 |
|---|---|---|
| 에너지 절감 | 트래픽 적은 시간대에 셀·안테나 일부를 잠재움 | 전력 비용 절감 |
| 트래픽 스티어링 | 혼잡 셀의 단말을 여유 셀·주파수로 분산 | 체감 속도 개선 |
| 간섭 관리 | 인접 셀 출력·빔 조정 | 셀 경계 품질 개선 |
| 이상 탐지·자가치유 | 성능 지표 급락 감지 후 자동 조치 | 장애 복구 시간 단축 |
| 커버리지 최적화 | 안테나 틸트·출력 자동 조정 | 음영 지역 축소 |

### 검증이 필요한 이유
- **앱 간 충돌**: 에너지 절감 앱은 셀을 끄려 하고, 품질 앱은 켜려 한다. 여러 xApp의 결정을 조정하는 **충돌 관리**가 필요하다.
- **오작동의 파급**: 잘못된 결정은 수천 명의 통화 품질에 즉시 영향을 준다. 디지털 트윈·제한 구역 시험 후 단계적으로 적용한다.
- **보안**: RIC와 개방 인터페이스는 새로운 공격면이다. 앱 서명·권한 통제·인터페이스 보호가 필요하다.

### 관련 표준
- **O-RAN Alliance 규격**: RIC 구조, A1·E2·O1 인터페이스, 개방형 프런트홀(7.2x 분할)
- **3GPP SON**: 자가설정·자가최적화·자가치유 기능 정의
- **3GPP NWDAF**: 5G 코어의 네트워크 데이터 분석 기능 — RAN과 코어 양쪽에서 AI 분석 결합
- **TM Forum 자율 네트워크 수준**(L0~L5): 운용 자동화 단계 구분

## 4. 연결 기출 토픽과 예상 변형

- **5G**: 블로그 통합 기출 분석(`exam_trend_integrated.json`) 기준 **5G는 기출 13회**로 네트워크 최빈출 키워드다. 5G 문항에서 RAN 개방화(O-RAN)는 코어(SBA)와 짝을 이루는 하위 주제다.
- **다중접속·스케줄링**: 140회 3교시 **CSMA/CA·CDMA·TDMA**, 2교시 **FIFO vs WFQ**가 출제됐다. 무선 자원 스케줄링과 트래픽 분산은 같은 기본기 위에 있다.
- **자율운영 네트워크**: 의도기반 네트워킹(IBN)이 운용자의 의도를 설정으로 번역한다면, RIC는 그 의도를 무선 구간에서 실시간으로 실행하는 계층이다. 두 개념을 묶은 "자율 네트워크 구조" 문항이 가능하다.
- **예상 변형**
  - 1교시: "O-RAN의 RIC(RAN Intelligent Controller) 구조를 설명하시오"
  - 1교시: "SON(Self-Organizing Network)의 기능을 설명하시오"
  - 논술: "AI 기반 무선망 자율운용 체계의 구조와 도입 시 검증·보안 고려사항을 논하시오"

## 5. 답안 구성 예시

**단답형**(1교시, 1페이지)
- 정의: RAN 상태를 실시간 분석해 설정 최적화·복구·에너지 절감을 자동 수행하는 운용, O-RAN RIC가 기반
- 특징 3개: ① 제어 주기별 계층화(Non-RT·Near-RT) ② rApp·xApp 개방 생태계 ③ A1·E2 표준 인터페이스
- 구성도 키워드: SMO(Non-RT RIC·rApp) → A1 → Near-RT RIC(xApp) → E2 → O-CU·O-DU·O-RU

**논술형(2~4교시) 목차**
1. 개요: 기지국 규모 증가와 수동 운용의 한계, 에너지 비용 압박
2. 구성/비교: RIC 구성도, SON vs RIC 비교표, 활용 사례표
3. 적용방안: 에너지 절감·트래픽 분산 우선 적용, 디지털 트윈 사전 검증, 앱 충돌 관리 정책, 단계적 지역 확대
4. 고려사항: 다중 제조사 연동, 앱 검증·인증, 개방 인터페이스 보안, 운용 조직 역량
5. 기술사 제언: 자율운용 범위를 **에너지 절감처럼 실패 영향이 작은 영역부터** 시작해 신뢰를 쌓고, 모든 자동 결정에 롤백 경로와 사람의 감시 지표를 함께 둘 것
