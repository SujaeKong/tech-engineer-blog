## 1. 뉴스 요약

서울경제·대한경제·파이낸셜뉴스·아시아투데이 등(10-21)은 **한국항공우주산업(KAI)이 우주 궤도에서 AI로 위성 자율운영을 실증하는 데 성공**했다고 보도했다. 제목에서 확인되는 내용은 "**위성 스스로 고장 진단**", "**고장 대응책도 스스로**"로, 지상국 지시를 기다리지 않고 위성이 결함을 판단·대응하는 기술이다. 같은 날 지디넷코리아(10-21)는 **펀진의 AI가 누리호에 실려 위성에서 정상 작동을 확인**했다고 전해, 궤도 위 AI 실증이 잇따르고 있음을 보여줬다. 대상 위성과 알고리즘의 세부 사항은 제목 이상으로 확인되지 않으므로, 아래에서는 위성 자율 고장 관리의 표준 구조인 **FDIR**을 중심으로 정리한다.

## 2. 핵심 개념

### 정의
**FDIR**(Fault Detection, Isolation and Recovery)은 시스템이 스스로 **결함을 탐지하고, 원인 부위를 격리하고, 정상 또는 안전 상태로 복구**하는 결함 관리 체계다. 위성은 지상국과 교신할 수 있는 시간이 제한되고 수리가 불가능하므로, FDIR을 탑재 소프트웨어로 구현해 **사람 개입 없이 생존**하도록 설계한다. AI 기반 자율운영은 이 FDIR의 탐지·진단 단계를 규칙 기반에서 **학습 기반 이상탐지**로 확장하는 것이다.

### 구성도 — 위성 온보드 FDIR 계층

```
 텔레메트리(전압·전류·온도·자세·통신 상태 …)
        │
        ▼
 [탐지 Detection]  ─ 규칙: 한계값(Limit) 초과 검사
        │          └ AI: 정상 패턴 학습 → 예측 잔차·재구성 오차로 이상 탐지
        ▼
 [격리 Isolation]  결함 부위 판정 (센서 고장인가, 실제 장비 이상인가)
        │          └ 교차 검증: 다른 센서·모델값과 비교
        ▼
 [복구 Recovery] ─┬─ 1단계: 장비 재시작·파라미터 재설정
                  ├─ 2단계: 예비 장비 전환(이중화)
                  └─ 3단계: 안전 모드(Safe Mode) 진입 — 태양 지향·최소 전력·지상 교신 대기
        │
        ▼
 [보고]  다음 교신 시 결함 이력·조치 내역 지상 전송 → 지상 분석·모델 갱신
```

복구는 **가장 가벼운 조치부터 단계적으로** 올라간다. 어떤 판단도 확신할 수 없을 때는 임무를 멈추고 생존을 우선하는 안전 모드가 최후 방어선이다.

### 지상 중심 운용 vs 온보드 자율 운용

| 구분 | 지상 중심 운용 | 온보드 자율 운용 |
|---|---|---|
| 판단 주체 | 지상 운용자 | 위성 탑재 소프트웨어·AI |
| 대응 시점 | 다음 교신 시간까지 지연 | 결함 발생 즉시 |
| 통신 의존 | 높음(교신 창에 종속) | 낮음(비가시 구간에도 대응) |
| 연산 자원 | 지상 서버(풍부) | 우주용 프로세서(제한적) |
| 대응 범위 | 복잡한 원인 분석 가능 | 사전 정의·학습된 범위 |
| 운용 인력 | 위성 수에 비례해 증가 | 다수 위성 운용 부담 감소 |
| 주요 위험 | 대응 지연으로 고장 확대 | 오판에 의한 불필요한 조치 |

### 결함 허용(Fault Tolerance) 기법

| 기법 | 원리 | 위성 적용 예 |
|---|---|---|
| 하드웨어 이중화 | 예비 장비 보유(냉대기/온대기) | 예비 컴퓨터·통신기 |
| TMR(3중 모듈 다수결) | 3개 출력 중 다수결 채택 | 핵심 연산 모듈 |
| EDAC/ECC | 메모리 비트 오류 검출·정정 | 우주 방사선에 의한 SEU 대응 |
| 워치독 타이머 | 응답 없으면 자동 재시작 | 탑재 소프트웨어 멈춤 대응 |
| 소프트웨어 이중 이미지 | 정상 이미지로 부팅 전환 | 업데이트 실패 대응 |
| 안전 모드 | 최소 기능으로 생존 유지 | 원인 불명 결함 시 |

### AI 적용 시 설계 고려사항
- **오판의 비대칭 비용**: 놓친 결함(미탐)은 위성 손실로, 잘못된 경보(오탐)는 불필요한 안전 모드 진입과 임무 중단으로 이어진다. 임계값은 두 비용을 함께 보고 정한다.
- **검증 가능성**: 학습 모델은 판단 근거를 설명하기 어렵다. 그래서 AI는 **탐지·진단 보조**, 최종 복구 동작은 **검증된 규칙 기반 로직**이 맡는 혼합 구조가 일반적이다.
- **자원 제약**: 우주용 프로세서는 방사선 내성을 위해 성능이 낮다. 경량 모델, 추론 주기 조절이 필요하다.
- **모델 갱신**: 궤도에서 새 결함 패턴이 발견되면 지상 학습 후 업로드하는 경로와, 업로드 실패 시 이전 버전으로 되돌리는 체계를 갖춘다.

### 관련 표준·기준
- **ECSS-E-ST-70-11C**(유럽우주표준협력기구, 우주 세그먼트 운용성): 온보드 자율성 수준(실행 자율성 E1~E4 등)과 고장 관리 요구 정의
- **결함 허용 평가 지표**: 신뢰도 R(t), MTBF·MTTR, 가용성 A = MTBF / (MTBF + MTTR)
- **FMEA/FMECA**: 고장 모드·영향(치명도) 분석 — FDIR 설계의 입력

## 4. 연결 기출 토픽과 예상 변형

- **시계열 이상탐지**: 140회 4교시에 **시계열 데이터 이상치 탐지**가 출제됐고, 139회 4교시에도 **빅데이터 이상치 탐지**가 나왔다. 위성 텔레메트리는 시계열 이상탐지의 대표 적용 분야다.
- **엣지 컴퓨팅**: 블로그 통합 기출 분석(`exam_trend_integrated.json`) 기준 **기출 9회**인 시스템구조 빈출 토픽이며 139회 1교시 **엣지 vs 클라우드 컴퓨팅**으로도 출제됐다. 온보드 판단은 "통신이 끊긴 극단적 엣지" 사례로 쓸 수 있다.
- **가용성·복구**: 140회 3교시 **클라우드 네이티브 DR**처럼 복구 체계를 묻는 문항이 이어지고 있다. 이중화·안전 모드·롤백은 DR의 장치 수준 버전이다.
- **예상 변형**
  - 1교시: "FDIR(Fault Detection, Isolation and Recovery)의 개념과 절차를 설명하시오"
  - 1교시: "결함 허용 시스템의 하드웨어·소프트웨어 이중화 기법을 비교하시오"
  - 논술: "자율운영 시스템(위성·무인기 등)에 AI 기반 고장 진단을 적용할 때의 구조와 신뢰성 확보 방안을 논하시오"

## 5. 답안 구성 예시

**단답형**(1교시, 1페이지)
- 정의: 결함을 스스로 탐지·격리·복구해 정상 또는 안전 상태를 유지하는 결함 관리 체계
- 특징 3개: ① 통신 비의존 온보드 판단 ② 가벼운 조치부터 안전 모드까지 단계적 복구 ③ 이중화·EDAC 등 결함 허용 기법과 결합
- 구성도 키워드: 텔레메트리 → 탐지(규칙+AI) → 격리(교차 검증) → 복구(재시작→예비 전환→안전 모드) → 지상 보고

**논술형(2~4교시) 목차**
1. 개요: 교신 제약·수리 불가 환경과 위성 자율운영의 필요성
2. 구성/비교: FDIR 계층 구성도, 지상 vs 온보드 비교표, 결함 허용 기법표
3. 적용방안: 시계열 이상탐지 모델, AI 보조+규칙 기반 조치 혼합, 모델 업로드·롤백 경로
4. 고려사항: 오탐·미탐 비대칭, 검증 가능성, 방사선·연산 자원 제약
5. 기술사 제언: AI의 역할을 탐지·진단 고도화에 두고 최종 복구 동작은 검증된 로직에 남기며, 궤도 실증 데이터를 축적해 지상 검증 체계를 함께 키울 것
