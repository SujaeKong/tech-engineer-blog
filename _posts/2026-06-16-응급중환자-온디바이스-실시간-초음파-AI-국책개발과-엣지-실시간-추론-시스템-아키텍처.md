## 1. 뉴스 요약

2026-06-15 삼성서울병원을 중심으로 한 연구진이 **응급·중환자를 위한 '온디바이스 실시간 초음파 AI'** 기술 개발에 착수한다는 소식이 다수 매체(메디칼업저버·뉴스1 등)를 통해 보도됐다. 정부 R&D **약 50억 원**이 투입되는 이 과제의 핵심은 ① 클라우드 전송 없이 **초음파 장비(단말) 자체에서 영상 AI 추론을 실시간으로 수행**하고, ② 응급·중환자실의 **현장 즉시 진단(POCUS, Point-of-Care Ultrasound)** 상황에서 **수십 ms 단위의 저지연·결정적(deterministic) 응답**을 보장하며, ③ 환자 영상이 단말을 떠나지 않아 **프라이버시·네트워크 단절에 강건**하다는 점이다.

이는 단순한 '의료 AI'가 아니라, **자원이 제한된 의료기기에 거대 영상모델을 경량화해 탑재하고 실시간성을 보장**하는 **엣지 실시간 추론 시스템** 문제다. 추론 위치(엣지) 결정, 모델 경량화, 실시간 스케줄링, 임베디드 자원 제약, 의료기기 안전성·검증이 한 데 얽힌 **시스템구조의 종합 주제**로, 온디바이스 AI가 '되는가'를 넘어 '제때 정확히 동작하는가(real-time)'를 다룬다는 점에서 출제 시의성이 높다.

## 2. 핵심 개념

### 온디바이스 실시간 추론이란

**온디바이스 추론**은 학습된 AI 모델을 경량화해 단말 내부에서 직접 실행하는 방식이다. 여기에 **실시간(real-time)** 요건이 더해지면, 단순히 빠른 것을 넘어 **정해진 마감시간(deadline) 내 결과를 보장하는 결정성**이 핵심이 된다. 응급 초음파처럼 화면 프레임마다(예: 30fps) 병변을 추적해야 하는 경우, 평균 지연이 아니라 **최악 지연(WCET, Worst-Case Execution Time)**과 **지터(jitter)**가 품질을 좌우한다.

### 클라우드 추론 vs 엣지 실시간 추론

| 항목 | 클라우드 추론 | 엣지 실시간 추론(온디바이스) |
|---|---|---|
| 추론 위치 | 중앙 데이터센터 | 의료기기 내부(엣지) |
| 지연 특성 | 네트워크 왕복+큐잉, 변동 큼 | 로컬 처리, 저지연·낮은 지터 |
| 실시간성 | 보장 어려움(best-effort) | 마감시간 기반 결정성 확보 가능 |
| 네트워크 의존 | 상시 연결 필요 | 단절 시에도 동작 |
| 프라이버시 | 환자 영상 외부 전송 | 원본 미전송, 단말 내 처리 |
| 연산 자원 | 사실상 무제한 | NPU·메모리·전력 제약 |

### 실시간성을 만드는 시스템 요소

- **모델 경량화**: 양자화(FP32→INT8), 가지치기, 지식 증류로 연산량·메모리를 단말 가용 범위로 축소
- **하드웨어 가속**: NPU/DSP에 합성곱·행렬 연산을 오프로드해 전력당 추론 성능 확보
- **실시간 스케줄링**: 추론 태스크에 우선순위·마감시간을 부여(RTOS·우선순위 스케줄링)해 프레임 드롭 방지
- **파이프라이닝**: 영상 획득→전처리→추론→후처리 단계를 중첩 실행해 처리량(throughput) 향상
- **메모리·전력 관리**: 제한된 RAM에서 텐서 재사용, 발열·배터리 제약 하 DVFS(동적 전압·주파수 조정)

### 엣지-클라우드 하이브리드(폴백 구조)

실시간 1차 추론은 단말에서 처리하되, 정밀 판독·2차 소견·모델 업데이트는 클라우드와 협업하는 **계층형 구조**를 둔다. 네트워크가 끊겨도 단말이 단독 동작(graceful degradation)하고, 연결 시 결과·로그를 동기화한다.

## 3. 기술사 출제 포인트

- **개념 정의와 필요성**: 온디바이스 실시간 추론의 정의, 응급·의료 현장에서 저지연·오프라인·프라이버시가 요구되는 배경
- **기존 방식과의 비교**: 클라우드 추론 대비 지연 특성·실시간성·네트워크 의존·프라이버시 측면의 차이
- **실시간 시스템 관점**: 평균 지연이 아닌 최악 지연(WCET)·지터·마감시간 보장, 경성/연성 실시간의 구분
- **아키텍처 구성요소**: NPU 가속, 모델 경량화 기법, 실시간 스케줄링, 파이프라이닝, 엣지-클라우드 폴백
- **도입 시 고려사항**: 의료기기 인허가·검증(SaMD), 모델 갱신(OTA) 시 안전성, 자원 제약 하 정확도-지연 트레이드오프, 설명가능성·오작동 대응
