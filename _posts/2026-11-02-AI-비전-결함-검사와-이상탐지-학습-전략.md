## 1. 뉴스 요약

뉴시스·부산일보·뉴스1 등(10-28)은 **한국해양진흥공사가 컨테이너 손상을 1초 안에 잡아내는 AI 검사 기술로 '공공기관 AI 혁신 챌린지'에서 수상**했다고 보도했고, 부산일보는 **탐지 정확도 99% 수준**을, BBS불교방송(10-29)은 **부총리상** 수상을 전했다. 유교신문·쿠키뉴스(10-30)는 **한국수자원공사가 사진 한 장으로 시설물 위험을 분석하는 AI로 같은 챌린지 대상**을 받았다고 보도했다. 인공지능신문(10-29)과 헤럴드경제(10-30)는 **HD현대중공업이 선박 도장 결함을 AI로 자동 검사하는 시스템을 조선업계 최초로 개발**해, "눈대중 검사"를 측정 기반 검사로 바꿨다고 전했다. 각 시스템의 모델 구조와 데이터 규모는 제목 이상으로 확인되지 않으므로, 아래에서는 **AI 비전 결함 검사**의 일반 구조와 학습 전략을 정리한다.

## 2. 핵심 개념

### 정의
**AI 비전 결함 검사**는 카메라 영상에서 제품·설비·구조물의 **손상·균열·도장 불량 같은 결함을 딥러닝 모델로 자동 탐지**하는 기술이다. 결함을 직접 학습하는 **지도학습 방식**과, 정상 상태만 학습해 **정상에서 벗어난 부분을 결함으로 판단하는 비지도 이상탐지 방식**으로 크게 나뉜다. 현장에서는 결함 영상이 매우 적다는 점이 학습 전략을 결정하는 핵심 제약이다.

### 구성도 — AI 비전 검사 파이프라인

```
 [촬영]  고정 카메라 · 드론 · 스마트폰 (조명·각도 표준화)
    │
    ▼
 [전처리]  위치 정렬 · 관심 영역 추출 · 조명 보정
    │
    ▼
 [판정 모델] ─┬─ 지도학습: 결함 분류 / 위치 탐지(박스) / 영역 분할(픽셀)
             └─ 이상탐지: 정상 패턴 학습 → 이상 점수·이상 위치 맵
    │
    ▼
 [임계값 판정]  이상 점수 > 기준 → 불량 후보
    │
    ├─ 확실한 정상 → 자동 통과
    ├─ 확실한 불량 → 자동 불합격·조치 지시
    └─ 애매한 영역 → 검사자 재확인(HITL)
    │
    ▼
 [피드백]  재확인 결과를 라벨로 축적 → 재학습 · 임계값 조정 · 드리프트 감시
```

### 지도학습 vs 비지도 이상탐지

| 구분 | 지도학습(분류·탐지·분할) | 비지도 이상탐지 |
|---|---|---|
| 학습 데이터 | 결함 유형별 라벨 영상 필요 | 정상 영상 위주로 충분 |
| 새로운 결함 | 학습하지 않은 유형은 놓침 | 정상과 다르면 탐지 가능 |
| 결함 유형 구분 | 가능(긁힘·찌그러짐 등) | 어려움(이상 여부만) |
| 라벨링 비용 | 높음 | 낮음 |
| 오탐 경향 | 상대적으로 낮음 | 정상 변동(조명·오염)을 이상으로 오인 |
| 대표 기법 | CNN·Transformer 분류, 객체 탐지, 분할 | 오토인코더 재구성 오차, 특징 임베딩 거리 |
| 적합 상황 | 결함 유형이 정해져 있고 데이터 충분 | 결함이 드물고 다양 |

현장에서는 두 방식을 섞는 경우가 많다. **이상탐지로 후보를 넓게 걸러내고, 지도학습 모델로 결함 유형을 분류**하는 2단 구조가 대표적이다.

### 결함 데이터 부족 대응

| 방법 | 내용 | 주의점 |
|---|---|---|
| 데이터 증강 | 회전·밝기·잡음 변형으로 결함 영상 늘리기 | 실제와 다른 변형은 오히려 해가 됨 |
| 합성데이터 | 정상 영상에 결함을 합성하거나 생성 모델로 결함 생성 | 실제 결함과의 분포 차이 검증 필요 |
| 전이학습 | 대규모 영상으로 사전학습한 모델을 미세조정 | 도메인 차이가 크면 효과 제한 |
| 능동 학습 | 모델이 불확실한 영상부터 사람이 라벨링 | 라벨링 순서 설계 필요 |
| 이상탐지 전환 | 결함 학습 대신 정상만 학습 | 유형 분류 불가 |

### "정확도 99%"를 읽는 법
불량률이 1%인 현장이라면, 모든 제품을 "정상"으로 찍어도 정확도는 99%다. 결함 검사에서는 다음 지표를 함께 봐야 한다.
- **재현율**(미검 방지): 실제 결함 중 잡아낸 비율 — 놓치면 사고로 이어지므로 가장 중요
- **정밀도**(과검 방지): 결함이라 판정한 것 중 실제 결함 비율 — 낮으면 재검 비용 증가
- **처리 속도**: "1초 이내"처럼 현장 흐름을 멈추지 않는지
- **조건별 성능**: 야간·우천·오염 등 촬영 조건별로 성능이 유지되는지

### 관련 기준
- **ISO 2859**: 계수형 샘플링 검사 절차 — AI 전수 검사 도입 시 기존 표본 검사와의 비교 기준
- **ISO/IEC 25059**: AI 시스템 품질 모델(기능 정확성·견고성 등)
- 안전 관련 판단(시설물 위험)은 AI 단독 판정이 아니라 **검사자 확인 단계**를 남기는 것이 일반적이다

## 3. 기술사 출제 포인트

- AI 비전 결함 검사의 정의와 처리 절차
- 지도학습과 비지도 이상탐지 방식 비교
- 이상탐지 후보 추출 + 지도학습 분류의 2단 구조
- 결함 데이터 부족 대응(증강·합성데이터·전이학습·능동 학습)
- 클래스 불균형과 정확도 지표의 함정
- 재현율(미검)과 정밀도(과검)의 트레이드오프와 임계값 설정
- 애매한 판정의 검사자 재확인(HITL)과 피드백 학습
- 조명·카메라 변화에 따른 데이터 드리프트 감시
- 표본 검사(ISO 2859)에서 AI 전수 검사로의 전환 효과

## 4. 연결 기출 토픽과 예상 변형

- **이상치 탐지**: 139회 4교시 **빅데이터 클러스터링·필터링·이상치 탐지**, 140회 4교시 **시계열 데이터 이상치 탐지**가 출제됐다. 영상 기반 결함 검사는 이상탐지의 대표적인 비정형 데이터 응용이다.
- **합성데이터**: 140회 3교시 **합성데이터 생성·품질 평가**가 출제됐다. 결함 영상 부족을 합성데이터로 보완하는 것은 이 문항의 가장 실무적인 적용 사례다.
- **과적합·편향**: 139회 1교시 **과적합과 과소적합**, 3교시 **이상치·편향**이 출제됐다. 적은 결함 데이터에 맞춘 모델의 과적합, 촬영 조건 편향이 같은 맥락이다.
- **표본추출**: 140회 4교시 **표본추출**이 출제됐다. AI 전수 검사와 표본 검사를 비교하는 단락으로 활용할 수 있다.
- **예상 변형**
  - 1교시: "비지도 이상탐지(Unsupervised Anomaly Detection) 기반 결함 검사를 설명하시오"
  - 1교시: "불균형 데이터에서 모델 평가지표(정밀도·재현율·F1)를 설명하시오"
  - 논술: "제조·인프라 현장의 AI 비전 검사 시스템 구축 시 데이터 확보 전략과 운영 고려사항을 논하시오"

## 5. 답안 구성 예시

**단답형**(1교시, 1페이지)
- 정의: 카메라 영상에서 결함을 딥러닝으로 자동 탐지하는 기술(지도학습·비지도 이상탐지)
- 특징 3개: ① 결함 데이터 부족이 핵심 제약 ② 이상탐지+분류 2단 구조 ③ 재현율 중심 평가와 HITL 재확인
- 구성도 키워드: 촬영 → 전처리 → 판정 모델(분류·탐지·이상탐지) → 임계값 → 자동 통과/불합격/재확인 → 재학습

**논술형(2~4교시) 목차**
1. 개요: 육안 검사의 한계(속도·편차)와 공공·제조 현장의 AI 검사 확산
2. 구성/비교: 검사 파이프라인 구성도, 지도 vs 비지도 비교표, 데이터 부족 대응표
3. 적용방안: 촬영 표준화, 2단 판정 구조, 합성데이터 보완, 불확실 구간 재확인, 재학습 루프
4. 고려사항: 정확도 지표 착시, 미검 위험, 조건 변화 드리프트, 안전 관련 판정의 책임
5. 기술사 제언: 성과를 정확도 한 숫자로 발표하기보다 **재현율·정밀도·조건별 성능을 분리해 관리**하고, 미검 비용이 큰 현장일수록 임계값을 보수적으로 두고 사람 확인 단계를 유지할 것
