|------|------|-----------|------|

**핵심 인사이트**: 벡터DB(137)·RAG(138)에서 한 단계 나아가, **구조화된 지식(그래프)과 결합한 GraphRAG**로 진화. 환각 저감과 설명가능성이 논술 포인트.

## 2. 개념·정의

### 지식그래프 (Knowledge Graph)
> 개체(Entity)와 관계(Relation)를 **노드-엣지 그래프**로 표현한 지식베이스. 사람·조직·개념 간 의미 연결을 구조화.

### 온톨로지 (Ontology)
> 특정 도메인의 **개념·속성·관계를 형식적으로 정의**한 명세(스키마). 지식그래프의 의미 골격을 제공.

### GraphRAG
> 벡터 검색에 **지식그래프의 구조적 탐색**을 결합한 RAG. 다단계 추론·근거 추적이 가능해 환각을 줄이고 설명력을 높인다.

## 3. GraphRAG 아키텍처

```
[문서 코퍼스] ──추출(Entity/Relation)──→ [지식그래프] ←── 온톨로지(스키마)
      │                                        │
   청킹·임베딩                            그래프 인덱싱
      ▼                                        ▼
 ┌─────────┐        질의        ┌──────────────────────┐
 │ 벡터 DB │ ◀───────────────▶ │ 그래프 탐색(멀티홉)   │
 └────┬────┘                    └──────────┬───────────┘
      └────────── 하이브리드 검색 ─────────┘
                        ▼
             [LLM 생성] → 근거(출처·경로) 포함 답변
```

## 4. 핵심 기술요소

| 요소 | 역할 |
|------|------|
| 온톨로지/스키마 | 개념·관계 정의(의미 골격) |
| 개체·관계 추출 | 문서→트리플(Entity-Rel-Entity) |
| 그래프 임베딩 | 노드/관계 벡터화 |
| 하이브리드 검색 | 벡터+그래프 탐색 결합 |
| 멀티홉 추론 | 관계 연쇄 따라 근거 수집 |
| 근거 추적 | 출처·경로 제시(설명가능성) |

> 🔑 **두음: 온추임하멀근** (온톨로지·추출·임베딩·하이브리드·멀티홉·근거)

## 5. 벡터RAG와의 비교·과제

- **벡터RAG**: 유사도 기반 단편 검색 → 다단계 추론 약함, 근거 추적 제한
- **GraphRAG**: 구조적 관계 탐색 → 멀티홉 추론·설명가능성 강함
- **과제**: 그래프 구축·유지비용, 스키마 설계, 최신화(지식 갱신), 규모 확장

## 6. 답안 키워드

### 단답형(10점)
- **정의**: 개체-관계 그래프(지식그래프)+RAG 결합(GraphRAG)
- **핵심**: 온톨로지·개체추출·멀티홉·근거 추적
- **차이**: 벡터RAG(유사도) vs GraphRAG(구조·추론)

### 논술형(25점) 구조
**[서론]** LLM 환각·근거 부재 문제, 지식 결합 필요성
**[본론1] 지식표현** 온톨로지·지식그래프, 개체-관계 추출
**[본론2] GraphRAG** 하이브리드 검색·멀티홉 추론·근거 추적
**[본론3] 적용·과제** 산업형 LLM 결합, 구축비용·최신화·확장
**[결론]** 설명가능·신뢰 AI를 위한 구조화 지식의 가치
