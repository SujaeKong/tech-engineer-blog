## 1. 뉴스 요약

2026-06-01 v.daum.net은 **"LLM 다음은…현실세계 이해하는 월드모델 경쟁 치열"**을 보도했다. 같은 날 다른 매체는 **"다른 시간·다른 위치서 찍은 영상 비교해 변화만 찾는 AI 개발"**(과학을읽다) 등 **월드모델(World Model)과 시공간 인지 AI** 관련 보도를 잇따라 다뤘다. 핵심은 ① 텍스트 중심 LLM의 한계를 넘어 **물리·시간·공간을 일관되게 추론하는 월드모델**이 차세대 AI 패러다임으로 부상하고, ② 엔비디아 Cosmos·Meta V-JEPA·구글 Genie·Wayve GAIA 등 글로벌 빅테크가 **물리 기반 영상·시뮬레이션 데이터로 학습된 월드 파운데이션 모델**을 경쟁적으로 공개했다는 점이다. 월드모델은 **현실 세계의 동역학(Dynamics)**을 학습해 ① 행동 → 결과 예측, ② 합성 데이터·시나리오 생성, ③ 자율 에이전트의 계획·실행 기반을 제공한다. 같은 시기 KIST·KAIST 등 국내 연구진도 **변화 탐지(Change Detection) AI**, **공간 이해 AI** 같은 인접 기술을 연구 성과로 발표하며 월드모델 생태계를 보강하고 있다. 기술사 AI데이터분석 영역에서 **파운데이션 모델·자기지도학습·멀티모달 데이터·합성 데이터 거버넌스** 출제 비중은 매우 높다.

## 2. 핵심 개념

### LLM vs 월드모델(World Model) 비교

| 항목 | LLM(언어 모델) | 월드모델(World Model) |
|---|---|---|
| 주 입력 | 텍스트 토큰 | 영상·센서·물리 상태·텍스트 |
| 학습 신호 | 다음 토큰 예측 | 다음 상태/장면 예측, 행동→결과 예측 |
| 표현 공간 | 언어 의미 임베딩 | 시공간 동역학 임베딩 |
| 한계 | 물리 인과·공간 이해 약함 | 학습 데이터·계산량 폭증 |
| 활용 | 대화·요약·코드 | 시뮬레이션·로봇 계획·합성 데이터 생성 |
| 평가 지표 | Perplexity, MMLU | 예측 정확도, 물리 일관성, 행동 성공률 |

### 주요 월드모델 패러다임

| 모델/접근 | 핵심 아이디어 | 특징 |
|---|---|---|
| NVIDIA Cosmos | 물리 기반 영상 파운데이션 모델 | 로봇·자율주행 합성 데이터 생성 |
| Meta V-JEPA | Joint-Embedding Predictive Architecture | 픽셀 복원이 아닌 표현 공간 예측 |
| Google Genie | 인터랙티브 월드 생성 모델 | 행동 조건부 장면 생성 |
| Wayve GAIA | 자율주행 월드모델 | 주행 시나리오 합성·계획 |
| Dreamer 계열 | 잠재 동역학 + 강화학습 | 잠재 공간에서 시뮬레이션 후 행동 최적화 |

### 인지 데이터 파이프라인 구성

| 단계 | 데이터 유형 | 처리 기법 |
|---|---|---|
| 수집 | 영상·LiDAR·IMU·로그 | 멀티 센서 동기화, 시각·시간 정렬 |
| 정제 | 라벨·메타데이터 | 자기지도(Self-supervised) 사전학습 |
| 증강 | 시뮬레이션 합성 데이터 | Omniverse·Isaac Sim·CARLA |
| 학습 | 시공간 토큰화 | Video Tokenizer, 3D ConvNet, Diffusion |
| 평가 | 예측 정확도·물리 일관성 | 시나리오 벤치마크, 행동 성공률 |
| 거버넌스 | 출처·편향·저작권 | 데이터 시트·합성 데이터 표시 |

## 3. 기술사 출제 포인트

### 개념 정의와 필요성

- **월드모델(World Model)**: 현실 세계의 시공간 동역학·물리 법칙·인과 관계를 학습해 미래 상태·행동 결과를 예측하는 파운데이션 모델
- **Embodied AI**: 물리적 신체(로봇·차량·드론 등)를 가지고 환경과 상호작용하며 학습·행동하는 AI
- **자기지도학습(Self-Supervised Learning)**: 라벨 없는 데이터에서 예측 과업으로 표현을 학습하는 방식, 월드모델 사전학습의 핵심
- **합성 데이터(Synthetic Data)**: 시뮬레이션·생성모델로 만든 가상 데이터, 희소·위험·고비용 데이터를 보강
- **필요성**: ① LLM의 물리·공간 이해 한계 보완, ② 자율 에이전트·로봇 학습 데이터 부족 해소, ③ 시뮬레이션 기반 안전한 사전 학습, ④ Sim-to-Real 격차 축소

### 기존 방식과의 비교

- **지도학습 비전 모델**: 라벨 의존·작업 특화 → 일반화·예측 한계
- **LLM(텍스트 중심)**: 언어 추론 강함, 물리 인과 약함
- **VLM(Vision-Language Model)**: 이미지·텍스트 정렬, 동영상 동역학은 약함
- **월드모델**: 시공간 예측·인과 추론 가능, 시뮬레이션 기반 행동 학습에 적합
- **고전 시뮬레이션(물리엔진)**: 명시적 규칙, 새로운 환경 일반화 어려움 → 월드모델은 학습 기반 일반화

### 아키텍처 구성요소

- **입력 인코더**: 비디오 토크나이저, 멀티모달 임베딩(영상·텍스트·센서)
- **잠재 동역학 모델**: Transformer, Diffusion, JEPA, RSSM 등 시간 예측 백본
- **행동 조건부 디코더**: 행동·제어 신호를 받아 미래 장면·상태 생성
- **메모리·맥락**: 장기 의존성·시나리오 그래프, 검색 증강(RAG-of-Scenes)
- **시뮬레이터 연동**: Omniverse·Isaac·CARLA·MuJoCo 등과 데이터/모델 연계
- **평가 프레임워크**: 예측 정확도, 물리 일관성, 다운스트림 행동 성공률, 안전성 지표

### 도입 시 고려사항

- **데이터 거버넌스**: 영상 저작권·초상권, 합성 데이터 라벨링, 편향 점검
- **계산 자원**: 영상·시뮬레이션 학습은 LLM 대비 데이터·연산 폭증, AI 팩토리 인프라 필요
- **Sim-to-Real 격차**: 시뮬레이션 학습 모델의 현실 일반화, 도메인 적응(Domain Adaptation)
- **안전성·신뢰성**: 행동 예측 오차의 물리 위험, Human-in-the-Loop, 안전봉투 설계
- **평가 표준 부재**: LLM의 MMLU 같은 단일 지표 부재 → 다운스트림 행동 벤치마크 조합 필요
- **법·윤리**: 생성된 영상의 출처 표시·딥페이크 위험·합성 데이터 표시 의무화 흐름
- **상호운용성**: USD(Universal Scene Description)·glTF·ROS2 등 시뮬레이션·로봇 표준 매핑
- **거버넌스 통합**: AI 기본법·신뢰성 원칙·영향평가와 월드모델 위험성 평가 연계
