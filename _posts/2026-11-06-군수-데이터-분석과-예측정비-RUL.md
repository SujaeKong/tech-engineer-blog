## 1. 뉴스 요약

웹이코노미(11-04)는 **KAI(한국항공우주산업)가 293억 원 규모의 AI 군수 데이터 분석 플랫폼 개발에 착수**했다고 보도했다. 항공기 같은 무기체계는 수십 년 운용되며 정비 이력·부품 교체·가동 데이터가 쌓이는데, 이를 분석하면 **고장을 미리 예측하고 필요한 부품을 제때 확보**할 수 있다. 플랫폼의 대상 체계와 기능은 제목 이상으로 확인되지 않으므로, 아래에서는 **군수 데이터 분석의 대표 과제인 예측정비와 부품 수요 예측**을 답안 재료로 정리한다.

## 2. 핵심 개념

### 정의
**예측정비**(PdM, Predictive Maintenance)는 장비의 센서·운용·정비 이력 데이터를 분석해 **고장 시점을 미리 예측하고, 고장 직전 적정 시점에 정비**하는 방식이다. 그 핵심 산출물이 **잔여수명**(RUL, Remaining Useful Life), 즉 현재 상태에서 장비·부품이 기능을 잃기까지 남은 시간이다. 군수 분야에서는 이를 부품 수요 예측과 결합해 **가동률을 높이고 재고 비용을 줄이는 것**이 목표다.

### 정비 방식의 진화

| 방식 | 정비 시점 | 장점 | 단점 |
|---|---|---|---|
| 사후정비(BM) | 고장 난 뒤 | 계획 불필요 | 예기치 못한 가동 중단 |
| 예방정비(TBM) | 정해진 시간·사용량마다 | 계획 수립 쉬움 | 멀쩡한 부품도 교체(과잉 정비) |
| 상태기반정비(CBM) | 상태 지표가 기준을 넘을 때 | 불필요한 정비 감소 | 기준 초과 후라 여유 짧음 |
| 예측정비(PdM) | 예측된 고장 직전 | 정비 시점 최적화, 부품 사전 준비 | 데이터·모델 필요 |
| 처방정비(RxM) | 예측 + 최적 조치 추천 | 의사결정까지 지원 | 가장 높은 데이터 성숙도 요구 |

미국 국방부는 상태기반정비를 데이터 분석·예측으로 확장한 **CBM+** 개념을 군수 정비 정책으로 추진해 왔다.

### 구성도 — 군수 데이터 분석 플랫폼

```
 [데이터 원천]
   운용 데이터(비행시간·출격 횟수) · 센서 데이터(진동·온도·압력)
   정비 이력(고장·교체·수리) · 부품 재고·조달 · 환경(기후·기지)
        │
        ▼
 [통합·정제]  부품 식별번호 표준화 · 이력 결측 보완 · 이상값 정제
        │
        ▼
 [분석 모델]
   ├ 고장 예측·RUL 추정: 열화 추세 회귀, 생존 분석, 시계열 딥러닝
   ├ 이상 탐지: 정상 운용 패턴 대비 이탈 감지
   └ 부품 수요 예측: 간헐적 수요 모델, 정비 계획 연동 수요
        │
        ▼
 [의사결정]  정비 일정 최적화 · 부품 선행 조달 · 가동률 시뮬레이션
        │
        ▼
 [피드백]  실제 고장·정비 결과로 모델 재학습
```

### RUL 예측 접근 비교

| 접근 | 원리 | 장점 | 한계 |
|---|---|---|---|
| 물리 기반 | 마모·피로 물리식으로 수명 계산 | 데이터 적어도 가능, 설명 쉬움 | 복잡한 시스템은 모델링 어려움 |
| 통계 기반(생존 분석) | 고장 시간 분포 추정 | 불확실성 정량화 | 개별 장비 상태 반영 한계 |
| 열화 추세 회귀 | 상태 지표의 추세를 외삽 | 직관적 | 비선형 열화에 취약 |
| 딥러닝(시계열) | 다변량 센서에서 수명 학습 | 복잡한 패턴 학습 | 고장 사례 데이터 많이 필요 |
| 하이브리드 | 물리 모델 + 데이터 학습 | 적은 데이터로 정확도 향상 | 설계 복잡 |

### 군수 부품 수요의 특성
- **간헐적 수요**: 대부분 기간은 수요가 0이다가 가끔 발생한다. 일반 시계열 모델은 잘 맞지 않아, 수요 발생 간격과 크기를 따로 추정하는 **크로스턴(Croston) 방식** 같은 간헐적 수요 모델을 쓴다.
- **긴 조달 기간**: 단종·해외 조달 부품은 확보에 수개월~수년이 걸려, 예측 오차의 비용이 크다.
- **정비 계획 연동**: 예측정비로 정비 시점을 알면 **부품 수요를 수요 예측이 아닌 계획 기반으로** 바꿀 수 있다. 예측정비와 수요 예측을 한 플랫폼에서 다루는 이유다.

### 데이터 품질·보안 고려사항
- **이력 데이터 품질**: 수기 정비 기록의 누락·표기 불일치가 모델 성능을 좌우한다.
- **고장 데이터 희소성**: 핵심 부품의 고장은 드물어 학습 데이터가 부족하다(합성데이터·물리 모델 보완).
- **보안**: 무기체계 운용 데이터는 군사 기밀이다. 망 분리 환경의 분석 플랫폼, 접근 통제, 반출 통제가 필요하다.

## 3. 기술사 출제 포인트

- 예측정비(PdM)의 정의와 정비 방식 비교(BM·TBM·CBM·PdM·RxM)
- 잔여수명(RUL)의 개념과 예측 접근(물리·통계·회귀·딥러닝·하이브리드)
- CBM+와 군수 정비 정책
- 다변량 센서 시계열 기반 이상 탐지
- 간헐적 수요 특성과 크로스턴 방식
- 예측정비와 부품 수요 예측의 연동
- 정비 이력 데이터 품질과 고장 데이터 희소성
- 군수 데이터 보안(망 분리·접근 통제)
- 가동률 향상과 재고 비용 절감의 성과 지표

## 4. 연결 기출 토픽과 예상 변형

- **시계열 이상치**: 140회 4교시 **시계열 데이터 이상치 탐지**가 출제됐다. 장비 센서 데이터의 이상 탐지는 예측정비의 첫 단계다.
- **합성데이터**: 140회 3교시 **합성데이터 생성·품질 평가**가 출제됐다. 드문 고장 사례를 합성데이터로 보완하는 것은 RUL 모델의 현실적 과제다.
- **과적합·편향**: 139회 1교시 **과적합과 과소적합**, 3교시 **이상치·편향**이 출제됐다. 고장 사례가 적은 모델의 과적합과 기록 편향이 같은 맥락이다.
- **데이터 레이크**: 139회 2교시 **데이터 레이크·데이터 스웜프**가 출제됐다. 다양한 군수 데이터를 모으되 스웜프가 되지 않도록 메타데이터·표준화가 필요하다.
- **예상 변형**
  - 1교시: "예측정비(Predictive Maintenance)와 잔여수명(RUL) 예측을 설명하시오"
  - 1교시: "간헐적 수요(Intermittent Demand) 예측 기법을 설명하시오"
  - 논술: "국방·제조 분야 AI 기반 예측정비 체계의 데이터 구성, 모델링 방법, 도입 고려사항을 논하시오"

## 5. 답안 구성 예시

**단답형**(1교시, 1페이지)
- 정의: 센서·운용·정비 데이터로 고장 시점을 예측해 적정 시점에 정비하는 방식, 핵심 산출물은 RUL
- 특징 3개: ① 정비 시점 최적화 ② 부품 선행 조달 연동 ③ 물리·데이터 하이브리드 모델
- 구성도 키워드: 운용·센서·정비 이력 → 통합·정제 → 이상 탐지·RUL·수요 예측 → 정비·조달 의사결정 → 재학습

**논술형(2~4교시) 목차**
1. 개요: 무기체계 장기 운용과 가동률·정비 비용 문제
2. 구성/비교: 정비 방식 비교표, 플랫폼 구성도, RUL 접근 비교표
3. 적용방안: 정비 이력 표준화, 핵심 부품 우선 RUL 모델, 간헐적 수요 모델, 정비 계획 연동 조달
4. 고려사항: 이력 데이터 품질, 고장 사례 희소, 군사 기밀 보안, 예측 오차의 운용 영향
5. 기술사 제언: 모든 부품에 한꺼번에 적용하기보다 **가동 중단 영향이 큰 핵심 부품부터** 예측정비를 도입하고, 성과를 가동률·불시 고장 감소·재고 비용으로 측정할 것
