## 1. 뉴스 요약

2026-07-01 글로벌경제신문·mstoday 등은 **네이버와 다음이 포털을 '대화창' 중심의 대화형 AI 검색으로 전환**한다고 보도했다. 다음은 'AI 솔라'를 앞세워 대화형 포털로 진화하고, 네이버도 링크 나열식 검색에서 **질문에 직접 답하는 생성형 검색**으로 무게를 옮긴다. 단순 키워드 매칭·링크 목록을 제시하던 전통 검색이, 사용자의 자연어 질의를 이해하고 **근거와 함께 답변을 생성**하는 방식으로 재편되는 흐름이다.

이 뉴스는 단순 서비스 개편을 넘어 **'검색을 어떻게 생성형 AI와 결합할 것인가'**라는 데이터 분석·AI 응용의 본질적 주제를 보여준다. 핵심은 **RAG(검색증강생성)**로, 방대한 웹·문서에서 관련 정보를 검색해 LLM 답변의 근거로 제공함으로써 최신성과 신뢰성을 확보한다. 정보관리기술사 AI데이터분석 영역의 LLM·RAG·정보검색 주제와 직결된다.

## 2. 핵심 개념

### 전통 검색과 생성형 검색
전통 검색은 키워드 매칭과 링크 랭킹으로 **문서 목록**을 제시한다. 생성형 검색은 질의를 이해해 여러 출처를 종합한 **직접 답변**을 생성하고 출처를 함께 제시한다. 사용자는 링크를 일일이 탐색하지 않고 답을 얻는다.

### RAG(검색증강생성)
질의에 대해 벡터·키워드 검색으로 관련 문서를 찾아 **LLM 프롬프트에 근거로 결합**한 뒤 답변을 생성하는 구조다. 모델의 파라미터 지식만 쓰지 않고 외부 최신 정보를 참조해 **환각을 줄이고 최신성**을 확보한다.

### 그라운딩과 출처 표기
답변을 실제 검색된 문서에 **근거(grounding)**하고 출처를 인용해 신뢰성과 검증 가능성을 높인다. 잘못된 정보 생성 위험을 완화하는 핵심 장치다.

### 전통 검색과 생성형 검색 비교

| 구분 | 전통 검색 | 생성형 AI 검색 |
|------|-----------|----------------|
| 입력 | 키워드 | 자연어 질의·대화 |
| 결과 | 링크 목록 | 종합 답변+출처 |
| 처리 | 매칭·랭킹 | 검색+LLM 생성(RAG) |
| 강점 | 원문 탐색 | 즉답·맥락 이해 |
| 위험 | 정보 과부하 | 환각·출처 신뢰성 |

## 3. 기술사 출제 포인트

- **생성형 검색의 개념과 등장 배경**: 링크 나열식 검색의 한계와 대화형 즉답 수요, 검색 패러다임 전환
- **RAG 아키텍처와 구성요소**: 질의 이해, 문서 검색(벡터·키워드), 재순위화, 프롬프트 결합, 답변 생성
- **전통 검색과의 비교**: 입력·결과·처리 방식 차이와 각 방식의 강점·위험
- **환각 저감과 그라운딩**: 출처 기반 답변 생성, 인용·검증, 신뢰성 확보 기법
- **도입 시 고려사항**: 응답 지연·비용, 저작권·출처 표기, 편향·오정보 대응, 품질 평가 체계
