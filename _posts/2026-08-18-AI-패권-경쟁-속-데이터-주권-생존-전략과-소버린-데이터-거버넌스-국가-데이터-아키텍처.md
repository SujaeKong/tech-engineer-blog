## 1. 뉴스 요약

2026-08-18 글로벌 **AI 패권 경쟁이 '데이터 주권' 싸움으로 번지고 있다**며, 한국의 생존 전략을 짚는 기획 보도가 나왔다. AI 경쟁력의 원천이 결국 **데이터**인 만큼, 자국 데이터를 누가·어디서 통제하느냐가 국가 경쟁력을 좌우한다는 것이다.

이는 AI 시대의 핵심 자산이 **데이터로 이동**하고, 그 통제권(주권)이 전략 이슈가 됨을 보여준다. 데이터 주권·거버넌스는 정보관리기술사 AI데이터분석 영역과 직결된다.

## 2. 핵심 개념

### 데이터 주권(Data Sovereignty)
데이터가 **생성·저장·처리되는 국가의 법·통제 아래 놓인다**는 개념이다. 클라우드·AI가 국경을 넘나들면서 데이터 현지화·이전 규제가 핵심 쟁점이 된다.

### 데이터 주권 확보 수단

| 수단 | 내용 |
|---|---|
| 현지화 | 국내 저장·처리(데이터 레지던시) |
| 소버린 클라우드 | 자국 통제 클라우드·AI 인프라 |
| 거버넌스 | 분류·접근통제·이전 규제 |
| 데이터 자산화 | 개방·유통과 가치화 균형 |

### 국가 데이터 아키텍처 관점
핵심은 **보호(주권)와 활용(경제)의 균형**이다. ① 민감·전략 데이터는 현지화·소버린 인프라로 통제하고, ② 데이터 분류·접근통제·이전 규제로 거버넌스를 세우며, ③ 가명·비식별로 안전한 활용을 열고, ④ 개방·유통으로 데이터 경제를 키운다. 관건은 과도한 현지화의 비효율과 개방의 유출 위험 사이 균형, 그리고 데이터 **생명주기 전반의 품질·거버넌스** 확보다.

## 3. 기술사 출제 포인트

- 데이터 주권(Data Sovereignty)과 데이터 현지화·레지던시
- 소버린 클라우드·소버린 AI와 데이터 통제권
- 데이터 분류·접근통제·국외 이전 규제 거버넌스
- 보호(주권)와 활용(데이터 경제)의 균형 전략
- 데이터 생명주기 전반의 품질·거버넌스 확보
