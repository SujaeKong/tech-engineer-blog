## 1. 뉴스 요약

2026-09-09 천안시가 **빅데이터 플랫폼 유지관리·분석사업 중간보고회**를 열고, 분석과제 결과와 **시각화 대시보드**를 공유하며 결과를 정책에 활용하겠다고 밝혔다. 흩어진 행정 데이터를 모아 **수집·저장·분석·시각화**하는 플랫폼을 지속 운영·고도화하는 것이다.

이는 공공 데이터가 단순 개방을 넘어 **분석·활용 중심의 플랫폼**으로 진화함을 보여준다. 빅데이터 플랫폼의 운영·데이터 아키텍처는 정보관리기술사 데이터베이스 영역의 핵심 주제다.

## 2. 핵심 개념

### 공공 빅데이터 플랫폼
여러 부서·기관의 데이터를 **통합 수집·적재**하고, 분석·시각화로 **정책 의사결정**을 지원한다. 지속적 유지관리와 데이터 품질 확보가 관건이다.

### 빅데이터 플랫폼 요소

| 계층 | 내용 |
|---|---|
| 수집 | 다원 데이터 연계·ETL/ELT |
| 저장 | 데이터레이크·웨어하우스 |
| 분석 | 통계·ML·분석과제 |
| 활용 | 시각화·대시보드·정책 |

### 운영·데이터 아키텍처 관점
핵심은 **수집-저장-분석-활용의 선순환**이다. ① 다원 데이터를 ETL/ELT로 연계·정제하고, ② 데이터레이크·웨어하우스에 적재하며, ③ 분석과제로 인사이트를 도출하고, ④ 시각화 대시보드로 정책에 환류한다. 지속 운영에는 **데이터 품질·메타데이터·거버넌스**가 필수이며, 개인정보·보안도 고려해야 한다. 관건은 데이터 표준화·품질 관리, 지속가능한 유지관리, 그리고 활용 성과 측정이다.

## 3. 기술사 출제 포인트

- 공공 빅데이터 플랫폼의 수집·저장·분석·활용 계층
- ETL/ELT와 데이터레이크·데이터웨어하우스
- 데이터 품질·메타데이터·데이터 거버넌스
- 시각화·대시보드와 데이터 기반 정책 의사결정
- 지속 운영(유지관리)과 개인정보·보안 고려
