## 1. 뉴스 요약

2026-06-25 소비자경제·뉴스핌 등은 **하나생명이 사내망 전용 생성형 AI 챗봇 '별비서'를 오픈**했다고 보도했다. 금융사는 망분리 규제와 고객정보 보호 의무 때문에 외부 클라우드 LLM API를 그대로 쓰기 어렵다. 별비서는 **사내망(폐쇄망) 안에서 동작하는 업무 지원 챗봇**으로, 규정·상품·내부 문서를 검색해 임직원의 업무를 돕는다. 외부 데이터 유출 없이 생성형 AI를 활용하려는 금융권의 전형적 접근이다.

이 뉴스는 단순 서비스 출시를 넘어 **'민감 데이터 환경에서 생성형 AI를 어떻게 안전하게 운영할 것인가'**라는 시스템 구조의 핵심 과제를 보여준다. 퍼블릭 클라우드 LLM과 달리, 폐쇄망에서는 모델 호스팅·GPU 인프라·데이터 파이프라인을 자체 구축해야 하며, 보안과 성능·비용의 균형이 관건이다. 정보관리기술사 시스템구조 영역의 온프레미스 인프라·망분리·AI 시스템 아키텍처 주제와 직결된다.

## 2. 핵심 개념

### 망분리와 폐쇄망 AI
금융·공공은 내부망과 외부망을 분리(망분리)해 운영한다. 폐쇄망에서 생성형 AI를 쓰려면 **모델과 데이터를 모두 내부에 두는** 온프레미스(또는 프라이빗 클라우드) 구성이 필요하다. 외부 API 호출이 차단되므로 모델 호스팅을 직접 책임진다.

### 온프레미스 LLM과 sLLM
대형 모델을 자체 GPU로 서빙하려면 막대한 자원이 들어, 많은 기업이 **경량 모델(sLLM)**이나 양자화·증류로 비용을 낮춘다. 모델 크기와 응답 품질·인프라 비용 사이의 절충이 설계의 핵심이다.

### RAG(검색증강생성)
사내 규정·상품·매뉴얼을 벡터DB에 색인하고, 질문 시 관련 문서를 검색해 모델에 함께 제공하는 **RAG** 구조로 환각을 줄이고 최신성을 확보한다. 폐쇄망 업무 챗봇의 사실상 표준 패턴이다.

### 퍼블릭 클라우드 LLM과 폐쇄망 온프레미스 비교

| 구분 | 퍼블릭 클라우드 LLM | 폐쇄망 온프레미스 |
|------|---------------------|-------------------|
| 데이터 위치 | 외부 전송 | 내부 보존 |
| 보안·규제 | 망분리 위배 우려 | 규제 부합 |
| 모델 규모 | 초대형 활용 | 경량·자체 호스팅 |
| 비용 구조 | 사용량 과금 | 초기 인프라 투자 |
| 운영 책임 | 제공사 | 자체 운영 |

## 3. 기술사 출제 포인트

- **망분리 환경의 생성형 AI 도입 과제**: 외부 클라우드 LLM 활용의 제약과 폐쇄망 온프레미스 구성의 필요성
- **온프레미스 LLM 인프라 구성요소**: GPU 서빙, 모델 경량화(sLLM·양자화·증류), 추론 최적화와 비용 관리
- **RAG 아키텍처**: 벡터DB 색인, 검색-생성 결합, 환각 저감과 사내 지식 최신성 확보
- **퍼블릭과 온프레미스 비교**: 데이터 위치·보안·모델 규모·비용·운영 책임 관점의 트레이드오프
- **보안·거버넌스**: 프롬프트·출력 필터링, 접근통제, 로깅·감사, 민감정보 마스킹
- **도입 시 고려사항**: 단계적 확산, 사용자 업무 적합성 검증, 모델 업데이트·운영 체계(LLMOps)
