> **140회 출제 예상 토픽 #7** — 시스템구조 슬롯(139 과소예측 보강)
> 선정 근거: ① KPC 모의·합숙에서 냉각·HBM·CXL·전력 반복(하드웨어 상위), ② **시스템구조는 기출 비중 19%인데 139 과소예측**, ③ AI 데이터센터 전력·발열 병목이 실물 이슈, ④ 138 GPU/TPU 단답 → 140 인프라 통합 논술화

## 1. 출제 트렌드 분석 (135~139회)

| 회차 | 유형 | 출제 형태 | 관점 |
|------|------|-----------|------|
| 137회 | 관리 단답 | GPU 아키텍처·병렬처리 | 연산 장치 |
| 138회 | 관리 논술 | GPU·TPU·NPU 비교 | 가속기 |
| 139회 | — | (인프라 통합 미출제) | **공백** |
| 모의/합숙 | KPC | 냉각·HBM·CXL·전력 | **140 집중** |

**핵심 인사이트**: 가속기(칩) 단위(137·138)에서 **데이터센터(시스템) 단위**로 확장. 전력·냉각·메모리 대역폭 병목을 다루는 시스템구조 통합 논술 유력.

## 2. 개념·정의

### AI 데이터센터 (AI Data Center / AIDC)
> 대규모 GPU 클러스터로 AI 학습·추론을 수행하는 고밀도 인프라. **전력밀도·발열·메모리 대역폭**이 핵심 병목.

### HBM / CXL
- **HBM**: GPU에 적층된 초고대역폭 메모리, AI 연산의 데이터 공급 병목 해소
- **CXL**: CPU-가속기-메모리를 캐시 일관성으로 연결하는 **메모리 확장/풀링** 인터커넥트

## 3. AI 데이터센터 스택 아키텍처

```
┌──────────────── 시설(Facility) ────────────────┐
│ 전력(수·MW급) · UPS · 액침/D2C 냉각 · PUE 관리  │
├──────────────── 랙/네트워크 ───────────────────┤
│ 고밀도 랙 · InfiniBand/RoCE · 스케일아웃 패브릭 │
├──────────────── 컴퓨트 노드 ───────────────────┤
│ GPU × N ─ NVLink ─ HBM  │  CXL 메모리 풀        │
│      │                         │                │
│   병렬학습(데이터/텐서/파이프라인 병렬)         │
└─────────────────────────────────────────────────┘
    핵심 병목: 전력(W) · 발열(냉각) · 대역폭(HBM/네트워크)
```

## 4. 핵심 기술요소

| 요소 | 설명 |
|------|------|
| 액침/D2C 냉각 | 고발열 대응(공랭 한계 극복) |
| 전력·PUE | 전력밀도 관리·에너지효율(PUE) |
| HBM | 초고대역폭 적층 메모리 |
| CXL | 메모리 풀링·확장·일관성 |
| 인터커넥트 | NVLink·InfiniBand 스케일아웃 |
| 병렬화 | 데이터/텐서/파이프라인 병렬 |

> 🔑 **두음: 냉전H씨인병** (냉각·전력·HBM·CXL·인터커넥트·병렬화)

## 5. 병목과 대응

- **전력**: 랙당 수십~수백kW → 전력 조달·PUE 최적화·에너지 재활용
- **발열**: 공랭 한계 → **액침냉각·다이렉트칩냉각(D2C)**
- **메모리 벽**: 연산 대비 데이터 공급 부족 → HBM·CXL 풀링·오프로딩
- **확장**: 단일 노드 한계 → 저지연 패브릭 기반 스케일아웃

## 6. 답안 키워드

### 단답형(10점)
- **정의**: 고밀도 GPU 클러스터 AI 인프라, 전력·냉각·대역폭 병목
- **핵심**: 액침냉각·HBM·CXL·스케일아웃 패브릭
- **차이**: 일반 IDC(범용) vs AIDC(초고밀도·고발열)

### 논술형(25점) 구조
**[서론]** AI 규모 확대와 인프라 병목(전력·발열·메모리)
**[본론1] 컴퓨트·메모리** GPU·HBM·CXL, 병렬학습 구조
**[본론2] 시설·냉각·전력** 액침/D2C 냉각, 전력밀도·PUE
**[본론3] 네트워크·확장** 인터커넥트·스케일아웃, 에너지 지속가능성
**[결론]** 성능·전력·비용의 균형, 그린 데이터센터
