## 1. 뉴스 요약

2026-06-21 연합뉴스는 **KT가 양자 기반 미래 네트워크 보안 구상을 공개**했다고 보도했다. 양자컴퓨터가 상용화되면 RSA·ECC 같은 현행 공개키 암호가 무력화되는 'Q-Day' 위협이 현실화되는데, 통신사는 국가 기간망을 운영하므로 가장 먼저 대응이 요구되는 사업자다. KT의 구상은 **양자키분배(QKD)로 물리계층 키 교환을 보호**하고, **양자내성암호(PQC)로 종단 간 데이터를 보호**하는 이중 방어 체계를 백본망에 적용하는 것이 핵심이다.

이 뉴스는 단순 기업 홍보를 넘어 **'양자 시대에 통신 네트워크를 어떻게 다시 설계할 것인가'**라는 네트워크 구조의 본질적 문제를 다룬다. 그동안 양자보안 논의가 법·제도(양자기술산업법)나 블록체인 위주였다면, 이번 사안은 통신사가 운영하는 **실제 백본·전송망에 양자보안을 상용 적용**한다는 점에서 차별적이다. 정보관리기술사 네트워크 영역의 보안 프로토콜·키 관리·전송 아키텍처 주제와 직결된다.

## 2. 핵심 개념

### Q-Day와 HNDL 위협
**Q-Day**는 양자컴퓨터가 현행 공개키 암호를 실시간 해독할 수 있게 되는 시점을 말한다. 더 시급한 위협은 **HNDL(Harvest Now, Decrypt Later)**로, 공격자가 지금 암호문을 수집해 두었다가 양자컴퓨터 확보 후 복호화하는 방식이다. 장기 기밀성이 필요한 데이터는 Q-Day 이전부터 대응해야 한다.

### QKD(양자키분배)
광자의 양자역학적 특성을 이용해 두 지점이 **도청 시 반드시 흔적이 남는** 방식으로 대칭키를 분배하는 기술이다. 키 자체를 물리계층에서 보호하지만, 전용 광선로와 신뢰 중계(trusted node)가 필요하고 거리 제약이 있어 **백본·구간 보호**에 적합하다.

### PQC(양자내성암호)
양자컴퓨터로도 풀기 어려운 수학적 난제(격자·해시 등) 기반의 공개키 암호로, 기존 인터넷 인프라에 **소프트웨어로 적용** 가능하다. NIST가 표준화한 ML-KEM(키 캡슐화)·ML-DSA(서명)가 대표적이며, 광범위한 종단 간 보호에 쓰인다.

### QKD와 PQC 비교

| 구분 | QKD(양자키분배) | PQC(양자내성암호) |
|------|-----------------|-------------------|
| 보안 근거 | 양자역학 물리법칙 | 수학적 난제 |
| 적용 계층 | 물리·전송계층 | 응용·세션계층 |
| 인프라 요구 | 전용 광선로·중계 | 소프트웨어 업데이트 |
| 거리·범위 | 구간 제한적 | 종단 간 광범위 |
| 역할 | 백본 키 보호 | 범용 데이터 보호 |

## 3. 기술사 출제 포인트

- **Q-Day·HNDL 위협의 개념과 대응 시급성**: 양자컴퓨터에 의한 공개키 암호 붕괴와 선수집-후복호 위협의 의미
- **QKD와 PQC의 차이와 상호보완**: 보안 근거·적용 계층·인프라 요구 비교, 백본은 QKD·종단은 PQC로 결합하는 이중화 전략
- **크립토 애자일리티(crypto-agility)**: 암호 알고리즘을 신속 교체할 수 있도록 설계하는 마이그레이션 원칙과 하이브리드 키 운용
- **통신 백본 적용 시 구성요소**: 키 관리 시스템(KMS), 신뢰 중계 노드, 양자보안 게이트웨이, 기존 망과의 연동
- **도입 시 고려사항**: 거리·비용 제약, 표준 적합성(NIST PQC), 단계적 전환 로드맵, 장기 기밀 데이터 우선순위
