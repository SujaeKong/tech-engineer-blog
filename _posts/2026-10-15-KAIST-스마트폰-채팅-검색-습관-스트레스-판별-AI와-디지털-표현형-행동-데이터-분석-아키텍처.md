## 1. 뉴스 요약

행정수도뉴스(10-14)는 **KAIST가 스마트폰 채팅·검색 습관으로 스트레스를 판별하는 AI**를 개발했고, **판별 정확도는 75%**라고 보도했다. 설문에 직접 답하지 않아도 일상적인 사용 행태에서 정신 상태를 추정하려는 연구다. 확인 가능한 정보는 제목 수준이므로, 아래에서는 이 연구가 속한 **디지털 표현형(Digital Phenotyping)** 분석의 일반 구조와 답안 포인트를 정리한다.

## 2. 핵심 개념

### 정의
**디지털 표현형**은 스마트폰·웨어러블 등 개인 기기에서 생기는 **행동 데이터를 정량화해 건강·심리 상태를 추정**하는 접근이다. 사용자가 따로 입력하지 않아도 자동으로 쌓이는 **패시브 센싱** 데이터를 주로 쓴다는 점이 설문(능동 데이터)과 다르다.

### 구성도 — 행동 데이터 분석 파이프라인

```
[수집]  입력 속도·오타율 / 사용 시간대 / 검색 빈도 / 앱 전환 / 수면 추정
   │        (패시브 센싱)          +  EMA·스트레스 척도 응답 (라벨)
   ▼
[전처리] 결측 보정 → 시간창(일·주) 집계 → 개인 기준선 대비 정규화
   ▼
[특징]  변화량·변동성·리듬(일주기) 붕괴 지표
   ▼
[모델]  분류(스트레스 고/저) 또는 시계열 이상탐지
   ▼
[검증]  개인 단위 교차검증(LOSO) · AUROC/F1 · 보정(Calibration)
   ▼
[활용]  선별(스크리닝) 알림 → 전문가 연계 (진단 대체 아님)
```

### 능동 데이터 vs 수동(패시브) 데이터

| 구분 | 능동 데이터(설문·EMA) | 수동 데이터(패시브 센싱) |
|---|---|---|
| 수집 방식 | 사용자가 직접 응답 | 기기가 자동 기록 |
| 수집 빈도 | 하루 수 회 이하 | 연속적 |
| 사용자 부담 | 높음(응답 피로) | 낮음 |
| 편향 | 자기보고·회상 편향 | 기기·사용 습관 편향 |
| 해석 | 의미 명확 | 간접 지표, 해석 필요 |
| 프라이버시 위험 | 상대적으로 낮음 | 높음(행동 전반 노출) |
| 역할 | 라벨(정답) 제공 | 예측 입력 특징 |

### 데이터 분석 설계에서 놓치기 쉬운 점
- **개인차 정규화**: 원래 타자가 빠른 사람과 느린 사람의 절대값은 비교 의미가 없다. 각자의 **평소 기준선 대비 변화량**을 특징으로 써야 한다.
- **교차검증 단위**: 같은 사람의 데이터가 학습·평가에 섞이면 성능이 부풀려진다(데이터 누수). **사람 단위로 나누는 LOSO(Leave-One-Subject-Out)** 검증이 필요하다.
- **정확도 해석**: 스트레스 상태가 드물면, 전부 "정상"으로 찍어도 정확도가 높게 나온다. 75%는 **클래스 비율, 민감도·특이도, AUROC**와 함께 봐야 의미가 정해진다.
- **용도 한정**: 이 수준의 성능은 진단이 아니라 **선별·조기경보** 보조 용도다. 위양성 알림이 반복되면 사용자 신뢰가 떨어진다.

### 관련 법·기준
- **개인정보 보호법 제23조(민감정보)**: 건강 정보는 별도 동의 등 강화된 보호 대상
- **개인정보 보호법 제28조의2(가명정보 처리)**: 연구 목적 활용 시 가명처리 요건
- 채팅 **내용**까지 다루면 통신비밀 침해 우려가 커지므로, 설계상 **내용이 아닌 메타데이터 중심 수집·온디바이스 처리**가 위험을 줄이는 방향이다.

## 3. 기술사 출제 포인트

- 디지털 표현형의 정의와 패시브 센싱 데이터의 특성
- 능동(설문·EMA) 데이터와 수동 데이터의 비교
- 개인 기준선 정규화 등 행동 데이터 특징 설계
- 사람 단위 교차검증(LOSO)과 데이터 누수 방지
- 정확도의 한계와 민감도·특이도·AUROC 해석
- 클래스 불균형 처리(재표본·가중치·임계값 조정)
- 건강 민감정보 처리 요건(별도 동의·가명처리)
- 온디바이스 처리·메타데이터 중심 수집 등 프라이버시 설계
- 선별 보조 vs 진단 대체의 경계와 전문가 연계

## 4. 연결 기출 토픽과 예상 변형

- **데이터 분석 기본기**: 139회 1교시 **과적합과 과소적합**, 139회 3교시 **데이터 분석 이상치·편향**이 출제됐다. 소수 참가자의 행동 데이터로 만든 모델은 과적합과 표본 편향에 취약해, 이 뉴스는 두 토픽의 응용 사례가 된다.
- **표본과 시계열**: 140회 4교시 **표본추출**(확률·비확률)과 **시계열 데이터 이상치 탐지**가 출제됐다. 연구 참가자 모집 방식(비확률 표본)과 일상 패턴 이탈 탐지는 그대로 연결된다.
- **개인정보**: 139회 1교시 **개인정보보호를 위한 가명처리 기법**이 출제됐다. 건강 행동 데이터의 연구 활용은 가명처리 문항으로 이어지기 쉽다.
- **예상 변형**
  - 1교시: "디지털 표현형(Digital Phenotyping)의 개념과 데이터 유형을 설명하시오"
  - 논술: "스마트폰 행동 데이터 기반 정신건강 예측 모델의 설계 절차와 검증 방법, 개인정보 보호 방안을 논하시오"
  - 통계 융합: "분류 모델의 정확도가 갖는 한계와 대안 평가지표를 설명하시오"

## 5. 답안 구성 예시

**단답형(1교시, 1페이지)**
- 정의: 개인 기기 행동 데이터를 정량화해 건강·심리 상태를 추정하는 접근
- 특징 3개: ① 패시브 센싱(무부담 연속 수집) ② 개인 기준선 대비 변화 분석 ③ 선별·조기경보 용도
- 구성도 키워드: 수집 → 전처리(기준선 정규화) → 특징 → 모델 → LOSO 검증 → 전문가 연계

**논술형(2~4교시) 목차**
1. 개요: 설문 기반 정신건강 평가의 한계(응답 부담·회상 편향)와 등장 배경
2. 구성: 분석 파이프라인 구성도 + 능동·수동 데이터 비교표
3. 적용방안: 기준선 정규화 특징 설계, LOSO 검증, 불균형 대응, 보정된 확률 출력
4. 고려사항: 정확도 해석, 위양성 관리, 민감정보·통신비밀, 표본 대표성
5. 기술사 제언: 진단이 아닌 선별 보조로 범위를 한정하고, 메타데이터·온디바이스 중심 설계와 전문가 연계 경로를 함께 갖출 것
