## 1. 뉴스 요약

2026-06-25 산경e뉴스는 **한국남부발전이 AI 시대에 대비해 데이터 주권을 강화하고 데이터 거버넌스 '삼각동맹' 체계를 구축**한다고 보도했다. AI 활용이 늘면서 학습·분석의 토대인 데이터의 품질과 통제권이 곧 경쟁력이 된다. 흩어진 데이터를 표준화·통합 관리하지 않으면 AI 모델의 신뢰성도 담보할 수 없다. 남부발전의 구상은 **데이터의 생성-관리-활용 전 주기를 통제하는 거버넌스 체계**를 세워 데이터 주권을 확보하는 것이 핵심이다.

이 뉴스는 단순 시스템 도입을 넘어 **'AI를 떠받치는 데이터를 어떻게 신뢰성 있게 관리할 것인가'**라는 데이터베이스 영역의 본질적 과제를 다룬다. 'Garbage In, Garbage Out'이라는 말처럼, AI의 성능은 결국 데이터 품질에 좌우된다. 데이터 거버넌스는 데이터 표준·품질·보안·소유권을 조직 차원에서 규율하는 체계로, 정보관리기술사 데이터베이스 영역의 데이터 관리·품질·MDM 주제와 직결된다.

## 2. 핵심 개념

### 데이터 거버넌스와 데이터 주권
**데이터 거버넌스**는 데이터의 표준·품질·보안·생애주기를 정책·조직·프로세스로 규율하는 체계다. **데이터 주권**은 조직이 자신의 데이터에 대한 통제권과 소유권을 갖는 것으로, 외부 의존을 줄이고 규제·보안 요구를 충족한다.

### 마스터 데이터 관리(MDM)
고객·자산·설비처럼 여러 시스템이 공유하는 핵심 데이터를 **단일 기준 정보(Single Source of Truth)**로 통합 관리하는 것이 MDM이다. 부서·시스템마다 다른 데이터로 인한 불일치를 제거한다.

### 데이터 품질과 메타데이터
정확성·완전성·일관성·적시성 등 **데이터 품질** 차원을 측정·개선하고, 데이터의 의미·출처·계보를 기술하는 **메타데이터**와 **데이터 카탈로그**로 활용성을 높인다. 데이터 계보(lineage)는 추적성과 신뢰를 제공한다.

### 거버넌스 구성요소 비교

| 구성요소 | 목적 | 핵심 산출물 |
|----------|------|-------------|
| 데이터 표준 | 일관성 확보 | 표준 사전·코드 |
| 데이터 품질 | 신뢰성 확보 | 품질지표·정제규칙 |
| MDM | 단일 기준정보 | 마스터 데이터 |
| 메타데이터 | 의미·계보 관리 | 데이터 카탈로그 |
| 데이터 보안 | 통제·주권 | 접근정책·등급 |

## 3. 기술사 출제 포인트

- **데이터 거버넌스의 개념과 필요성**: AI 시대 데이터 품질·주권의 중요성과 'Garbage In, Garbage Out' 관점
- **데이터 거버넌스 구성요소**: 표준·품질·MDM·메타데이터·보안의 역할과 상호관계
- **MDM과 단일 기준정보**: 시스템 간 데이터 불일치 문제와 마스터 데이터 통합 관리 방안
- **데이터 품질 관리**: 품질 차원(정확성·완전성·일관성 등) 측정과 정제·개선 프로세스
- **메타데이터와 데이터 계보**: 데이터 카탈로그·리니지를 통한 추적성·신뢰성 확보
- **도입 시 고려사항**: 거버넌스 조직(데이터 오너십)과 정책, 점진적 확산, AI 학습 데이터 신뢰성 연계
