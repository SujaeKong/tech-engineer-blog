## 1. 뉴스 요약

2026-06-29 더팩트·브릿지경제 등은 **과학기술정보통신부가 '제조AI'를 국가전략 사업으로 추진하며 2030년까지 약 20조 원을 투자**한다고 보도했다. 핵심 과제는 산업 현장의 데이터를 모아 공동 활용하는 **국가 제조데이터 라이브러리(National Manufacturing Data Library) 구축**이다.

제조AI는 설계·공정·품질·설비 운영 등 제조 전 주기에 AI를 적용하는 것을 말한다. 그러나 AI의 성능은 결국 **학습에 쓸 양질의 데이터**에 좌우된다. 개별 기업이 가진 데이터는 양이 적고 품질·형식이 제각각이어서, 국가 차원에서 데이터를 표준화·집적해 **공동 학습 기반**을 만들겠다는 것이 이번 전략의 본질이다. 정보관리기술사 AI데이터분석 영역의 빅데이터·데이터셋 구축·파운데이션 모델 학습 주제와 직결된다.

## 2. 핵심 개념

### 제조AI와 제조데이터의 특수성
제조데이터는 센서 시계열, 설비 로그, 품질 검사 이미지, 공정 파라미터 등 **다종·대용량·고빈도** 특성을 갖는다. 또한 결함(불량) 사례가 드물어 **데이터 불균형**이 심하고, 라벨링에 도메인 전문성이 필요하다. 일반 텍스트·이미지 학습과 달리 도메인 특화 전처리가 핵심이다.

### 국가 제조데이터 라이브러리
여러 기업·산업의 제조데이터를 **표준 스키마로 정제·집적**해 공동 학습과 재사용이 가능하도록 만든 데이터 저장·제공 체계다. 데이터 수집 → 정제·표준화 → 라벨링 → 카탈로그화 → 안전한 제공의 라이프사이클로 운영되며, 개별 기업이 풀기 어려운 **데이터 부족 문제를 규모의 경제로 해결**하는 것이 목적이다.

### 데이터 표준화와 메타데이터
서로 다른 설비·공정에서 나온 데이터를 함께 쓰려면 단위·포맷·식별자를 통일하는 **표준화**와, 출처·품질·이력을 기록하는 **메타데이터(데이터 카탈로그)**가 필수다. 표준화 없는 데이터 집적은 학습 효율을 떨어뜨리고 모델 신뢰성을 훼손한다.

### 데이터 공유의 신뢰 장치
기업이 핵심 데이터를 내놓으려면 **영업비밀 보호와 통제권**이 보장돼야 한다. 가명·비식별 처리, 데이터를 옮기지 않고 학습하는 연합학습(Federated Learning), 합성데이터 생성 등이 신뢰 기반 공유를 가능하게 하는 기술적 장치다.

### 일반 데이터 활용과 제조데이터 활용 비교

| 구분 | 일반 데이터 활용 | 제조데이터 라이브러리 |
|------|------------------|------------------------|
| 데이터 출처 | 단일·자체 수집 | 다수 기업·산업 집적 |
| 표준화 수준 | 낮음 | 공동 스키마 표준화 |
| 데이터 불균형 | 보통 | 결함 희소·심함 |
| 공유 장벽 | 낮음 | 영업비밀·통제권 |
| 활용 방식 | 개별 학습 | 공동 학습·재사용 |

## 3. 기술사 출제 포인트

- **개념 정의와 필요성**: 제조AI와 국가 제조데이터 라이브러리의 정의, 데이터 부족·불균형을 국가 차원에서 해결하는 배경
- **데이터 라이프사이클**: 수집·정제·표준화·라벨링·카탈로그화·제공 단계별 구성요소와 품질 관리
- **표준화와 메타데이터**: 데이터 스키마 표준화와 데이터 카탈로그가 공동 학습 효율에 미치는 영향
- **신뢰 기반 공유 기술**: 가명·비식별, 연합학습, 합성데이터의 원리와 영업비밀 보호 방안
- **도입 시 고려사항**: 데이터 주권·통제권, 라벨링 비용, 데이터 거버넌스, 중소 제조기업의 참여 유인
- **기대효과와 한계**: 공정 최적화·예지보전·품질 향상 효과와 데이터 편향·공유 거부에 따른 한계
